# 附录第3章：摩擦减速下绕固定轴的旋转

*Rotational Motion with Friction*

---

## 本章概述

欧拉讨论了摩擦力对旋转运动（rotational motion）的减速效果。当旋转的刚体受到轴承摩擦或其他摩擦力矩时，角速度逐渐减小直至停止。欧拉在第1001节的问题6中，详细讨论了如何将旋转轴固定在轴承中的多种工程方案（圆环、V形槽、凹圆槽等），并在第1005节的问题7中给出了完整的摩擦减速分析。

---

## 1. 轴承摩擦力矩

绕固定轴旋转的刚体，在轴承处受到摩擦力矩。如果轴承处的法向力（pressing force）为 $N$，轴的半径为 $r$，摩擦系数为 $\mu$：

$$M_{\text{摩擦}} = -\mu N r \cdot \text{sgn}(\omega)$$

**推导说明**：轴承处的摩擦力为 $f = \mu N$（库仑摩擦定律），作用在轴的表面上。摩擦力对旋转轴的力矩等于摩擦力乘以力臂，即轴的半径 $r$：$M_{\text{摩擦}} = f \cdot r = \mu N r$。由于摩擦力总是阻碍相对运动，当 $\omega > 0$ 时摩擦力矩为负（顺时针），当 $\omega < 0$ 时为正（逆时针），因此加上 $\text{sgn}(\omega)$ 因子以确保力矩方向与角速度方向相反。负号表示摩擦力矩总是阻碍旋转。

## 2. 匀减速旋转

运动方程（由转动定律 $I\dot{\omega} = M$）：
$$I\dot{\omega} = -\mu N r$$

**积分求角速度**：由于右端为常数（假设 $\omega > 0$，故 $\text{sgn}(\omega) = 1$），对时间积分：

$$\int_0^t \dot{\omega}\,dt' = -\frac{\mu N r}{I}\int_0^t dt'$$

$$\omega(t) - \omega_0 = -\frac{\mu N r}{I}t$$

解：
$$\omega(t) = \omega_0 - \frac{\mu N r}{I}t$$

**停止时间**：令 $\omega(t_{\text{停止}}) = 0$：
$$t_{\text{停止}} = \frac{I\omega_0}{\mu N r}$$

**积分求总转角**：由 $\omega = d\theta/dt$，将角速度表达式对时间积分：

$$\theta = \int_0^{t_{\text{停止}}} \omega(t)\,dt = \int_0^{I\omega_0/(\mu Nr)}\left(\omega_0 - \frac{\mu N r}{I}t\right)dt$$

$$= \omega_0 \cdot \frac{I\omega_0}{\mu N r} - \frac{1}{2}\cdot\frac{\mu N r}{I}\cdot\left(\frac{I\omega_0}{\mu N r}\right)^2 = \frac{I\omega_0^2}{\mu N r} - \frac{I\omega_0^2}{2\mu N r}$$

总转角：$\theta = \frac{I\omega_0^2}{2\mu N r}$

**能量验证**：初始旋转动能 $\frac{1}{2}I\omega_0^2$ 全部被摩擦力矩做功消耗。摩擦力矩做功为 $\mu N r \cdot \theta = \mu N r \cdot \frac{I\omega_0^2}{2\mu N r} = \frac{1}{2}I\omega_0^2$，与初始动能一致。

> **批注**：转动惯量 $I$ 越大，旋转停止所需的时间越长——这就是飞轮的原理。飞轮通过大的转动惯量来储存旋转动能，即使有摩擦也能长时间保持旋转。欧拉在第1005节的解中特别指出，轴承半径 $f$ 越小，摩擦的减速效果越弱（$f$ 出现在角减速度的分子中），但轴承又不能太细，否则无法承受载荷。这个工程约束与物理分析的结合，体现了欧拉的务实风格。

## 3. 物理摆的摩擦阻尼

有摩擦时，物理摆的运动方程：
$$I\ddot{\theta} + \mu Nr\,\text{sgn}(\dot{\theta}) + Mgd\sin\theta = 0$$

**推导说明**：方程各项的来源——（1）$I\ddot{\theta}$ 是转动定律 $I\alpha = M$ 的左端；（2）$\mu Nr\,\text{sgn}(\dot{\theta})$ 是轴承摩擦力矩，方向总是与角速度方向相反；（3）$Mgd\sin\theta$ 是重力对悬挂点的恢复力矩（$Mgd\sin\theta$ 来源于重力 $Mg$ 对距质心 $d$ 处的悬挂点的力矩，当 $\theta$ 为正时力矩为负，故需要调整符号使整个方程描述正确的恢复行为）。

库仑摩擦（与速度无关，只与方向有关）导致**振幅线性衰减**（不同于粘性阻尼的指数衰减）。

**振幅衰减量的推导**：考虑摆从最大偏角 $\theta_{\text{max}}$ 释放，摆动到另一侧最大偏角 $\theta'_{\text{max}}$ 的半个周期。在这半个周期内，摩擦力矩 $\mu Nr$ 始终做负功。利用能量关系（假设小角度，$\sin\theta \approx \theta$）：

初始势能：$Mgd\frac{\theta_{\text{max}}^2}{2}$（取最低点为零势能）

到达另一侧时的势能：$Mgd\frac{{\theta'}_{\text{max}}^2}{2}$

摩擦力矩做功：$-\mu Nr \cdot (\theta_{\text{max}} + {\theta'}_{\text{max}})$（总转角约为两个振幅之和）

由能量守恒：
$$Mgd\frac{{\theta'}_{\text{max}}^2}{2} = Mgd\frac{\theta_{\text{max}}^2}{2} - \mu Nr(\theta_{\text{max}} + {\theta'}_{\text{max}})$$

对于小幅衰减，$\theta_{\text{max}} \approx {\theta'}_{\text{max}}$，因此：
$$Mgd\frac{\theta_{\text{max}}^2 - {\theta'}_{\text{max}}^2}{2} \approx \mu Nr \cdot 2\theta_{\text{max}}$$

$$Mgd(\theta_{\text{max}} + {\theta'}_{\text{max}})\frac{\theta_{\text{max}} - {\theta'}_{\text{max}}}{2} \approx \mu Nr \cdot 2\theta_{\text{max}}$$

每半个周期，振幅减少一个固定量：
$$\Delta\theta = \theta_{\text{max}} - {\theta'}_{\text{max}} \approx \frac{2\mu Nr}{Mgd}$$

关键在于：衰减量 $\Delta\theta$ 与振幅无关，仅取决于摩擦参数和重力参数。这意味着振幅随时间（或周期数）线性递减，最终，摆会在某个非零角度处停止（静摩擦力平衡了重力力矩）。

> **批注**：库仑摩擦与粘性阻尼的区别在于衰减的方式：粘性阻尼给出指数衰减（每周期减小相同的百分比），库仑摩擦给出线性衰减（每周期减小相同的角度值）。这个区别可以通过实验验证——记录摆的振幅随时间的变化，画在半对数坐标上。如果是直线，则是粘性阻尼；如果是线性递减，则是库仑摩擦。值得注意的是，欧拉在第964节的注释中已经认识到，纯滚动时摩擦为零——因为接触点之间没有相对滑动（"rubbing"）。这一观察是理解滚动摩擦与滑动摩擦本质区别的关键。

## 本章小结

附录第3章讨论了摩擦对旋转运动的影响：

1. **轴承摩擦力矩**
2. **匀减速旋转**：转动惯量越大，减速越慢
3. **库仑摩擦阻尼**：振幅线性衰减
