把这套文稿改进为：

> **以欧拉英文底本为依据，保留欧拉提出问题和推进论证的思想路线，用现代符号和适合高中生的现代汉语重写核心内容，并通过就地批注留下通往现代理论的引子。**

1. **内容准确、论证完整、概念清楚**；

3. 语言润色和格式美化。

不要只在现有中文稿上做表面润色。内容需要重排、压缩或重写时，可以直接重写，不受原有段落结构限制。

## 三、逐章工作流程

### 1. 读取原文和现稿

先读目标中文文件，再读对应英文底本。英文文件对应关系如下：

- 引言：`english_translation/genmotch1.txt` 至 `genmotch6.txt`。
- 正文：`english_translation/tmvol1ch1tr.txt` 至 `tmvol1ch19tr.txt`。
- 附录第1—3章：`english_translation/appendiixchs123.txt`。
- 附录第4—5章：`english_translation/appendiixchs45.txt`。

需要公式或图版时，查同目录 PDF。部分辅助文本可能不是 UTF-8，不要为了无关内容大规模转换文件。

同时查看总览中的“原著与本系列对应表”，注意中文文件编号不等于原著章号。

### 2. 做内容审计

改写前先列出：

- 本章实际讨论的问题和论证路线；
- 现稿遗漏的关键定义、假设或推理步骤；
- 现稿把现代一般定理误写成欧拉原结论的地方；
- 公式、适用条件、历史论断和现代类比的疑点；
- 重复、跳跃或对目标读者过深的内容；
- 应省略的繁琐历史计算。

核心定义、命题和公式必须回查英文底本；现代公式还应独立验算，不能因为英文或旧中文稿如此写就默认正确。

### 3. 重建议论路线

优先采用以下认知顺序，但不必机械套栏目：

1. 直观问题或物理情境；
2. 核心概念及其适用条件；
3. 一个可算通的具体例子；
4. 从例子到一般结论的推导；
5. 结论的意义、限制和后续问题；
6. 就地批注与现代引子；
7. 简短小结和下一章过渡。

正文第1章的“两个质点取矩 → 微元力矩积分 → 一般质心定义”是推荐的推导方式：先让读者亲手算通，再抽象推广。

### 4. 重写正文

- 先说明一个量“描述什么”，再写公式。
- 每个重要结论都说明成立条件，避免把特殊情形写成一般定理。
- 不用大段微积分符号代替物理解释。
- 不随意引入未定义的术语；必须使用时，就地给出最短充分解释。
- 删除重复总结、反复赞颂和无新信息的过渡段。
- 保留欧拉的历史术语，但解释其现代含义及两者并不完全等同之处。
- 不把现代符号、矩阵、矢量叉积或现代定理说成欧拉已经使用的工具。

### 5. 添加批注和现代引子

批注放在对应定义、公式或论证之后，主要承担：

- 补充直观解释或省略的非核心推导；
- 区分欧拉原命题与现代一般形式；
- 指出常见误读和概念陷阱；
- 说明历史背景或现代对应概念；
- 留下进一步阅读入口。

现代引子应短而明确，例如“非均匀引力场 → 潮汐力”“质心方程不能决定转动 → 角动量方程”。需要继续学习的内容给出可靠来源，不在批注中展开完整高级课程。

### 6. 必要时配图

图应解决具体的理解困难，例如：

- 刚体取向与轨迹的关系；
- 参考方向、旋转轴和力矩；
- 质心与等效作用线；
- 陀螺、滚动和摩擦中的几何关系。

图中同一时刻与不同时刻、位置与速度、实际轨迹与辅助线必须区分清楚。速度箭头应沿轨迹切线。新增或修改 SVG 后必须实际渲染检查，不能只看 XML 源码。

### 7. 读者审读

以目标高中生视角通读，重点问：

- 能否在不查大学教材的情况下跟上核心论证？
- 哪个术语第一次出现时没有解释？
- 哪一步只是“代数能算”，但几何或物理意义没有看懂？
- 正文与现代批注的适用范围是否会被读成矛盾？
- 图是否可能暗示匀速、同轨迹或其他并未成立的结论？
- 读完后能否复述本章解决了什么问题、结论为何成立？

只修改真正阻碍理解的问题，不为追求形式统一反复改写已经清楚的文字。重要章节可再进行一次读者视角复核。

### 8. 技术检查

完成后检查：

- 本地 Markdown 链接和图片路径是否存在；
- `$$` 等公式定界符是否配对；
- 新公式中的符号是否已定义；
- SVG 是否实际渲染正常；
- `git diff --check` 是否通过；
- `git status --short -- .` 中是否出现本轮不需要的临时文件。

删除自己创建的预览文件和临时输出，不处理用户已有的无关文件。

## 四、内容准确性的硬约束

### 欧拉与现代内容必须分层

- 欧拉在本章没有证明的一般定理，不得直接写成本章原命题。
- 现代推广只能放在批注、现代引子或明确标出的延伸内容中。
- 若现代证明更短，可以使用，但要说明这是现代重述，不冒充原始论证。

### 遇到冲突或疑点

若英文底本、现有中文稿和现代结论不一致：

1. 先核实底本与公式；
2. 正文采用正确、清楚的现代表述；
3. 必要时在批注说明原表述、差异和修改理由；
4. 无法确认的标为“待考”，不得编造确定结论或参考文献。

### 省略不等于遗忘

省略的标准不是“原著有没有”，而是“是否帮助现代读者理解核心思想”。

- 对理解核心思想没有帮助的重复轴承受力计算、旧单位换算和纯哲学讨论，直接省去。
- 影响理论完整性的内容不能用“选编”为理由删掉。
- 章首可用简短“选编说明”交代重写和合并原则，但不堆原著节号。

### 正文第16章的特殊处理

当前正文第16章应按原著天体旋转问题重写，保留天体旋转、月球天平动与岁差的核心物理思想，删去繁复历史推算。

原“柔性轴上的刚体运动”属于现代推广，不与欧拉原著正文混排。其中有价值的内容只能移入相关批注或明确标出的现代延伸。

## 五、符号与语言风格

### 符号

遵循总览的现代符号表。粗体字母表示矢量，普通斜体字母表示标量。常用约定包括：

- $\mathbf r$：点的位置；$\mathbf R$：质心位置；
- $\mathbf v,\ \mathbf V$：点速度、质心速度；
- $m_i,\ M$：微元或质点质量、总质量；
- $\mathbf F$：力；$\mathbf P$：总动量；
- $\boldsymbol\omega$：角速度；$\mathbf L$：角动量；
- $\boldsymbol\tau$：外力矩；
- $I$：对固定轴的转动惯量；$\mathbf I$：惯量张量或其矩阵；
- $T$：动能；$t$：时间。

同一章内不要让一个符号无说明地改变意义。符号转换不能改变定理的适用条件。

### 正文语气

- 少用“伟大”“划时代”“最深刻”等评价词。
- 历史意义应通过具体问题说明，不靠赞颂代替解释。
- 不写成逐句翻译，也不写成只列现代公式的教科书。
- 小结只回扣核心思想，不重复整章。

### 批注语气

保留现有样板中“解释背景—澄清思想—联系现代”的风格。批注可以有启发性，但夸张判断必须有依据，现代概念不能倒算到欧拉身上。

## 七、完成一章的验收标准

只有同时满足以下条件，才把一章视为完成：

### 内容

- 已对照英文底本，而不是只润色旧中文。
- 核心概念、公式和适用条件准确。
- 关键论证完整，没有影响理解的跳步。
- 欧拉原述、现代重述和编者延伸已经分层。
- 省略内容符合选编原则。

### 读者体验

- 高中生能借助直观例子和基本微积分思想跟上主线。
- 新术语和新符号在首次出现时得到充分解释。
- 图示不会引入新的误读。
- 批注保留启发性，现代引子简洁且可追踪。

### 形式

- 标题和正文不含原著节号定位。
- 语言克制，重复和机械展开已删除。
- 本地链接、公式定界符和 SVG 渲染检查通过。
- 没有遗留临时文件或无关修改。

## 八、推荐推进顺序

1. 按学习依赖处理引言各章。
2. 依次处理正文第2—10章，先建立固定轴转动、转动惯量、主轴和欧拉方程的核心体系。
3. 处理正文第11—19章的自由转动、陀螺、天体与滚动应用；第16章按专门约定重写。
4. 处理附录第1—5章，重点辨析欧拉摩擦表述与现代模型的异同。
5. 最后复查总览、章节标题、导航、符号表、跨章引用和术语一致性。

每章完成后即可提交审读，不要为了等待全部章节而积累大量未验证改写。全书完成后，再做一次跨章一致性和重复内容检查。
