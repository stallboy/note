# 附录第5章：进一步的摩擦问题

*Concerning the Motion of Globes on a Horizontal Plane*

---

## 本章概述

在附录的最后一章，欧拉讨论了球体（globe）在水平面上的运动。他假定球体的质心（centre of inertia）位于几何中心，这使得问题大大简化。欧拉在第1038-1045节（问题14-16）中系统分析了球体在水平面上同时具有平移和旋转运动时，接触点处的摩擦效应。

> **批注**：欧拉选择以球体作为附录的最后一个主题，是有深意的。球体是最简单的"各向同性"刚体——所有直径都是主轴，转动惯量在所有方向上相等。这使得数学分析比第4章的陀螺问题简单得多，同时又能完整展示摩擦如何同时影响平移和旋转两种运动。

---

## 1. 纯滚动条件

欧拉在第1039-1041节的推论中讨论了球体在水平面上**无摩擦运动**的条件。

当球体的接触点没有相对滑动（即纯滚动）时，摩擦力为零。根据欧拉的分析，这需要同时满足两个条件：

1. 旋转轴的水平投影方向与平移运动方向垂直
2. 平移速度与旋转角速度之间满足特定关系：$v = f\omega'\sin s$

**推导说明**：接触点的速度由两部分叠加——（1）球体质心的平移速度 $v$（沿运动方向）；（2）绕旋转轴旋转产生的线速度 $f\omega'\sin s$（垂直于旋转轴方向）。当这两个分量恰好大小相等、方向相反时，接触点的合速度为零——即无相对滑动，此时摩擦力为零。旋转轴水平投影与运动方向垂直的条件保证了两个速度分量的方向恰好相反；而 $v = f\omega'\sin s$ 的条件保证大小相等。这类似于纯滚动的条件 $v = R\omega$（其中 $R$ 是球体半径），只是这里的几何关系更为一般。

> **批注**：欧拉在第1042节的注释1中承认了一个重要的事实：实际中球体放在桌面上总是会停下来的，即使理论分析表明纯滚动时摩擦为零。他指出，这是由于实际接触不是一个理想的"点"，而是一个有限区域，导致了另一种"阻碍"——这正是后来被称为"滚动摩擦"的现象。Ian Bruce在此处加了一个注释，指出当时的人们尚未完全理解滚动摩擦的本质——它涉及接触区域的连续微小非弹性碰撞和表面变形。

## 2. 接触点速度与摩擦方向

欧拉在第1038节的问题14中，精确计算了球体接触点相对于水平面的速度。

**推导说明**：接触点的速度是平移速度和旋转速度的矢量和。平移速度 $v$ 沿运动方向。旋转产生的线速度大小为 $f\omega'\sin s$（其中 $f$ 是球体半径，$\omega'$ 是角速度大小，$s$ 是旋转轴与竖直方向的夹角——$\sin s$ 给出旋转速度在水平面上的分量），方向由旋转轴的水平投影决定（方位角为 $\sigma$）。

将旋转速度分解为沿运动方向和垂直于运动方向的两个分量：
- 沿运动方向分量：$f\omega'\sin s\sin\sigma$
- 垂直于运动方向分量：$f\omega'\sin s\cos\sigma$

接触点合速度方向由角度 $\zeta$ 确定：
$$\tan\zeta = \frac{f\omega'\sin s\cos\sigma}{v - f\omega'\sin s\sin\sigma}$$

其中分子是垂直分量，分母是沿运动方向的净速度（平移速度减去旋转速度沿运动方向的分量）。$\sigma$ 是旋转轴方向的方位角，$s$ 是旋转轴与竖直方向的角距离。

摩擦力 $\alpha M$（$\alpha$ 为摩擦系数，$M$ 为球体重力即正压力）沿接触点速度的反方向作用于球体。

> **批注**：欧拉在第1043节的注释2中指出，由于球体质心位于几何中心，正压力始终等于球体重量 $M$——这比第4章的陀螺问题简单得多，因为陀螺的正压力是随运动状态变化的。这个简化使得球体问题可以被更完整地分析。

## 3. 摩擦力矩对主轴的分量

欧拉在第1044节的问题15中，将摩擦力分解到三个主轴方向，计算了各轴上的力矩分量：

$$P = \alpha Mf\sin l\sin(\varphi + \sigma + \zeta)$$
$$Q = \alpha Mf\sin m\sin(\varphi + \sigma + \zeta)$$
$$R = \alpha Mf\sin n\sin(\varphi + \sigma + \zeta)$$

其中 $l, m, n$ 是各主轴与竖直方向的角距离，$\varphi$ 是进动角。

> **批注**：这三个力矩具有相同的正弦因子 $\sin(\varphi + \sigma + \zeta)$，只是振幅不同（由 $\sin l$, $\sin m$, $\sin n$ 决定）。这意味着摩擦力矩的方向在空间中是固定的（由接触点速度方向决定），而它在各主轴上的分量则随着球体的旋转而周期性变化。这个结构使得球体问题比陀螺问题更容易处理。

## 4. 球体平移运动的方程

欧拉在第1045节的问题16中，建立了描述球体质心平移运动的微分方程：

$$\frac{dv}{2g\,dt} = \cos\varepsilon, \quad \frac{v\,d\varphi}{2g\,dt} = \sin\varepsilon$$

其中 $\varepsilon$ 是摩擦力方向与运动方向之间的角度。

**推导说明**：摩擦力大小为 $\alpha M$（$\alpha$ 为摩擦系数，$M$ 为球体重力即正压力），方向沿接触点速度的反方向。将该摩擦力分解为两个分量：沿运动方向的分量 $\alpha M\cos\varepsilon$（使速率改变）和垂直于运动方向的分量 $\alpha M\sin\varepsilon$（使运动方向改变）。

由牛顿第二定律，沿运动方向：$M_{\text{球}}\frac{dv}{dt} = -\alpha M\cos\varepsilon$。欧拉使用的符号中，质量用 $M/2g$ 表示（其中 $M$ 是重量，$2g$ 是换算因子），因此方程变为 $\frac{M}{2g}\frac{dv}{dt} = -\alpha M\cos\varepsilon$（注意符号约定，欧拉取减速为正）。

垂直于运动方向（向心方向）：$M_{\text{球}}v\dot{\varphi} = \alpha M\sin\varepsilon$，即 $\frac{M}{2g}v\frac{d\varphi}{dt} = \alpha M\sin\varepsilon$。

这两个方程联立确定了速率 $v(t)$ 和方向角 $\varphi(t)$，从而确定球体质心的轨迹。由于 $\varepsilon$ 本身依赖于 $v$ 和 $\varphi$（通过接触点速度方向），这组方程是耦合的，一般需要数值求解。

> **批注**：球体在水平面上的运动是附录中最"完整"的例子——欧拉能够同时处理平移和旋转两种运动，以及它们通过摩擦的耦合。虽然最终的方程仍然无法获得封闭形式的解，但问题的结构已经被完全揭示。从欧拉的整个附录来看，他展示了一条清晰的研究路径：先建立摩擦的基本定律（第1章），再依次处理越来越复杂的系统——纯平移（第2章）、纯旋转（第3章）、陀螺的耦合运动（第4章）、球体的耦合运动（第5章）。

## 5. 全书结论

通过30章的系统论述（引言6章 + 正文19章 + 附录5章），欧拉完成了经典力学史上最伟大的理论构建之一。

### 引言部分（第1-6章）——基础

欧拉从质点力学出发，建立了全书所需的分析框架：

- **运动学**：位置→速度→加速度的三层结构，微积分符号的系统运用
- **动力学**：牛顿三定律的分析形式表述，力与加速度、动量与力的关系
- **直线运动**：恒力、位置相关力（谐振子）、速度相关力（阻力）的完整求解
- **曲线运动**：运动的分解、切向与法向加速度、角动量守恒（面积定律）
- **阻尼介质**：终端速度、抛体在有阻力介质中的轨迹

### 正文部分（第1-19章）——核心

这是全书的主体，构成了完整的刚体动力学理论体系。概念展开遵循严密的逻辑顺序：

**第一阶段——平移运动（第1章）**：
- 刚体的严格定义（定义1：距离不变的质点系）
- 质心运动定理（$\mathbf{F}_{\text{外}} = M\ddot{\mathbf{R}}_{\text{cm}}$）
- 刚体有6个自由度

**第二阶段——绕固定轴的旋转（第2-4章）**：
- 角速度、角动量的概念
- 转动惯量 $I = \sum m_i r_i^2$ 的定义
- 旋转运动方程 $I\dot{\omega} = M$
- 物理摆理论和等效单摆长度
- 平行轴定理 $I = I_{\text{cm}} + Md^2$

**第三阶段——一般旋转的几何基础（第5章）**：
- **欧拉旋转定理**：有限旋转等价于绕某轴的一次旋转
- 瞬时旋转轴和角速度矢量的概念
- 速度公式 $\mathbf{v} = \boldsymbol{\omega} \times \mathbf{r}$

**第四阶段——惯量张量与主轴（第6-7章）**：
- 转动惯量的方向依赖性：$I(\hat{\mathbf{n}}) = A\alpha^2 + B\beta^2 + C\gamma^2 - 2D\alpha\beta - 2E\alpha\gamma - 2F\beta\gamma$
- 惯量椭球
- **主轴定理**：三个互相垂直的轴使惯量积为零（实对称矩阵对角化）
- 主转动惯量 $I_1, I_2, I_3$

**第五阶段——运动方程的推导（第8-10章）**：
- 双坐标系（空间固定 + 固连于刚体）
- 时间导数变换公式：$\frac{d\mathbf{A}}{dt}\big|_{\text{空间}} = \frac{d\mathbf{A}}{dt}\big|_{\text{固连}} + \boldsymbol{\omega} \times \mathbf{A}$
- 角速度的矢量加法
- **欧拉旋转方程**（全书核心）：
$$I_1\dot{\omega}_1 - (I_2 - I_3)\omega_2\omega_3 = M_1$$
$$I_2\dot{\omega}_2 - (I_3 - I_1)\omega_3\omega_1 = M_2$$
$$I_3\dot{\omega}_3 - (I_1 - I_2)\omega_1\omega_2 = M_3$$
- 欧拉角参数化和完整的6方程体系

**第六阶段——应用与推广（第11-19章）**：
- 球对称体、旋转对称体、一般三轴体的分类讨论
- 自由旋转的稳定性分析（绕中间轴不稳定——网球拍效应）
- 自由刚体运动（6自由度系统）
- 重陀螺理论（进动、章动、休止陀螺）
- 陀螺运动的详尽分析
- 柔性轴上的刚体运动（陀螺耦合振动、临界转速）
- 球体和圆柱体的滚动

### 附录部分（第1-5章）——完善

欧拉将摩擦纳入理论力学，使理论更接近实际：

- 摩擦的基本定律（静/动摩擦，库仑摩擦）
- 摩擦对平移和旋转运动的减速效果
- 摩擦对陀螺运动的影响（自转减速→进动加速→稳定性丧失→倒下）
- 滚动摩擦和机械效率

### 核心贡献总结

| 贡献 | 现代名称 | 意义 |
|---|---|---|
| 刚体的严格定义 | — | 建立了刚体力学的研究对象 |
| 质心-转动分解 | 柯尼希定理 | 将6自由度问题分解为两个3自由度问题 |
| 转动惯量 | 二次型/惯量张量 | 刚体抵抗角加速度的度量 |
| 主轴定理 | 谱定理的特例 | 惯量张量的对角化 |
| 欧拉旋转方程 | — | 刚体旋转运动的基本方程 |
| 欧拉角 | — | 旋转的参数化描述 |
| 旋转稳定性 | 中间轴定理 | 理解自由旋转的关键 |

> **批注**：欧拉的《刚体运动理论》是物理学史上最重要的著作之一。它不仅解决了"刚体如何运动"这个物理问题，还在数学上开创了新的领域（惯量张量的理论、实对称矩阵的对角化、非线性微分方程的定性分析）。从牛顿的《原理》（1687）到欧拉的《刚体运动理论》（1765），经典力学花了近80年才从质点力学扩展到刚体力学——这个时间跨度本身就说明了刚体动力学的数学难度。欧拉以一己之力，将刚体动力学从零发展为一门成熟的科学——这无疑是他众多伟大贡献中最辉煌的之一。

## 全书结语

欧拉在1765年完成了这部著作，当时他58岁。他在此前多年中视力逐渐衰退（约1738年一场重病后右眼几乎完全失明），而1766年左眼也将完全失明。也就是说，这部包含大量复杂推导和计算的著作，是欧拉在视力严重受损的情况下完成的。

> **批注**：更令人惊叹的是，欧拉在完全失明后仍然继续工作，通过口述让助手记录，又产出了大量的数学和物理论文。他一生发表了超过800篇论文和著作，全集至今仍未完全出版完毕（已超过80卷）。在刚体运动理论方面，欧拉的影响延续至今：从卫星姿态控制到分子光谱计算，从陀螺仪导航到机器人运动学——260多年过去了，欧拉的方程依然在描述着我们的世界。欧拉的创造力堪称人类智慧的巅峰。

这部著作中的每一个方程、每一个定理，都仍在今天的物理学、工程学和数学中发挥着作用。从卫星的姿态控制到分子光谱的计算，从陀螺仪导航到机器人运动学——250多年过去了，欧拉的方程依然在描述着我们这个世界。
