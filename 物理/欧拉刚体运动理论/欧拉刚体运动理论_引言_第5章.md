# 引言第5章：受任意力作用的微粒的绝对运动

*Concerning the Absolute Motion of Bodies Acted on by Forces in General*

---

## 本章概述

本章将运动理论从直线推广到平面和三维空间中的曲线运动。欧拉依次处理了：平面内的自由运动（问题13）、约束在管道中的平面运动（问题14）、用极坐标处理的中心力运动（问题15）、三维空间中的自由运动（问题16）、三维管道中的约束运动（问题17），以及用天文学坐标（经度、纬度、交点线、倾角）处理的空间运动（问题18）。这一章的数学工具和物理概念直接为后面的刚体运动理论做准备。

> **批注**：本章是欧拉解析力学的精华所在。几个关键贡献值得注意：（1）将力分解为切向分量和法向分量（推论207），这至今仍是力学教科书中的标准做法；（2）给出了离心力公式 $\frac{Avv}{2gr}$（推论213），这是牛顿以来首次在解析框架中系统处理；（3）引入了球面三角学来处理三维力的方向（注释227），这在后来的刚体动力学中至关重要；（4）建立了天文学中处理轨道运动的一般方法（问题18），直接影响了梅耶的月球表。

## 问题13：平面内的自由运动

**问题13**（205）. 若一微粒受力作用，其运动在同一平面内完成，求任意时刻走过的距离、位置和速度。

**解答**. 设运动在平面内进行（图18），取两条互相垂直的方向 $OA$ 和 $OB$。微粒沿曲线 $ESF$ 运动，在时间 $t$（以秒表示）到达点 $S$。作 $SX$ 垂直于 $OA$，得坐标 $OX = x$ 和 $XS = y$。走过的弧长 $ES = s$，故：

$$ds = \sqrt{dx^2 + dy^2}$$

设微粒质量为 $A$（即它在选定地区的重量），在 $S$ 处受力。通过静力学分解，这些力可化为沿 $SP$ 和 $SQ$ 两个方向（分别平行于坐标轴）的力。设 $SP = P$，$SQ = Q$，均以相等的重量给出。

力的分解依据平行四边形法则：任何一个力都可以沿两个互相垂直的方向分解为分量 $P$ 和 $Q$，使得原来的力等价于 $P$ 和 $Q$ 的叠加。

取时间元素 $dt$ 为常数，将运动沿 $SP$ 和 $SQ$ 分解，运动由以下两个方程确定：

$$ddx = \frac{2gP}{A}dt^2, \quad ddy = \frac{2gQ}{A}dt^2$$

其中 $g$ 表示重物在选定地区一秒内自由下落的高度。这两个方程直接来自第3章建立的运动方程 $dds = \frac{2gp}{A}dt^2$（定理5的推论3），分别应用于 $x$ 方向和 $y$ 方向。由于第4章中已经确定了 $\alpha = 2g$，这里出现因子 $2g$。

### 速度方程

沿 $SP$ 方向的速度：

$$\frac{dx}{dt} = \frac{2g}{A}\int P\,dt$$

沿 $SQ$ 方向的速度：

$$\frac{dy}{dt} = \frac{2g}{A}\int Q\,dt$$

设 $S$ 处速度为 $v$，由于 $v = \frac{ds}{dt}$ 且 $ds^2 = dx^2 + dy^2$，可得：

$$v\,dv = \frac{2g}{A}(P\,dx + Q\,dy)$$

这个方程的推导如下：对 $v^2 = v_x^2 + v_y^2 = (dx/dt)^2 + (dy/dt)^2$ 微分，得 $2v\,dv = 2(dx/dt)\,d(dx/dt) + 2(dy/dt)\,d(dy/dt)$。利用运动方程 $d(dx/dt) = 2gP\,dt/A$ 和 $d(dy/dt) = 2gQ\,dt/A$，代入并整理即得 $v\,dv = \frac{2g}{A}(P\,dx + Q\,dy)$。这是关于速度 $v$ 的微分方程。

### 法向力与曲率

设 $dy = p\,dx$，从而 $ds = dx\sqrt{1+p^2}$。经过微分运算得：

$$dp = \frac{2g\sqrt{1+p^2}}{Av^2}(Q\,dx - P\,dy)$$

这里的推导过程：令 $dy/dx = p$，则 $d^2y/dx^2 = dp/dx$。从两个运动方程消去 $dt^2$，利用 $ddy = dp \cdot dx + p \cdot ddx$ 和 $ddx = \frac{2gP}{A}dt^2$、$ddy = \frac{2gQ}{A}dt^2$，可得关于 $dp$ 的表达式。

曲线 $ESF$ 的密切圆半径（radius of osculation）为：

$$r = -\frac{ds(1+p^2)}{dp}$$

密切圆半径的几何含义是：曲线在该点附近的弯曲程度越小，密切圆越大（$r$ 越大）；反之弯曲程度越大，密切圆越小（$r$ 越小）。负号是为了使 $r$ 取正值（因为 $dp$ 在曲线向内弯曲时为负）。

代入得：

$$\frac{P\,dy - Q\,dx}{ds} = \frac{Av^2}{2gr}$$

这一步将密切圆半径 $r$ 的定义式代入 $dp$ 的表达式，经过代数整理即得。左边 $\frac{P\,dy - Q\,dx}{ds}$ 正是力在法线方向的投影（法向力），右边 $\frac{Av^2}{2gr}$ 则揭示了法向力与速度平方成正比、与曲率半径成反比的关系。

### 切向力与法向力

**推论1**（206）. 引入速度 $v$ 后，运动由以下两个方程表示：

$$Av\,dv = 2g(P\,dx + Q\,dy), \quad Av^2\,ds = 2gr(P\,dy - Q\,dx)$$

**推论2**（207）. 应当注意，$\frac{P\,dx + Q\,dy}{ds}$ 表示切向力（tangential force），$\frac{P\,dy - Q\,dx}{ds}$ 表示法向力（normal force）。令切向力 $= T$，法向力 $= N$，有：

$$Av\,dv = 2gT\,ds, \quad Av^2 = 2gNr$$

这两个方程的物理含义清晰：切向力 $T$ 沿运动方向做功，改变速度大小（动能）；法向力 $N$ 垂直于运动方向，不做功，只改变运动方向（产生向心加速度 $v^2/r$）。

> **批注**：将力分解为切向分量和法向分量是欧拉对力学的重大贡献之一。切向力改变速度的大小（$Av\,dv = 2gT\,ds$），法向力改变速度的方向（$Av^2 = 2gNr$）。这种分解方式在现代教科书中仍然是标准内容。法向力公式 $N = \frac{Av^2}{2gr}$ 就是离心力（centrifugal force）公式的变体——它揭示了曲线运动中"向心力"的本质。欧拉在注释204中提到这些公式"与前面的书中的公式一致"——说明他在《力学》中已经推导过，但当时用的是比例方法，现在用绝对量重新表述。

**推论3**（208）. 切向力的效果为 $T = \frac{Av\,dv}{2g\,ds}$，法向力的效果为 $N = \frac{Av^2}{2gr}$。

## 例子：抛体运动

**例子**（209）. 设微粒持续受沿 $BO$ 方向的常力作用，力的大小等于其重量 $A$——这就是地球表面以上投射体的情形。因此 $P = 0$，$Q = -A$，方程为：

$$ddx = 0, \quad ddy = -2g\,dt^2$$

设微粒从 $O$ 点以速度 $c$ 投出，方向与水平线 $OA$ 成角 $\alpha$。初始沿 $OA$ 方向的速度为 $c\cos\alpha$，沿 $OB$ 方向为 $c\sin\alpha$。

积分（注意到 $t=0$ 时 $x=0, y=0$）：

$$x = ct\cos\alpha, \quad y = ct\sin\alpha - gt^2$$

消去 $t$ 得到轨迹方程：

$$\left(\frac{c^2\sin\alpha\cos\alpha}{2g} - x\right)^2 = \frac{c^2\cos^2\alpha}{g}\left(\frac{c^2\sin^2\alpha}{4g} - y\right)$$

这是一条抛物线（parabola），参数为 $\frac{c^2\cos^2\alpha}{g}$。消去 $t$ 的过程如下：从 $x = ct\cos\alpha$ 解出 $t = x/(c\cos\alpha)$，代入 $y = ct\sin\alpha - gt^2$，得 $y = x\tan\alpha - \frac{gx^2}{c^2\cos^2\alpha}$，配方后即得上述标准形式。

$S$ 处的速度：

$$v = \sqrt{c^2 - 4gy}$$

令 $y = 0$ 得射程（range of throw）：

$$R = \frac{c^2\sin\alpha\cos\alpha}{g}$$

射程可以直接从轨迹方程令 $y=0$ 得到，也可以从 $x$ 的表达式分析：物体回到同一水平面时 $y=0$，即 $t = \frac{c\sin\alpha}{g} \cdot 2$（利用对称性，上升和下降时间相等），此时 $x = ct\cos\alpha = \frac{c^2\sin\alpha\cos\alpha}{g}$。

> **批注**：这是伽利略抛体运动的解析版。伽利略在其《两门新科学》（1638）中用几何方法证明了抛体轨迹是抛物线。欧拉的贡献在于用解析方程系统地处理——这种方法可以自然地推广到有力阻力的情况。值得注意欧拉使用的符号与我们不同：他的 $c$ 是初速度的"等效高度"的平方根，而 $g$ 是一秒下落距离，因此公式中出现了因子4而非2。

## 约束运动：管道中的运动

**问题14**（211）. 若微粒被约束在平面内的管道中运动，同时受力作用，求微粒在管道中的运动以及对管道施加的力。

**解答**. 设管道形状 $ESR$ 已知（图18），微粒在时间 $t$ 到达 $S$，坐标 $OX = x$，$XS = y$，弧长 $ES = s$。外力 $SP = P$，$SQ = Q$，质量为 $A$。

由于管道改变微粒的运动方向，管道本身对微粒施加未知的约束力。将约束力分解为 $SP = X$ 和 $SQ = Y$。约束力不改变微粒的速率（只改变方向），故 $X\,dx + Y\,dy = 0$——这个条件的物理含义是约束力在切向方向不做功（$X\,dx + Y\,dy$ 正是约束力在位移方向的投影乘以位移大小，即约束力所做的功）。

管道对微粒施加的法向力为：

$$\frac{Av^2}{2gr} - \frac{P\,dy - Q\,dx}{ds}$$

反过来，微粒对管道的压力（pressing force）与此大小相等、方向相反。这个表达式可以从运动方程推导：将约束力 $X, Y$ 加入运动方程，利用 $X\,dx + Y\,dy = 0$ 消去约束力的切向分量，剩下的法向分量就是管壁施加的法向约束力。

**推论1**（212）. 若无外力（$P = 0, Q = 0$），运动是匀速的，管道处处受法向力 $\frac{Av^2}{2gr}$。

**推论2**（213）. 这个压力 $\frac{Av^2}{2gr}$ 被称为**离心力**（centrifugal force），因为它源于微粒被迫违背惯性沿曲线运动。离心力与质量 $A$ 成正比，与速度平方 $v^2$ 成正比，与曲率半径 $r$ 成反比。这个比例关系的物理直觉是：质量越大惯性越大，越难改变方向，所需约束力越大；速度越快，方向变化越剧烈，所需约束力越大；曲率半径越大（越接近直线），所需约束力越小。

> **批注**：离心力公式 $F_{cf} = \frac{mv^2}{r}$ 是牛顿在《原理》中推导的，但牛顿用的是几何方法。欧拉将其纳入解析框架，使之成为运动方程的一部分而非独立的原理。这种处理方式更加系统化——离心力不再是"例外"现象，而是法向约束力的一个自然结果。在后面的刚体旋转理论中，这一思想将自然发展为刚体内各质点之间的约束力分析。

**推论3**（214）. 若还有切向外力 $T$ 和法向外力 $N$，则管道所受压力为 $\frac{Av^2}{2gr} - N$。

## 例：竖直圆周上的运动

**例子**（215）. 设微粒受重力作用，被约束沿竖直圆周 $OS$ 上升（图19），圆心 $B$，半径 $OB = b$。$OA$ 水平，在 $O$ 处水平速度为 $c$。

则 $P = 0$，$Q = -A$，$r = -b$。运动方程：

$$v\,dv = -2g\,dy$$

解得 $v^2 = c^2 - 4gy$，速度在 $D$ 处为零，此处 $y = \frac{c^2}{4g}$。

压力沿 $SB$ 为：

$$-A + \frac{3Ay}{b} - \frac{Ac^2}{2gb}$$

对于小初速度（$c$ 相对于 $b$ 无穷小），半振荡时间（tempus semioscillationis / time of semi-oscillation）为：

$$T_{1/2} = \frac{\pi}{2}\sqrt{\frac{b}{2g}}$$

完整的秒摆（pendulum simple / simple pendulum）长度为 $b = \frac{2g}{\pi^2}$。当 $g = 15.625$ 莱茵尺时，秒摆长为 $3.166287$ 莱茵尺。

> **批注**：这个例子实际上就是"竖直圆环上的无摩擦珠子"问题——惠更斯早在1673年的《钟摆论》中就研究过。欧拉的贡献在于用解析方法系统地处理，给出了压力随位置变化的完整表达式。秒摆长度的计算则直接服务于精密计时，这是18世纪最迫切的科学需求之一——精确的海上经度测定依赖于精密时钟。

## 极坐标方法：中心力运动

**问题15**（217）. 若微粒在平面内自由运动，受两个力作用：一个指向固定点 $O$，另一个垂直于该方向（图20），求任意时刻微粒到 $O$ 的距离和角度 $AOS$。

**解答**. 设距离 $OS = u$，角度 $AOS = \varphi$。沿 $SO$ 方向的力为 $V$（推力），垂直于 $OS$ 方向的力为 $S$。

通过坐标变换，得到两个运动方程：

$$\text{I.} \quad ddu - ud\varphi^2 + \frac{2gV}{A}dt^2 = 0$$

$$\text{II.} \quad udd\varphi + 2du\,d\varphi - \frac{2gS}{A}dt^2 = 0$$

**推论1**（218）. 方程II乘以 $u$ 并积分，面积元素 $\frac{1}{2}uu\,d\varphi$ 正比于时间——这就是**面积定律**（即角动量守恒的几何表述）。当侧向力 $S = 0$ 时，面积与时间成正比——无论径向力 $V$ 如何。

具体推导：方程II为 $udd\varphi + 2du\,d\varphi - \frac{2gS}{A}dt^2 = 0$。注意到 $d(u^2\,d\varphi) = 2u\,du\,d\varphi + u^2\,dd\varphi = u(2du\,d\varphi + u\,dd\varphi)$，因此方程II乘以 $u$ 后左端可以写成 $d(u^2\,d\varphi) = \frac{2gSu}{A}dt^2$。当 $S = 0$ 时，$d(u^2\,d\varphi) = 0$，积分得 $u^2\,d\varphi = \text{const}$。而 $\frac{1}{2}u^2\,d\varphi$ 正是面积元素（极坐标下位置向量扫过的面积的微分），因此面积与时间成正比。

**推论4**（221）. 若 $S = 0$（中心力情形），则 $uu\,d\varphi = ff\,dt$（常数），由此可推导出行星运动的轨道方程。

> **批注**：欧拉在此引入的极坐标运动方程组是理论天文学的基石。方程I描述径向运动（受到"离心力" $ud\varphi^2$ 的修正），方程II描述角运动。推论1中表述的面积定律就是开普勒第二定律的解析形式——力指向固定点时，面积扫过速率恒定。欧拉明确指出这些公式在理论天文学中的"最大用途"（usus amplissimus），用来确定行星的经度、近点角和距离。

## 三维空间中的自由运动

**问题16**（223）. 若微粒在空间中自由运动，受任意力作用，用三个互相垂直的坐标确定其运动。

**解答**（图21）. 取三条互相垂直的方向线 $OA, OB, OC$。微粒质量 $A$，沿曲线 $ESF$ 运动。从 $S$ 向 $AOB$ 平面作垂线 $SY$，从 $Y$ 向 $OA$ 作垂线 $YX$，得三个坐标 $OX = x$，$XY = y$，$YS = z$。弧长 $ES = s$，速度 $v = \frac{ds}{dt}$。

$$ds = \sqrt{dx^2 + dy^2 + dz^2}$$

力分解为 $SP = P$，$SQ = Q$，$SR = R$，运动方程：

$$ddx = \frac{2gP}{A}dt^2, \quad ddy = \frac{2gQ}{A}dt^2, \quad ddz = \frac{2gR}{A}dt^2$$

速度方程：

$$v\,dv = \frac{2g}{A}(P\,dx + Q\,dy + R\,dz)$$

其中 $\frac{P\,dx + Q\,dy + R\,dz}{ds}$ 为切向力。

**推论3**（226）. 消去速度后，得到不含时间的曲线方程：

$$P\,dz\frac{d^2\cdot\frac{dy}{dz}}{dx\,dy} + Q\,dx\frac{d^2\cdot\frac{dz}{dx}}{dz\,dx} + R\,dy\frac{d^2\cdot\frac{dx}{dy}}{dx\,dy} = 0$$

**注释**（227）. 欧拉用球面三角学（spherical trigonometry）表示了法向力的方向（图22）。合力 $V = \sqrt{P^2 + Q^2 + R^2}$，它与运动方向的夹角 $\varphi$ 的余弦为 $\frac{P\,dx + Q\,dy + R\,dz}{V\,ds}$。这个余弦表达式的含义是：分子是力向量 $(P, Q, R)$ 与位移向量 $(dx, dy, dz)$ 的内积，分母 $V\,ds$ 是两者大小的乘积，因此这正是力与运动方向之间夹角的余弦（点积公式）。曲率半径等于 $\frac{Av^2}{2gV\sin\varphi}$，位于法线方向 $SN$ 上。

> **批注**：问题16是整个刚体运动理论的解析基础。三个坐标方向的运动方程本质上就是牛顿第二定律的分量形式——虽然欧拉的符号与今天不同（他用 $ddx$ 而非 $\frac{d^2x}{dt^2}$），但物理内容完全一致。特别值得注意的是注释227中对法向力方向的球面三角学处理——这种方法在后面处理刚体旋转的力矩时将发挥关键作用。

## 三维管道中的约束运动

**问题17**（228）. 若微粒在管道中运动，不受任何外力，求其运动及对管道的压力。

**解答**. 因不受外力，速度恒定：$\frac{ds}{dt} = c$，$s = ct$。管道对微粒施加的约束力不做功（$X\,dx + Y\,dy + Z\,dz = 0$），总约束力为：

$$V = \frac{Acc\sqrt{ddx^2 + ddy^2 + ddz^2}}{2g\,ds^2}$$

曲率半径 $r = \frac{Acc}{2gV}$（推论229），其方向与约束力一致。

> **批注**：这是三维空间中"无外力管道运动"的一般理论。微粒保持匀速运动，管道提供的约束力完全用于改变运动方向——这个力就是三维的"向心力"。曲率半径的公式表明，对于给定的速度和质量，曲率越大（半径越小），所需的约束力越大。

## 天文学坐标方法

**问题18**（232）. 若微粒部分地受指向固定点 $O$ 的力作用，部分地受其他力作用，求其相对于该点的运动。

**解答**（图23）. 通过固定点 $O$ 取"桌面平面"（plane of the table），取固定方向线 $OA$。微粒在时间 $t$ 到达 $S$，从 $S$ 向平面作垂线 $SY$，从 $Y$ 向 $OA$ 作垂线 $YX$，得正交坐标 $OX = x$，$XY = y$，$YS = z$。

在 $S$ 处的力分解为：沿 $YO$ 方向的力 $V$，沿 $YV$ 方向的力 $S$（垂直于 $OY$，在平面内），沿 $SR$ 方向的力 $R$。

令 $OY = u$，角度 $AOY = \varphi$，角 $SOY = \psi$（纬度 / latitude），角 $AOY = \varphi$（经度 / longitude）。引入交点线（nodal line）$OT$，角度 $AOT = \omega$，平面倾角（inclination）$= i$。

四个运动方程：

$$ddu - ud\varphi^2 + \frac{2gV}{A}dt^2 = 0$$

$$udd\varphi + 2du\,d\varphi - \frac{2gS}{A}dt^2 = 0$$

$$d\omega = \frac{2g\,dt^2\sin(\varphi-\omega)}{Au\,d\varphi}\left(V\sin(\varphi-\omega) - S\cos(\varphi-\omega) + R\cot i\right)$$

$$d(\ln\tan i) = \frac{2g\,dt^2\cos(\varphi-\omega)}{Au\,d\varphi}\left(V\sin(\varphi-\omega) - S\cos(\varphi-\omega) + R\cot i\right)$$

**推论1**（233）. 因此，对于给定时间 $t$，需要确定四个量 $u, \varphi, \omega, i$——由两个二阶微分方程和两个一阶微分方程决定。

**推论3**（235）. 当 $\sin(\varphi-\omega) = 0$（即微粒经过参考平面时），且 $V\sin(\varphi-\omega) - S\cos(\varphi-\omega) + R\cot i = 0$ 时，交点线和倾角不发生变化。

**注释**（237）. 欧拉特别指出，这种能够令人满意地表达交点线和倾角瞬时变化的方法，为理论天文学带来了显著的好处。格丁根的梅耶教授（Johann Tobias Mayer）正是基于此方法，以极大的热情推导出了最卓越的月球表（Tabulae Lunares），使天文学几乎登上了最高峰。

> **批注**：问题18是本章最前沿的部分，直接服务于天体力学。欧拉引入的"交点线"和"倾角"概念，与今天轨道力学中的"升交点赤经"（$\Omega$）和"轨道倾角"（$i$）完全对应。梅耶的月球表是18世纪天文学的重大成就——它使得海上经度的精确测定成为可能。欧拉与梅耶的通信和合作是理论与应用紧密结合的典范。这段历史也说明，欧拉写作《刚体运动理论》时，天体力学的需求始终是他最重要的驱动力之一。

## 本章小结

第5章建立了平面和三维空间中运动的完整理论：

1. **平面运动**：力的切向/法向分解，离心力公式
2. **约束运动**：管道中的运动和对管道的压力
3. **中心力运动**：极坐标方程和面积定律
4. **三维运动**：三坐标方程，球面三角学处理力的方向
5. **天文学坐标**：交点线、倾角、经纬度的运动方程

> **批注**：本章从平面到三维、从自由到约束、从直角坐标到天文学坐标，层层递进，建立了一套完整的解析力学工具箱。这些工具在后面的刚体理论中将全部得到运用：切向/法向力的分解用于分析刚体内力，离心力概念用于旋转运动，三维坐标用于描述刚体姿态，而球面三角学更是欧拉角的理论来源。
