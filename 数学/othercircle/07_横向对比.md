## 一、全球数学精英培养模式分类

按"**核心载体**"分，全球数学精英培养可分为 **5 大模式**：

| 模式 | 代表 | 核心载体 | 对回龙观的契合度 |
|------|------|---------|----------------|
| **A. 讨论班模式** | 俄罗斯（莫斯科） | 线下每周讨论班 | ⭐⭐⭐⭐⭐（`moscow/` 已是核心） |
| **B. 杂志模式** | 匈牙利（KöMaL）/ 罗马尼亚（Gazeta）/ 日本（大学への数学） | 每月问题 + 署名解答 | ⭐⭐⭐⭐（可做"每月问题专栏"） |
| **C. 志愿圈模式** | 美国（Math Circles） | 社区志愿者圈 | ⭐⭐⭐⭐⭐（与回龙观定位最接近） |
| **D. 大师讲座模式** | 英国（RI Masterclasses） | 邀请制大师系列讲座 | ⭐⭐⭐（客座讲者可借鉴） |
| **E. 专门学校模式** | 俄罗斯（AESC）/ 新加坡（NUS High）/ 韩国（科学高中）/ 中国（1+3、丘成桐） | 选拔 + 贯通培养 | ⭐⭐（回龙观依托的 1+3 属此类） |

> **回龙观的定位**：**A（讨论班）+ C（志愿圈）为骨架，B（杂志）+ D（讲座）为补充，依托 E（1+3 专门学校）的生源**。

## 四、关键共性（全球共识）

无论哪种模式，全球数学精英培养有 **7 条共性**：

| 共性 | 说明 |
|------|------|
| **1. 问题驱动** | 没有任何国家用"知识点+例题"培养精英 |
| **2. 长期投入** | 至少 3–4 年的持续投入（中学到大学） |
| **3. 早期发现** | 从 11–14 岁开始识别（KöMaL/数学圈/1+3 都是初一起） |
| **4. 大学下沉** | 大学教授/研究生直接接触中学生 |
| **5. 共同体感** | 学生不仅是学习者，更是"数学共同体"成员 |
| **6. 教师关键** | 教师的数学能力 + 热情是核心 |
| **7. 荣誉激励** | 解答署名 / 竞赛名次 / 数学共同体认可 |

```
                    选拔强度
                       ↑
        俄罗斯 ●        │        ● 新加坡 NUS High
        （AESC）        │        ● 韩国科学高中
                       │        ● 中国丘成桐
                       │
   匈牙利 ●            │        ● 日本灘/開成
   （KöMaL）           │        ● 中国 1+3
                       │
                       │
   美国 ●──────────────┼──────────── 英国
   Math Circles        │        RI Masterclasses
                       │
   回龙观 ● ←──────────┘
   （目标位置）
                       │
                       │
                    低压力
```

**回龙观的目标位置**：
- **选拔强度：中**（1+3 已筛选，但圈内开放）
- **压力水平：低**（研究导向，非应试）
- **主持人：家长 + 客座**（非大师，但有数学专业者支持）
- **形式：每周讨论班 + 每月问题专栏 + 寒暑假读书营**

> **一句话定位**：回龙观 = **莫斯科的骨架（每周讨论班）+ 美国的皮肤（社区志愿圈）+ 匈牙利的血液（每月问题专栏）+ 英国的点缀（客座大师讲座）+ 中国 1+3 的生源基础**。
