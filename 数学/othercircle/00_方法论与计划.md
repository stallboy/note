# 00 方法论与计划：其他国家/地区数学圈资料收集

> 本文件是 `othercircle/` 目录的**总纲**。它规定：**为什么收集、收集什么、怎么收集、收集后怎么用**。
>
> 与 `../moscow/` 的关系：moscow 目录已系统整理了**俄罗斯（苏）**的数学讨论班与中学数学圈体系；本目录负责**补全世界其他地区 + 中国本土**的对照资料，最终服务于"回龙观数学圈"的本土化实践（见 `../moscow/实践方案_回龙观数学圈/`）。
>
> 目录创建日期：2026-06-22

---

## 一、为什么要做这件事（研究的意义）

`moscow/实践方案_回龙观数学圈/01_核心方案.md` 已基于莫斯科模式给出了完整的实践方案。但直接照搬单一模式有 3 个风险：

| 风险 | 说明 |
|------|------|
| **文化错位** | 莫斯科模式依赖"大学数学家下沉到中学"的传统，中国/北京不具备这个土壤 |
| **制度错位** | 俄罗斯有 Kvant 杂志 + 数学奥林匹克 + 寄宿学校的三位一体；中国是"1+3 / 强基 / 奥赛"轨道 |
| **样本单一** | 仅参考一国容易陷入"路径依赖"，看不到其他可能（如美国的完全民间化、匈牙利的竞赛+研究双轨） |

**因此**：收集多国/多地区资料，目的是**为"回龙观数学圈"提供一个"对照系"**，从中提炼出**可迁移的要素**，而不是再复制一个模式。

---

## 二、研究问题（Research Questions）

本研究要回答 5 个核心问题：

### RQ1：除了俄罗斯，还有哪些国家/地区有成熟的"中学数学讨论班/数学圈"传统？
- 候选：美国（Math Circles）、匈牙利、保加利亚、罗马尼亚、英国、法国、日本、新加坡、中国台湾、中国香港
- 产出：`01_到`~ `06_` 各国/地区专题文件

### RQ2：这些数学圈在**组织形式**上有哪些共同点与差异？
- 维度：主持人身份、频率规模、招生方式、场地、费用、退出机制
- 产出：`07_横向对比.md`

### RQ3：它们在**教学内容与方法**上各有什么特色？
- 维度：题目来源、主题选择、是否分层、是否鼓励多解、是否做"推广"
- 产出：`07_横向对比.md`

### RQ4：**中国本土**有哪些已存在的、可对标"数学圈"的实践？
- 候选：民间数学圈（如"数学文化"读书会）、中学"数学兴趣小组"、高校"少年班"/"英才计划"、线上社区（ AoPS 中文用户、B 站数学 up 主）
- 产出：`06_中国本土实践.md`

### RQ5：从全球经验中，哪些要素**最值得**回龙观数学圈借鉴？
- 产出：`08_回龙观本土化借鉴.md`（最终落地文件）

## 三、研究方法（Methodology）

### 方法 1：**三角验证的资料收集**
每个国家/地区至少从 3 类来源交叉验证：
1. **一手资料**：官方章程、教材、官网
2. **二手资料**：学术论文、教育学期刊的 case study
3. **参与者叙述**：回忆录、采访、博客、Reddit/Math Stack Exchange 讨论

> 凡只有单一来源的"传说"，明确标注 `[未证实]`。

### 方法 2：**统一的对比框架**
所有专题文件遵循同一套小标题结构，便于横向对比：

```
## 一、历史与起源
## 二、组织形式（主持人/频率/规模/招生/场地/费用）
## 三、教学内容与方法
## 四、关键机构与代表人物
## 五、经典教材与题库
## 六、与莫斯科模式的异同
## 七、对回龙观的启示（至少 3 条）
## 八、参考资料链接
```

### 方法 3：**"可迁移性"过滤器**
对每个发现，追问一句：**"这件事在回龙观社区层面（家长主持、6-10人、免费/AA制、每周90分钟）能不能做？"**
- ✅ 能 → 进入 `08_回龙观本土化借鉴.md`
- ❌ 不能（如"需要大学教授主持"）→ 仅作背景知识，不进入落地清单

### 方法 4：**区分"竞赛轨道"与"数学圈轨道"**
很多国家数学圈与奥赛集训深度绑定。本研究**重点关注"非应试、研究导向"的部分**，应试部分仅作背景。

## 七、关键约束（Scope Limits）

为避免范围蔓延，**本研究不做**：
1. ❌ **不做"哪个国家数学教育最好"的排名**——这无意义且政治敏感。
2. ❌ **不深入大学阶段讨论班**——moscow 目录已覆盖，本研究聚焦**中学/课外**。
3. ❌ **不收集纯奥赛题库**——除非该题库明确服务于"研究性讨论"而非应试。
4. ❌ **不评价各国政治/教育体制**——只看"可迁移的方法"。
