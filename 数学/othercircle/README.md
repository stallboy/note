## 一、为什么有这个目录

`../moscow/实践方案_回龙观数学圈/` 已基于莫斯科模式给出完整实践方案。但直接照搬单一模式有文化错位、制度错位、样本单一致三大风险。

本目录负责补全**全球其他地区 + 中国本土**的对照资料，目标是让回龙观数学圈从"借鉴莫斯科"升级为"**借鉴全球 + 莫斯科为骨 + 中国本土为根**"。

详见 [00_方法论与计划.md](./00_方法论与计划.md)。

## 六、回龙观的 3 大独特优势（全球少见）

基于本研究，回龙观有 **3 个全球少见的独特优势**：

| 优势 | 说明 |
|------|------|
| ⭐⭐⭐ **1+3 学生的时间红利** | 免中考，4 年贯通时间——俄罗斯 AESC MSU 学生才有的奢侈 |
| ⭐⭐⭐ **双减后的政策窗口** | 2021 双减压缩商业培训，回龙观"非商业、AA 制、社区公益"完全契合 |
| ⭐⭐ **北京的高校密度** | 北大、清华、北师大、首师大（单墫、李毓佩所在）、中科院 |

> **结论**：回龙观**不是"勉强做一个数学圈"，而是"站在天时地利人和的最佳位置做数学圈"**。
