# 全球线上数学社区与平台（数字时代的"虚拟数学圈"）

> 线下数学圈之外，**线上社区**是现代中学生接触"研究性数学"的核心渠道。它们构成了一个**异步的、跨时区的、自选难度的全球数学圈**。对回龙观而言：线上平台既是**题目来源**，也是**学生课外加油站**，更是**弥补线下不足的补充**。
>
> 整理时间：2026-06-22

---

## 一、Art of Problem Solving (AoPS) ⭐⭐⭐

### 1.1 起源
- **创始人**：**Richard Rusczyk**（美国 IMO 1994 队员）
- **创办**：**2003 年**
- **起源**：Rusczyk 邀请两位 Math Olympiad Summer Program（MOSP）的好友（Sandor Lehoczky 等）一起，从做数学竞赛书起步
- 官网：https://artofproblemsolving.com/

### 1.2 AoPS 的四大支柱

| 支柱 | 说明 |
|------|------|
| **AoPS Online（在线课程）** | 从 MATHCOUNTS 到 USAMO 各水平的付费在线课程 |
| **AoPS 社区论坛** | 全球最大的数学解题社区，分版块（高中数学、奥数、竞赛、闲聊） |
| **AoPS Wiki** | 用户共建的竞赛题库，AMC/AIME/USAMO/IMO 题目+解答全集 |
| **Alcumus** | **免费**的自适应学习系统，按难度递进 |

### 1.3 AoPS 书籍
- 《Volume 1》《Volume 2》（与 Lehoczky 合著）——AMC/AIME 入门经典
- 《Intermediate Algebra》《Precalculus》等系统教材
- 《Introduction to Number Theory》《Introduction to Geometry》——各分册入门

### 1.4 AoPS 作为"虚拟数学圈"的特征
- ⭐ **多解讨论**：每道竞赛题下常有 5–20 种不同解法
- ⭐ **追问文化**：新人问"为什么这步成立？"，老用户解释
- ⭐ **声望系统**（积分/徽章）：激励机制
- ⭐ **社区批改**：用户互评解答
- **异步讨论**：跨越时区
- **难度自选**：从初中到研究生都有

### 1.5 对中国学生的可及性
- ⭐ **英文为主**——对初二学生有一定门槛，但数学语言是通用的
- AoPS Wiki 的题目（AMC/AIME）大量有中文解析（B 站、知乎）
- 国内访问需注意网络

## 二、Brilliant.org ⭐⭐

### 2.1 起源
- **创办**：**2012 年**
- 官网：https://brilliant.org/
- 总部：旧金山

### 2.2 模式
- **互动课程**：不是看视频，而是**每堂课中做题**
- **每周 problem sets**
- **引导式解题**：一步一题，错了有提示
- 覆盖：**数学 + 科学 + 计算机科学 + 数据科学**
- **与竞赛关系较弱**，更偏科普/启发

### 2.3 付费模式（⭐ 教师免费是重大利好）

| 层级 | 内容 |
|------|------|
| **免费层** | 核心课程 + 每日限额 |
| **Premium** | 全部 40+ 课程无限制 + AI 导师，约 $13/月（年付） |
| **⭐ Brilliant for Educators** | **K-12 教师和学生完全免费** |

> **对回龙观的重大利好**：主持人（即便只是家长身份）可以**以"教育者"身份申请免费 Premium**，整个数学圈共享一个账号。官方申请页：https://brilliant.org/help/for-educators/

### 2.4 适合中学生
- 逻辑、概率、几何的可视化讲解
- **比 AoPS 更亲民，比 Khan Academy 更进阶**
- ⭐ **对回龙观的启示**：可作为推荐给学生的"每日一题"App

## 三、Project Euler ⭐⭐

### 3.1 起源
- **创始人**：**Colin Hughes**（英国，网名 "euler"）
- **创办**：**2001 年 10 月 5 日**
- **命名**：纪念欧拉（Leonhard Euler）
- 官网：https://projecteuler.net/

### 3.2 模式
- **数学 + 编程**混合问题
- **难度递增**：从最简单的（如"3 或 5 的倍数求和"）到极难的研究级问题
- **已有 1000+ 道题**
- **独特规则**：**解出后才能看讨论区**——形成"解题后讨论"文化

### 3.3 对中学生的适用性
- 需要编程基础（Python 即可）
- ⭐ **对回龙观的启示**：对**对编程也感兴趣**的学生，是"数学+CS"双修的好去处
- 中国学生可用：网络稳定，英文题目清晰

## 四、Math Stack Exchange / MathOverflow

### 4.1 Math Stack Exchange
- 官网：https://math.stackexchange.com/
- 从中学到研究生水平的问答社区
- "问答即讨论"模式
- **声望系统**（reputation）：决定权限

### 4.2 MathOverflow
- 官网：https://mathoverflow.net/
- 职业数学家的社区
- 对中学生过于专业，但其"开放问题"氛围值得了解
- 中学生可读，但多数问题看不懂

### 4.3 适合中学生的使用方式
- 筛选标签（如 `elementary-number-theory`、`recreational-mathematics`）
- 看别人如何**严谨地**表述和证明
- ⭐ **对回龙观的启示**：可作为高水平学生的"延伸阅读"

---

## 五、Khan Academy / Coursera / edX

### 5.1 Khan Academy
- 官网：https://www.khanacademy.org/
- 从小学到大学的数学课程体系
- **免费**
- 视频 + 练习 + 自适应
- **适合**：知识点补漏、系统学习
- **不适合**：研究性数学（偏向教学而非探讨）

### 5.2 Coursera / edX 上的数学 MOOC
- **Keith Devlin《Introduction to Mathematical Thinking》**（Coursera，斯坦福）
- **MIT 18.01/18.02 微积分**（edX）
- 适合高水平中学生（如 1+3 学生）

## 六、YouTube 数学频道 ⭐⭐⭐

### 6.1 3Blue1Brown（Grant Sanderson）
- 官网：https://www.3blue1brown.com/
- YouTube：https://www.youtube.com/c/3blue1brown
- **可视化数学**的巅峰
- 经典系列：**线性代数的本质（Essence of Linear Algebra）、微积分的本质、神经网络**
- ⭐ **对回龙观的启示**：可推荐给所有学生，特别是"线性代数本质"——彻底改变孩子对矩阵的理解

### 6.2 Numberphile
- YouTube：https://www.youtube.com/numberphile
- Brady Haran 制作
- 邀请各类数学家讲一个数学话题
- **趣味性强**，适合激发兴趣
- 与 3Blue1Brown 有合作

### 6.3 Mathologer
- 澳大利亚数学家
- 深入浅出讲数学难题
- 难度比 Numberphile 高

### 6.4 Eddie Woo
- 澳大利亚中学数学老师
- 把**自己的课堂录下来**，免费分享
- ⭐ **对回龙观的启示**：Eddie Woo 模式证明"**中学老师也能做出顶级数学内容**"——这与回龙观家长主持的定位契合

### 6.5 MindYourDecisions（Presh Talwalkar）
- 趣味数学谜题
- 难度适中，适合中学生

### 6.6 Math Antics
- 动画讲解，适合初中基础概念

## 七、中文线上数学社区 ⭐⭐⭐（对回龙观最直接可用）

### 7.1 B站（哔哩哔哩）数学 up 主
B 站已成为中文世界最大的数学内容平台。代表性的数学 up 主包括（数据随时间变化，仅作参考）：

| up 主 | 粉丝规模 | 方向 | 适合人群 |
|--------|---------|------|---------|
| **3Blue1Brown（B站官方）** | 130 万+ | 可视化数学（线性代数/微积分/神经网络本质） | 全体，极高 |
| **一数** | 1100 万+（2023 单年涨粉 526.8 万，"数学博主 TOP1"） | 初中+高中数学，从基础到拔高 | **初二学生首选** |
| **宋浩老师官方** | 739 万+（山东财经大学副教授） | 高等数学/考研数学 | 高中-大学 |
| **乐乐课堂** | 近百万 | 小学+初中全科微课，动画形式 | 初中微课，高 |
| **数学微课帮** | 较高人气 | 初中+高中专题复习，配文本 | 初中，高 |
| **马同学图解数学** | 约 15 万 | 高等数学科普，"数形结合" | 高水平中学生，中 |
| **漫士沉思录** | 百万级 | 数学思维科普 | 中 |
| **赵礼显数学** | 约 257 万 | 高中数学 | 高中 |

> ⚠️ **特别澄清**：用户背景曾提到"老石"——B 站知名的"老石"是 **"老石谈芯"**（[space.bilibili.com/612932327](https://space.bilibili.com/612932327/)），内容方向是**芯片/硬件科普**，**并非中学数学方向**。可能是记忆混淆。
>
> ⚠️ **提醒**：B 站内容质量参差不齐，需主持人/家长甄别推荐。对初二学生，**一数** + **乐乐课堂** + **3Blue1Brown（B 站官方）** 是最稳妥的三件套。

### 7.2 知乎数学话题
- https://www.zhihu.com/topic/19550909
- 大量数学问题讨论、教材推荐、学习经验
- **优点**：中文、互动、有深度回答
- **缺点**：信息碎片化、需筛选

### 7.3 微信公众号
代表性数学类公众号：
- **数学文化**：数学史、数学家
- **和乐数学**：数学科普、新闻
- **好玩的数学**：趣味数学、数学游戏
- **算法与数学之美**：数学+算法
- **普林斯顿读书汇**（数学分部）

### 7.4 数学中国、奥数网等社区
- **奥数网**（aoshu.com）：竞赛资讯、题库
- **数学中国**（madio.net）：数学论坛
- **小学/初中数学社区**：多为家长聚集地

### 7.5 小红书 / 抖音
- **小红书**：大量"数学笔记"、学习方法分享（适合寻找思路）
- **抖音**：短节数学科普，碎片化

## 八、线上社区作为"虚拟数学圈"的特征

| 特征 | 说明 |
|------|------|
| **多解讨论** | 每题下多种解法（AoPS 最强） |
| **异步讨论** | 跨越时区，按需参与 |
| **难度自选** | 从入门到研究级 |
| **社区批改** | 用户互评 |
| **认可机制** | 积分、徽章、声望 |
| **匿名性** | 保护隐私，鼓励发言 |
| **全球性** | 与全世界同龄人讨论 |

### 与线下数学圈的互补
| 维度 | 线下数学圈 | 线上社区 |
|------|-----------|---------|
| **互动** | 同步、面对面 | 异步、文字/视频 |
| **氛围** | 共同体、归属感 | 个人、匿名 |
| **深度** | 一道题讨论透 | 题量大、覆盖广 |
| **导师** | 有引导者 | 自主探索 |
| **适合** | 培养习惯与共同体 | 拓展视野与补充 |

## 九、对回龙观的启示（5 条）

### 启示 1：⭐⭐⭐ 推荐学生使用 **AoPS Wiki** 作为**竞赛题库**
- AoPS Wiki 收录 AMC/AIME/USAMO/IMO 全部题目，附多解
- 比任何中文题库都全、都新
- 英文门槛可通过数学符号化解

### 启示 2：⭐⭐⭐ 推荐学生看 **3Blue1Brown**
- "线性代数的本质"、"微积分的本质"系列
- 适合 1+3 学生（已免中考，可学超纲）
- 可作为每月"必看视频"

### 启示 3：⭐⭐ 建立"**回龙观数学圈线上延伸**"
- 微信群打卡：每天分享一道题或一个想法
- **共享 Notion / 腾讯文档题库**：累积每周问题单
- 公众号或视频号：定期发布"本月问题专栏"（呼应 02_东欧篇 启示 1）

### 启示 4：⭐⭐ 用 **Brilliant / Khan Academy** 应对**学生水平分化**
- 水平较低的学生：Khan Academy 补基础
- 水平中等的学生：Brilliant 做每日一题
- 水平高的学生：AoPS 论坛、Project Euler

### 启示 5：⭐ 谨慎使用 B 站、小红书——**需主持人甄别**
- 中文内容质量参差
- 主持人/家长先行筛选，每月推荐 2–3 个高质量视频/账号
