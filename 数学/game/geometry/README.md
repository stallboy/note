# 从变换的角度看几何

> 一句话概括这门课的精神：**几何，研究的是图形在"运动"下"什么不变"。**
> 说得更准确些——**每一种几何，都对应一种"允许的运动"（变换群）；这门几何关心的性质，就是那些在该变换下不变的东西（不变量）。**

---

## 这门课讲什么

传统中学几何是**静态**的：给你一个三角形，问它的角、边、面积、中线交点……研究对象是"摆在那里不动的图形本身"。

而"变换几何"换了一副**眼镜**：它不再死盯着一个图形，而是问——

> 如果我把这个图形**移动**、**旋转**、**镜像翻转**、**拉伸**、**斜切**、甚至从某个点**投影**出去……图形的哪些性质**保留下来**了，哪些**消失**了？

这一问，问出了几何学的灵魂。它最终在 1872 年由一位 23 岁的年轻人**费利克斯·克莱因（Felix Klein）**总结成一句革命性的宣言（史称"**爱尔兰根纲领**"）：

> **几何学 = 变换群 + 该群的不变量。**

不同的变换群，对应不同的几何。于是，欧氏几何、相似几何、仿射几何、射影几何、拓扑，看似各说各话的几门学科，被收进**同一个框架**，并排成一个漂亮的"层级"。这就是现代数学眼中的几何全貌。

---

## 为什么值得学

1. **它把"碎片"串成"地图"。** 中学里零散学过的全等、相似、对称、位似、平行投影，在变换的眼光下，全是同一棵树上的枝叶。
2. **它教一种强大的思维方式——"找不变量"。** 这是一种超越几何的通用智慧：面对一个变化的系统，盯住那个"守恒"的量。它在物理（守恒律）、代数（不变量理论）、信息（不变性）里一再重现。
3. **它通向现代数学的腹地。** 群、对称、不变量、流形——这些概念正是 19–20 世纪数学的语言，而它们的几何起源，就是这里。
4. **它直通物理学。** 相对论的核心"对称性决定物理定律"、诺特定理"对称 ↔ 守恒"，其数学骨架正是变换群与不变量。

## 给读者的话

- **前置知识**：会平面直角坐标系、基本三角、复数初步。需要群论的地方会现讲，不强求先学。
- **每个概念都配例子**，而且尽量选**能动手算一遍**的——数学不是看会的，是算会的。
- 符号约定：变换用粗体字母（如 $\mathbf{T}$），复合按"右起作用"读，即 $\mathbf{S}\mathbf{T}(P)$ 表示先 $\mathbf{T}$ 后 $\mathbf{S}$。
