从变换看几何

换一副眼镜：不再静态地盯着图形，而问——
当图形被移动、旋转、翻转、拉伸、投影时，什么留了下来？

$\text{几何学} \;=\; \text{变换群} \;+\; \text{该群的不变量}$
开始阅读 → 查看路线
一句话精神 传统中学几何是静态的：研究"摆在那里不动的图形本身"。
而变换几何问的是——图形在运动下，什么不变。
每一种几何，都对应一种"允许的运动"；这门几何关心的，就是那些在变换下幸存的性质。

全等、相似、对称、位似、平行投影——中学里零散的知识，在变换的眼光下全是同一棵树上的枝叶。

"找不变量"的智慧

面对变化的系统，盯住那个"守恒"的量。这种思维在物理守恒律、代数不变量、信息不变性里一再重现。

🌌

通向现代数学腹地

群、对称、不变量、流形——这些 19–20 世纪数学的语言，其几何起源正是这里。

⚛️

直通物理学

相对论的"对称性决定定律"、诺特定理的"对称 ↔ 守恒"，数学骨架就是变换群与不变量。

🎯前置与约定
  • 前置知识：会平面直角坐标系、基本三角、复数初步。需要群论的地方会现讲，不强求先学。
  • 每个概念都配例子，而且尽量选能动手算一遍的——数学不是看会的，是算会的。
  • 符号约定：变换用粗体字母（如 $\mathbf{T}$），复合按"右起作用"读，即 $\mathbf{S}\mathbf{T}(P)$ 表示先 $\mathbf{T}$ 后 $\mathbf{S}$。
  • 关于证明：每一条重要定理都会给出能跟进、可手算验证的证明。看不懂证明的结论只是别人的话；看懂了，才是你自己的几何。

💡 这套课件不只是文字——每一章都嵌有可动手的交互演示：拖动镜子看反射合成旋转、滑动矩阵看圆变椭圆、拖动点算交比、转正多边形看对称群……让"变换"真正动起来。
