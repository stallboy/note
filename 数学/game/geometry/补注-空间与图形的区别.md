# 补注 · 别把"图形"当成"集合":空间 vs 图形

> 这是第 1 章 1.4 节(Erlangen 纲领)的一个澄清。
> 起因的疑问:**"全等几何里,集合(空间)到底是圆,还是全平面?如果取全平面,全等又怎么定义?"**

## 核心澄清:圆不是"集合",圆是集合里的一个图形

在 Erlangen 纲领的三件套里——**集合(空间) $M$ + 变换群 $G$ + 不变量**——最容易混的一个点是:

> **"集合" $M$ 是图形居住的那片地;而圆、三角形这些东西,是这片地上的图形——也就是 $M$ 的子集。**

所以那个疑问的答案,其实已经藏在问题本身里:

**全等几何的集合,本来就是整个平面 $\mathbb{R}^2$(全平面的点),根本不是"圆上的点"。圆只是平面里的一个图形。**

把"被研究的图形"误当成"空间(集合)",是这个框架里唯一的别扭来源。

## 全等几何的三件套,明确写出来

| 角色 | 全等几何(欧氏等距几何)里到底是什么 |
|---|---|
| 集合(空间) $M$ | 整个平面 $\mathbb{R}^2$ = 全体点 $(x,y)$ |
| 变换群 $G$ | 等距变换群 $E(2)$:每个 $g:\mathbb{R}^2\to\mathbb{R}^2$ 是**保距双射**(平移、旋转、反射及其复合) |
| 不变量 | 距离、角度、面积、平行、垂直…… |
| 图形 $A,B$ 全等 | $\exists\, g\in E(2),\ g(A)=B$ |

注意 $g$ 是定义在**整个平面每一个点**上的——它把 $\mathbb{R}^2$ 整个搬一下。圆 $A$ 是 $\mathbb{R}^2$ 的子集,$g$ 把整个平面变了,自然把 $A$ 也变成另一个子集 $g(A)$。

## "全等"是图形之间的关系,不是图形本身的属性

这是第二个要拧过来的弯。欧几里得说"能重合",克莱因把它精确化为一个**等价关系**:

$$A \cong B \quad\Longleftrightarrow\quad \exists\, g\in G,\ \text{使得 } g(A)=B$$

- "全等"是**两个图形之间**的关系,不是一个图形的内在属性。
- 它把"所有平面图形"切成等价类,每一类就是"同一种图形"。全等几何就是研究这些等价类的不变量。

### 用手算验证:两个圆何时全等

圆 $C_1$(圆心 $O_1$,半径 $r_1$)与圆 $C_2$(圆心 $O_2$,半径 $r_2$):

- 若 $r_1=r_2$:取平移 $g(x)=x+(O_2-O_1)$,它把 $O_1$ 搬到 $O_2$,所以 $g(C_1)=C_2$。✓ 全等。
- 若 $r_1\ne r_2$:任何等距变换都保距,圆上点到圆心的距离 $=r_1$ 不变,所以像圆半径还是 $r_1\ne r_2$,不可能等于 $C_2$。✗ 不全等。

$$\boxed{\,C_1\cong C_2 \iff r_1=r_2\,}$$

整个过程里:**集合是整个平面,圆是平面里的子集,联系它们的是作用在整个平面上的等距变换**。

## 反过来:如果集合真取"圆上的点"会怎样?

这正是 1.4 节说的"换一片地,就长出一门新几何"。若硬把集合取成 $M=S^1$(单位圆周,圆上的点):

- 只能研究圆周**上**的点。
- 作用在 $S^1$ 上、还保距(弧长)的变换,只剩**绕圆心旋转**和**关于直径的反射**,群退化成 $O(2)$。
- 这是一门**完全不同的几何**——一维的圆周几何,"距离"是弧长。它**不是**平面的全等几何,因为它容不下"把一个三角形搬到别处"这种事(三角形不躺在圆周上)。

所以"集合取圆周"不是全等几何的另一种定义,而是**另起炉灶的另一门几何**。

## 为什么全等几何必须取全平面?

一句话:**变换群要能作用,空间就得装得下它。**

等距变换群 $E(2)$ 的每个元素都是 $\mathbb{R}^2\to\mathbb{R}^2$ 的整体双射——它需要**平面上每一个点**都有定义、都有去处。如果把空间砍成只剩圆周,$E(2)$ 里绝大部分元素(任意平移、关于任意直线的反射)在圆周上根本不是自映射,群就散了。

> **群决定空间能取多大,空间反过来限制群能留多少。**
> 这正是第 7 章要系统展开的"换地、换群"的张力。

## 一句话收尾

> **全等几何里,集合 = 整个平面 $\mathbb{R}^2$;圆 / 三角形 / 线段 = 平面的子集(图形);"全等" = 存在一个全平面的等距变换把一个图形映成另一个。**

把"空间"和"图形"这两层分清,Erlangen 纲领就再没有别扭的地方了。
