# 高斯与正十七边形（初高中生课件）

> 一份面向**初高中生**的讲义。我们不教"怎么画出正十七边形"，而是讲清楚一件更迷人的事：**一个 19 岁的年轻人，是怎么在脑子里把一个困住人类两千年的几何难题，变成了一道代数题，然后解开的。**

本课件把重点放在**思想**：高斯受了谁的启发、他做了哪几个关键跳跃、他发明的"周期法"到底是什么。所有需要的前置知识（复数、单位根、模运算、原根、欧拉函数）都在正文中从头讲起，并配大量例子。

---

## 你将学到什么（学习目标）

读完本课件，你应该能够：

1. 说清楚"用直尺圆规作正 $n$ 边形"这件事，**本质上等于**"用有限次开平方求出 $\cos\dfrac{2\pi}{n}$"；
2. 理解**单位根**、**模运算**、**欧拉函数 $\varphi(n)$**、**原根**、**费马素数**这些概念，并会做小例子；
3. 跟着正十七边形的例子，看懂高斯的**周期法**——如何把一个 16 次方程，拆成一串二次方程；
4. 复述高斯的**思想路径**：他受了哪些前人的启发，做出了哪几个关键跳跃；
5. 知道 **Gauss–Wantzel 定理**的内容，并理解为什么正 7 边形不能作、正 17 边形能作。

## 你需要的基础

- **初中代数**：会解一元二次方程、会用求根公式、知道 $\sqrt{\ }$（开平方）。
- **一点点几何**：勾股定理、单位圆、三角函数的初步（$\sin,\cos$ 是什么）。
- **复数**：知道 $i^2=-1$ 即可；复数的几何意义我们在第 2 章里讲。
- **模运算**（"时钟算术"）：第 2 章从头讲。

不需要会微积分，不需要学过群论或抽象代数——所有高级概念都会用初等语言重新讲一遍。

## 一个 30 秒的预告

$$\cos\frac{2\pi}{17}=\frac{1}{16}\!\left(\sqrt{17}-1+\sqrt{34-2\sqrt{17}}\right)+\frac{1}{8}\sqrt{17+3\sqrt{17}-\sqrt{34-2\sqrt{17}}-2\sqrt{34+2\sqrt{17}}}$$

这个看起来吓人的式子，**只用了加减乘除和开平方**。而"只用到开平方"，恰好就是"直尺圆规能画出来"的代数翻译。整份课件，就是讲清楚：**高斯是怎么找到它的，以及为什么他一定能找到它。**
