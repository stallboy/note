# 拉格朗日《关于代数方程解的思考》导读

> 给初高中生的备课讲义。我们把 18 世纪数学家拉格朗日（Joseph-Louis Lagrange）一篇开创性的论文，用现代语言重新讲一遍——看他是如何**用一个统一的想法（根的置换）**，解释清楚"为什么二次、三次、四次方程有求根公式，而五次没有"。

## 这篇论文是什么

1770–1771 年，意大利裔法国数学家拉格朗日在柏林科学院院刊上分两次发表了一篇长文：

> **《关于代数方程解的思考》（Réflexions sur la résolution algébrique des équations）**

它没有解出任何新方程，却做了一件更要紧的事：**回头审视**两千年来解方程的种种技巧（二次的"配平方"、三次的卡尔达诺公式、四次的费拉里方法），发现它们表面千差万别，背后却藏着同一个原理——**根的置换（permutation）**。

这篇论文是**群论和伽罗瓦理论的真正起点**。半个多世纪后，阿贝尔（Abel）证明五次方程没有普遍的求根公式，伽罗瓦（Galois）用"群"彻底讲清楚"方程能不能解"——他们的脚下，都是拉格朗日铺的路。

## 记号约定

- 方程的根记作 $x_1,x_2,\dots,x_n$。
- $\omega$ 表示 3 次单位原根 $\omega=e^{2\pi i/3}$，满足 $\omega^3=1$、$1+\omega+\omega^2=0$。（不熟的话，[正十七边形讲义第 2 章](../正十七边形/02-预备知识-复数-单位根-模运算.md) 有详细介绍。）
- "置换"= 把根重新排列，比如 $(x_1,x_2,x_3)\to(x_2,x_3,x_1)$。
