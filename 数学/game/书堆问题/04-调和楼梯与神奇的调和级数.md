# 第 4 章 · 调和楼梯与神奇的调和级数

上一章我们发现了一个规律：第 $k$ 本书多伸 $\dfrac{1}{2k}$，总悬伸
$$d_n=\frac12\!\left(1+\frac12+\frac13+\cdots+\frac1n\right).$$

括号里的 $1+\dfrac12+\dfrac13+\cdots+\dfrac1n$ 是一个非常重要的数学对象，叫**调和级数**（的前 $n$ 项和）。本章专门认识它，并回答那个最惊人的问题：**书堆能伸出无穷远吗？**

---

## 4.1 调和级数长什么样

定义**调和数** $H_n$：
$$H_n=1+\frac12+\frac13+\frac14+\cdots+\frac1n.$$

于是书堆的最大悬伸
$$\boxed{d_n=\frac{1}{2}H_n.}$$

前几个 $H_n$：

| $n$ | $H_n$ | $d_n=\frac12 H_n$ |
| :-: | :-: | :-: |
| 1 | 1 | 0.5 |
| 2 | 1.5 | 0.75 |
| 3 | 1.833… | 0.917 |
| 4 | 2.083… | 1.04 |
| 5 | 2.283… | 1.14 |
| 10 | 2.929… | 1.46 |
| 100 | 5.187… | 2.59 |
| 1000 | 7.485… | 3.74 |

> 💡 注意 $d_n$ 的增长：从 $n=10$ 到 $n=100$（书多了 10 倍），$d_n$ 只从 1.46 涨到 2.59（涨了 1.13）。**书数翻 10 倍，悬伸才增加 1 出头**——慢得离谱。

---

## 4.2 最惊人的事实：调和级数"发散"（能加到无穷大）

每一项 $\dfrac1n$ 都在**变小**：$\dfrac11,\dfrac12,\dfrac13,\dots$ 越加越小，到最后 $\dfrac1{1000},\dfrac1{1000000}$ 小得可怜。

一个很自然的猜测是：**把无穷多个越来越小的数加起来，会不会等于一个有限的数？**

比如 $\dfrac12+\dfrac14+\dfrac18+\dfrac1{16}+\cdots=1$（每次减半，加起来刚好是 1，有限）。

但调和级数**不一样**——它会**一直涨到无穷大**！这叫**发散**。

### 证明：为什么发散？（漂亮的分组法）

这是数学史上最巧妙的证明之一，由 14 世纪法国数学家**奥雷姆（Nicole Oresme）**给出。我们把级数这样**分组**：

$$\underbrace{1}_{\ge 1/2}+\underbrace{\frac12}_{\ge 1/2}+\underbrace{\left(\frac13+\frac14\right)}_{\ge 1/2}+\underbrace{\left(\frac15+\frac16+\frac17+\frac18\right)}_{\ge 1/2}+\cdots$$

逐组检查：

- 第 1 组：$1\ge\dfrac12$ ✓
- 第 2 组：$\dfrac12\ge\dfrac12$ ✓
- 第 3 组：$\dfrac13+\dfrac14$。因为 $\dfrac13>\dfrac14$，所以 $\dfrac13+\dfrac14>\dfrac14+\dfrac14=\dfrac12$ ✓
- 第 4 组：$\dfrac15+\dfrac16+\dfrac17+\dfrac18$。这 4 项每一项都 $\ge\dfrac18$，所以和 $\ge4\times\dfrac18=\dfrac12$ ✓
- 第 5 组：接下来 8 项 $\left(\dfrac19+\cdots+\dfrac1{16}\right)$，每项 $\ge\dfrac1{16}$，和 $\ge8\times\dfrac1{16}=\dfrac12$ ✓
- ……每组都是 **2 倍多项**，每项都不小于组里最小的那项，加起来 $\ge\dfrac12$。

**结论**：级数可以分成无穷多组，**每一组都 $\ge\dfrac12$**。无穷多个 $\dfrac12$ 加起来，当然是**无穷大**！

$$\boxed{H_n\to\infty\quad(n\to\infty).\ \text{所以}\ d_n=\frac12 H_n\to\infty.}$$

🎉 **这意味着：只要书足够多，书堆能伸出任意远！** 理论上，你可以用书堆"搭一座桥"伸到桌子对面、伸过一条河、伸到任意远的距离。

> 🤔 **想一想**：每一项 $\dfrac1n$ 都趋向 0，可加起来却是无穷大。这违反直觉吗？奥雷姆的证明告诉我们：**"趋向 0"不等于"加起来有限"**。调和级数是"趋向 0 趋得不够快"的典型例子。

---

## 4.3 但它增长得慢得令人发指

虽然 $H_n$ 能到无穷大，但它涨得**极其慢**。精确地说（这是高中的"对数"知识，不懂可跳过公式看例子）：
$$H_n\approx \ln n+\gamma,$$
其中 $\ln$ 是自然对数，$\gamma\approx0.577$ 是**欧拉–马歇罗尼常数**。

不懂对数没关系，只要记住这个意思：**$H_n$ 要增加 1，$n$ 大致要乘以 $2.7$**（约等于 $e$）。所以：

| 要让悬伸达到 | 大约需要 |
| :-: | :-: |
| 1 本书长 | 4 本 |
| 2 本书长 | 31 本 |
| 3 本书长 | **227 本** |
| 4 本书长 | **1674 本** |
| 5 本书长 | 12367 本 |
| 6 本书长 | 91380 本 |
| 10 本书长 | 约 **2.7 亿本**！ |

> 💡 从 3 倍（227 本）到 4 倍（1674 本），书数翻了 **7 倍多**，悬伸才多了 1 本的长度。这种"投入爆炸、产出可怜"的增长，就是对数增长的特色。

---

## 4.4 一个经典应用：一副扑克牌

一副扑克牌 52 张。最底下那张不动，上面 51 张按调和楼梯错开。总悬伸
$$d_{52}=\frac12 H_{52}\approx\frac12\times 4.538\approx 2.269\ \text{张牌长}.$$

也就是说，**一副扑克牌能伸出超过两张牌的长度**！这正是第 1 章那个实验的数学解释。

🧪 **动手做**：拿一副扑克牌试试。要完全精确地按 $\dfrac1{2k}$ 错开很难（第 51 张只错开 $\dfrac1{102}$ 张牌长，肉眼几乎看不出），所以实际效果会比理论略小，但伸出两倍牌长是完全可见的。

---

## 4.5 把"调和楼梯"画出来

如果我们把每一本书的右沿位置标出来，它们会形成一条**阶梯**，每一级比上一级窄：

```
第1本右沿 ─────────────────────────────┐  伸出最远（累计 1/2·H_n）
第2本右沿 ───────────────────────┐     │  差 1/4
第3本右沿 ─────────────────┐     │     │  差 1/6
第4本右沿 ───────────┐     │     │     │  差 1/8
   …            …     │     │     │     │
第n本右沿 ──┐         │     │     │     │  差 1/(2n)
桌沿 ───────┴─────────┴─────┴─────┴─────┘
            ←1/(2n)→
```

每一级的宽度 $\dfrac{1}{2k}$ 越来越小，但**永远不为零**，而且它们的和（总悬伸）能无限增长。这条"无限细的楼梯"，就叫**调和楼梯（harmonic staircase）**。

---

## 4.6 一段历史：调和级数的故事

调和级数的"发散"性质，大约在 **1350 年**由法国学者**奥雷姆**首次证明（就是上面那个分组法）。那时连"无穷大"的概念都还很模糊，奥雷姆的工作相当超前。

后来，**欧拉（Euler）**在 18 世纪深入研究 $H_n$，发现了它和 $\ln n$ 的关系，以及那个神秘的常数 $\gamma$（至今我们不知道 $\gamma$ 是不是有理数——这是数学的一个开放问题！）。

> 🤔 调和级数是数学里"反直觉"的经典案例：**每一项都趋向 0，和却是无穷大。** 它提醒我们，直觉有时会骗人，必须靠严格的证明。

---

## 4.7 本章小结

| 命题 | 内容 |
| --- | --- |
| 调和数 | $H_n=1+\dfrac12+\dfrac13+\cdots+\dfrac1n$ |
| 书堆公式 | $d_n=\dfrac12 H_n$ |
| 发散 | $H_n\to\infty$（奥雷姆分组法证明），故 $d_n\to\infty$ |
| 增长慢 | $H_n\approx\ln n+\gamma$，对数级增长 |
| 实例 | 52 张牌≈2.26 牌长；3 倍需 227 本；10 倍需 2.7 亿本 |

> 🔑 **核心张力**：书堆**理论上能伸到无穷远**（因为调和级数发散），但**实际上几乎不可能**（因为增长太慢，加上真实材料的限制）。数学的"无穷"和物理的"现实"在这里形成了迷人的对比——这正是第 7 章要展开的话题。

不过在此之前，我们要把第 3 章的规律**严格证明**——为什么第 $k$ 本恰好伸 $\dfrac{1}{2k}$？

*提示*：$H_{n+1}=H_n+\tfrac{1}{n+1}$。

**题 4.2（对比）几何级数 vs 调和级数**。(a) 证明 $\tfrac12+\tfrac14+\tfrac18+\cdots=1$（设 $S=$ 该和，算 $S-\tfrac12S$）。(b) 用一句话说明：为什么这个级数"加起来有限"，而调和级数却发散？
*提示*：关键是"项变小有多快"。

**题 4.3（应用）集卡问题**。薯片送卡共 6 种，每包随机送 1 种。平均要买多少包才能集齐 6 种？
*提示*：已有 $k$ 种时，下一包是**新**卡的概率 $\tfrac{6-k}{6}$，期望再买 $\tfrac{6}{6-k}$ 包。把 $k=0,\dots,5$ 加起来——这就是"赠券收集问题"，答案里藏着 $H_6$！
