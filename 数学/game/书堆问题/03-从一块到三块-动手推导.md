# 第 3 章 · 从一块到三块：动手推导

> 这一章我们拿起笔，**亲手**算出 1 本、2 本、3 本书最多能伸出多远。工具就是第 2 章的那把万能钥匙：**"把上方子摞的质心，恰好推到下方书的边沿上。"**
>
> 为了简单，全书我们设**书长 $l=1$**（最后再乘回 $l$ 即可）。

---

## 3.1 一本书：$\dfrac{1}{2}$

只有 1 本书。它的质心在书的正中央，离两个边沿各 $\dfrac12$。

把书往桌外推。由稳定性判据（第 2.6 节）：**质心的垂线必须落在桌面（支撑面）上**。临界状态是质心**恰好**在桌沿正上方。

```
           书的中心（质心）
                ●
         ┌──────┴──────┐
─────────┤             │←── 桌沿
         └─────────────┘
桌面─────╯
         ↑
       伸出 1/2
```

所以 1 本书最多伸出 $\dfrac12$：
$$\boxed{d_1=\frac{1}{2}.}$$

> 🤔 多伸一点点行不行？不行——质心垂线一"踩空"，重力立刻把书拧下去。

---

## 3.2 两本书：$\dfrac{3}{4}$

现在有 2 本书：上书 A、下书 B。我们要让**最上面的 A 的右沿**伸出桌沿尽量远。

### 第一步：A 相对 B 错开多少？

A 搁在 B 上。先不管 B 在桌上的位置，只看 A 和 B 的关系。由"上方子摞质心在下方书边沿"原则：

> **A 的质心，应恰好落在 B 的右沿正上方。**

A 的质心在 A 的正中央。所以要让 A 的中心位于 B 的右沿上方，A 的右沿就得比 B 的右沿**多伸出** A 长度的一半：
$$\text{A 伸出 B} = \frac{1}{2}.$$

```
         A 的质心
            ●
      ┌─────┴─────┐          ← A（上书）
      │           │
┌─────┴─────┐     │          ← B（下书），A 比 B 右沿多伸 1/2
│           │     │
└───────────┘     │
            ↑
          B 的右沿（A 的质心在此正上方）
```

### 第二步：A+B 整体质心在哪？

现在把 A、B 一起看。它们质量相同，所以**整体质心在"两者各自质心的中点"**（第 2.8 节）。

- A 的质心：在 B 的右沿正上方（刚算的）。
- B 的质心：在 B 的正中央，即 B 的右沿**左侧** $\dfrac12$ 处。

两者中点 = B 右沿**左侧** $\dfrac14$ 处。

> 💡 **算一下**：A 质心在"B 右沿"位置，B 质心在"B 右沿左 $\dfrac12$"位置。中点 = $\dfrac{0+(-1/2)}{2}=-\dfrac14$，即 B 右沿左 $\dfrac14$。

所以 **(A+B) 的整体质心，在 B 右沿左侧 $\dfrac14$ 处**。

### 第三步：B 能伸出桌面多少？

要让整摞 (A+B) 不翻倒，**整体质心要落在桌沿上（临界）**。整体质心在 B 右沿左侧 $\dfrac14$，所以 **B 的右沿在桌沿右侧 $\dfrac14$**：
$$\text{B 伸出桌面}=\frac{1}{4}.$$

### 第四步：总悬伸

最上面的 A 的右沿 = B 的右沿 + A 多伸的 $\dfrac12$：
$$d_2=\frac{1}{4}+\frac{1}{2}=\frac{3}{4}.$$

$$\boxed{d_2=\frac{3}{4}.}$$

🧪 **动手验证**：拿两本一样的书试试，是不是差不多能伸到 $\dfrac34$（伸出四分之三本书）？

## 3.3 三本书：$\dfrac{11}{12}$

3 本书：A（上）、B（中）、C（下）。我们要让 A 的右沿伸得最远。

### 思路

延续 2 本书的经验：**每一层都"卡到临界"——让上方子摞的质心恰好在下方书的右沿。** 我们来求 C 伸出桌面多少（记作 $d_C$）。

### 用质心公式独立解出每一步

设书长 $l=1$，**C 的右沿在桌沿右侧 $d_C$**（待求）。关键：我们**不假设**错开量，而是设 **B 比 C 右沿多伸 $s$**（$s$ 也待求），再用平衡条件把 $s$ 和 $d_C$ **都解出来**。

（A 相对 B 的错开是确定的：A 单独搁在 B 上，临界时 A 的质心要在 B 的右沿，所以 **A 比 B 多伸 $\dfrac12$**——这步只看 A 自己，与下面无关。）

于是三本书的右沿与质心位置（相对桌沿，质心 = 右沿左 $\dfrac12$）：

| 书 | 右沿位置 | 质心位置 |
| :-: | :-: | :-: |
| C（最底） | $d_C$ | $d_C-\dfrac12$ |
| B（中） | $d_C+s$ | $d_C+s-\dfrac12$ |
| A（顶） | $d_C+s+\dfrac12$ | $d_C+s$ |

**条件①（C 这一层临界）**：上方两本 (A+B) 的整体质心要落在 C 的右沿（再多就翻）。A、B 同质量，(A+B) 质心是 A、B 质心的中点：
$$\frac{(d_C+s)+(d_C+s-\frac12)}{2}=d_C+s-\frac14.$$
令它等于 C 右沿 $d_C$：
$$d_C+s-\frac14=d_C\quad\Longrightarrow\quad\boxed{\ s=\frac14\ }.$$
🎉 **B 比 C 多伸 $\dfrac14$——这是"解"出来的，不是假设的！**

**条件②（整体 3 本临界）**：整体 (A+B+C) 质心要落在桌沿（位置 $0$）。三本同质量，整体质心是三者平均：
$$\frac{(d_C-\frac12)+(d_C+s-\frac12)+(d_C+s)}{3}=\frac{3d_C+2s-1}{3}.$$
代入 $s=\dfrac14$：上式 $=d_C-\dfrac16$。令它 $=0$：
$$d_C-\frac16=0\quad\Longrightarrow\quad\boxed{\ d_C=\frac16\ }.$$
🎉 **C 伸出桌面 $\dfrac16$——也解出来了！** 正好等于 $\dfrac{1}{2\cdot3}$，规律延续。

### 总悬伸

最上面 A 的右沿 = C 右沿 + B 多伸 + A 多伸：
$$d_3=d_C+\frac14+\frac12=\frac16+\frac14+\frac12=\frac{2+3+6}{12}=\frac{11}{12}\approx0.917.$$

$$\boxed{d_3=\frac{1}{2}+\frac{1}{4}+\frac{1}{6}=\frac{11}{12}.}$$

> 💡 注意：$\dfrac{11}{12}\approx0.917$，**还不到 1**！3 本书最多伸出不到一本书长。要到第 4 本，才**首次超过 1**（$d_4=\dfrac{25}{24}\approx1.04$）。

> ✏️ **小验证（三层都临界吗？）**
> - A 的质心 = A 右沿左 $\dfrac12$ = B 右沿（因为 A 比 B 多伸 $\dfrac12$）✓
> - 整体 (A+B) 的质心在 B 右沿左 $\dfrac14$，而我们让 B 右沿 = C 右沿右 $\dfrac14$，于是 (A+B) 质心恰在 C 右沿 ✓
> - 整体 (A+B+C) 质心恰在桌沿 ✓
>
> 三层全部临界，所以这是最优构型。第 5 章会把这套思路推广成一般证明。

## 3.4 规律浮现

把前几个结果列出来：

| $n$ | 第 $n$ 本（最底）多伸出 | 总悬伸 $d_n$ |
| :-: | :-: | :-: |
| 1 | $\dfrac{1}{2}$ | $\dfrac{1}{2}=0.5$ |
| 2 | $\dfrac{1}{4}$ | $\dfrac{1}{2}+\dfrac{1}{4}=\dfrac{3}{4}=0.75$ |
| 3 | $\dfrac{1}{6}$ | $\dfrac{1}{2}+\dfrac{1}{4}+\dfrac{1}{6}=\dfrac{11}{12}\approx0.917$ |
| 4 | $\dfrac{1}{8}$ | $\cdots+\dfrac18=\dfrac{25}{24}\approx1.04$ |
| 5 | $\dfrac{1}{10}$ | $\approx1.14$ |

规律清清楚楚：

> **第 $k$ 本（从顶端数）比下一本多伸 $\dfrac{1}{2k}$。**
> **$n$ 本书总悬伸 $d_n=\dfrac12\!\left(1+\dfrac12+\dfrac13+\cdots+\dfrac1n\right)$。**

那一串 $\dfrac12,\dfrac14,\dfrac16,\dots$ 等价于 $1,\dfrac12,\dfrac13,\dots$ 的一半——这就是大名鼎鼎的**调和级数**。

下一章，我们正式认识它，并揭示一个惊人的事实：**它能把悬伸推到无穷远。**

---

## 3.5 本章小结

- 1 本书：$d_1=\dfrac12$（质心判据的直接应用）。
- 2 本书：$d_2=\dfrac34$（A 伸出 B 半本，B 再伸出桌面 $\dfrac14$）。
- 3 本书：$d_3=\dfrac{11}{12}$（C 伸出桌面 $\dfrac16$）。
- 规律：第 $k$ 本多伸 $\dfrac{1}{2k}$，总悬伸 $d_n=\dfrac12\!\left(1+\dfrac12+\cdots+\dfrac1n\right)$。
- 关键技巧：**"把最优的 $(n-1)$ 本堆，整体搁到第 $n$ 本上"**——这种"递推"思想，是第 5 章归纳法的雏形。

> 🤔 **想一想**：第 3 本为什么多伸 $\dfrac16$，而不是 $\dfrac14$ 或 $\dfrac18$？答案藏在"3 本书的整体质心"里——上面我们用质心公式验证了 $d_C=\dfrac16$。这个"$\dfrac{1}{2k}$"的由来，第 5 章会给一个干净的一般证明。
