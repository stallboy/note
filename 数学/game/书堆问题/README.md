# 书堆问题：能把书伸出桌子多远？（初高中生课件）

> 一份面向**初高中生**的讲义。我们要研究一个看似简单、实则深奥的问题：**把一摞完全相同的书（或积木、扑克牌）叠在桌边，最上面那本能伸出桌沿多远，而不掉下去？**
>
> 答案出乎意料地迷人：理论上**可以伸到无限远**——只要你有足够多的书。这件事的幕后，藏着"质心""杠杆""调和级数"这些重要的数学物理概念。

本课件把重点放在**思想与直觉**：所有需要的前置知识（特别是**质心**和**杠杆**）都从头讲起，配大量生活化的例子。

---

## 你将学到什么（学习目标）

读完本课件，你应该能够：

1. 理解**质心（重心）**的概念，会用"加权平均"算出几个物体的整体质心；
2. 理解**杠杆原理**和**力矩平衡**，并明白"杠杆平衡"与"质心位置"其实是同一件事；
3. 掌握书堆问题的**核心稳定性判据**：一摞物体不翻倒 ⟺ 它的整体质心落在支撑面之内；
4. 推导出经典结论：$n$ 块书最多伸出 $\dfrac{1}{2}\!\left(1+\dfrac12+\dfrac13+\cdots+\dfrac1n\right)$ 个书长；
5. 认识**调和级数**：它**发散**（能加到无穷大），却**增长极慢**；
6. 知道打破"一层一本"限制后，配重能把悬伸推进到 $\Theta(n^{1/3})$。

## 一个 10 秒的预告

假设书长为 1：

| 书的本数 | 最远能伸出（书长） |
| :-: | :-: |
| 1 | 0.5 |
| 2 | 0.75 |
| 3 | ≈0.917 |
| 4 | ≈1.04（**第一次超过一整本书！**） |
| 52（扑克牌） | ≈2.26 |
| 227 | ≈3 |
| 1674 | ≈4 |

看出规律了吗？每多伸出一本书的长度，需要的书数就要**翻几倍**。这背后是著名的**调和级数**——一个"明明能加到无穷大、却慢得令人发指"的数学对象。
