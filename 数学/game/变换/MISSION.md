# Mission: 从变换的角度看几何(严格版,从入门到能教大学)

## Why

用户要把"几何 = 变换群 + 不变量"这句话从**科普口号**升级到**能在大学水平严格讲清楚、可证明、可手算、带习题**的掌握程度。这是为自己学的,不是再写一套科普讲义。

并且要把这套严格机器与**高中数学竞赛几何**打通:用矩阵群/变换的工具解释并解决竞赛题(旋转相似、反演、调和点列、复数法、极点极线),反过来用竞赛真题当每一章的"真实试炼"。会解竞赛题 = 机器玩得转的最硬证据。

唯一已验证的严格地基是**线性代数**(向量空间、线性映射、特征值、行列式、正交/酉群的矩阵推导)。路径的统一杠杆因此是:**把每一种几何重铸为一族矩阵群**——等距 = O(n)、相似 = 标量×O(n)、仿射 = GL(n) ⋉ Rⁿ、射影 = PGL(n+1)。群论与不变量理论顺着这族矩阵群自然长出来,绝不悬空。

## Success looks like

读完整个工作区后,用户能:

- **用群论严格定义**"变换群"与"群作用",并用 GL(n) 及其子群/扩张解释欧氏、相似、仿射、射影、(双曲) 这几门几何为何排成一个塔。
- **逐条证明**每个关键定理:等距 = 至多 n+1 个反射、O(n) 保距的充要条件、仿射保共线比、交比是 PGL 在射影直线上的唯一不变量(自由度计数版)。
- **说清"不变量"的精确含义**:G-不变函数;并把 Klein 纲领写成"几何 = (G, X) 群作用 + 该作用下不变的量"。
- 把这套语言**接到连续情形**:李群、单参数子群、李代数、Killing 场,从而通向诺特定理(对称↔守恒)。
- **站上讲台**:能针对每个主题给出严格讲解、典型误解、可手算例子、分级习题与参考解答。
- **用变换工具解竞赛题**:能把一道竞赛几何题(旋转相似、反演、调和点列)识别成"某矩阵群的某条性质",给出严格解,并向学生讲清"这招为何有效"。

## Path(从入门到 master 的骨架)

> 详细可视化地图见 `reference/curriculum.html`。每完成一课,在 `learning-records/` 记一条。

- **地基重铸**(群与作用,全部用矩阵落地):群公理 → GL(n) → 子群与 O(n) → 群作用 / 轨道 / 稳定化子 / orbit-stabilizer → "不变量"的精确定义。
- **矩阵几何塔**:E(n) 等距与反射生成 → 相似 CO(n) → 仿射 Aff(n) = GL(n) ⋉ Rⁿ → 射影 PGL(n+1) 与齐次坐标、交比、对偶。
- **不变量理论**:不变环、各群的"第一基本定理"概念版;交比为何是唯一射影不变量。
- **连续与李**:李群、单参数群、指数映射、李代数;度量的 Killing 场;狭义相对论的 Lorentz 群。
- **爱尔兰根纲领严格与现代形态**:Klein 几何 (G,X);几何层级;Cartan 几何作为"弯曲的 Klein 几何"的概念入口。
- **通向物理**:Noether 定理(对称↔守恒)的证明思路;规范对称与标准模型的群骨架。
- **教学法**:每个主题配"如何讲 / 常见误解 / 习题与解答"。
- **竞赛联结(平行线)**:矩阵塔的每一站配竞赛金矿——相似→旋转相似(Miquel/共圆)、仿射→仿射秒杀共线与极值、射影→交比与调和点列、反演→反演秒杀、复数法→GL(2,ℂ)、极点极线→对偶。竞赛真题作为该章"真实试炼"习题。

## Constraints

- **唯一严格地基 = 线性代数**。其他工具(群论、轻量分析、李论)在本工作区内**从零严格补**,但始终以矩阵为锚,不先要求抽象代数或流形的前置。
- **详解优先**:核心推导可跟进、可手算、给数值核对(用户一贯偏好)。
- **不参考** `../geometry/` 那套科普讲义:本工作区独立设计,不复用其结构/配色/内容。
- 每课短、可快速完成、给一个明确的小胜;配习题与主源。
- 偏好互动标记:🤔想一想 / ✏️手算 / 💡洞见 / 🎯定义 / 📐证明。公式用 LaTeX(KaTeX)。
- 用户要"从科普水平开始重写",但严格度高于科普:同一概念,科普讲直觉,这里讲可证明。

## Out of scope(保护最近发展区)

- **抽象代数的非几何部分**(Sylow、环论、模论深度)——只在几何需要时现补最小量。
- **前沿研究**(Cartan 几何的严格联络论、模空间)——只到概念入口。
- **再写一套面向中学生的科普**——那是 `../geometry/` 的事,不是这里。
- **竞赛的非几何部分**(组合、数论、代数不等式)——不在范围,只在几何题触及群/不变量时引入。
