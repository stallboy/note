# 起点:唯一严格地基是线性代数;终点是能教大学

用户在首次访谈中明确:

- **严格工具掌握情况**:做过证明、不只是看过科普的,目前只有**线性代数**(向量空间、线性映射、特征值/特征向量、行列式、正交/酉群的矩阵推导)。**抽象代数、分析/流形、黎曼几何/李群均未在严格层面掌握**——科普层面有概念,但不到能证明。
- **终点**:"升级到能教大学水平"(可证明、可手算、带习题与误解纠正),非研究前沿、非纯物理应用。
- **起点策略**:从科普水平重写,**当用户是初高中水平起步**,但严格度高于科普;同时**不复用** `../geometry/` 科普讲义。

**对未来课的影响(implications)**:
- 全工作区的统一杠杆 = **把每种几何重铸为矩阵群**,让群论/不变量理论沿 GL(n) 及其子群自然落地,绝不悬空要求抽象代数前置。
- 群论、群作用、轻量分析、李论**在本工作区内从零严格补**,但始终以矩阵为锚。
- 每课默认用户线性代数扎实;矩阵证明可放手写。
- 节奏:先"地基重铸"(群/作用/不变量定义)→"矩阵几何塔"(E/CO/Aff/PGL)→不变量理论→连续与李→爱尔兰根严格版→物理→教学法。
