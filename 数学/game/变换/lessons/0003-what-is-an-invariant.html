"不变量"的精确定义

克莱因那句"几何 = 变换群 + 不变量",前半句("群")已钉死。现在钉后半句——"不变量"。一句话:它是在群作用下取值不变的函数。这一课把口号变成公式,并看清"不变量"与"轨道"如何互为表里。

1定义

🎯 定义($G$-不变量)　设 $G\curvearrowright X$。函数 $f:X\to V$ 称为$G$-不变量,若

$$f(g\cdot x)=f(x)\quad\text{对一切 }g\in G,\ x\in X.$$

即:无论你用群里的哪个变换去动 $x$,$f$ 的值都不变。几何学 = 研究 $(G,X)$ 上的 $G$-不变量。

💡 不变量 ⟷ 轨道。$f$ 是 $G$-不变量 $\Leftrightarrow$ $f$ 在每条轨道上取常值(因为轨道里的点都是 $g\cdot x$,而 $f(g\cdot x)=f(x)$)。所以:

  • 找不变量 = 给轨道贴标签。
  • 若这些标签能区分所有不同轨道(即 $f(x)=f(y)\Leftrightarrow x,y$ 同轨道),称 $f$ 是完备不变量(complete invariant)——它彻底回答了"$G$ 眼里两个东西等不等价"。

2每个群,配它的不变量(全塔一览)

现在我们能用同一把尺子,把整门几何的"不变量"逐一摆出来。注意一个规律:群越大,轨道越粗,不变量越少、越普适。

作用 $G\curvearrowright X$$G$-不变量轨道 / 完备不变量
$O(2)\curvearrowright\mathbb{R}^2$(一点)长度 $\|x\|$圆 $\|x\|=r$;$\|\cdot\|$ 完备
$E(2)\curvearrowright$(一点)无(只有一个轨道:全平面)欧氏几何不关心"在哪"
$E(2)\curvearrowright$(两点 $P,Q$)距离 $d(P,Q)$$d$ 完备:等距即等长
$\mathrm{Aff}(2)\curvearrowright$(共线三点)共线有向比 $\overline{AC}/\overline{BC}$仿射不关心"多长",只关心"几分之几"
$\mathrm{PGL}\curvearrowright$(共线四点)交比射影唯一不变量(第 08 课)

🔑 为什么"距离"是欧氏几何的主角?因为 $E(2)$ 作用在"点对"$(P,Q)$ 上时,距离是完备不变量:两个点对 $d$ 相同 $\Leftrightarrow$ 存在等距把一个送到另一个。整本中学几何(全等三角形 SSS/SAS)其实都在用这件事——"三边对应相等则全等"的本质,就是"点对的距离这一族不变量,完备地分类了三角形"。

3把克莱因纲领写成公式

有了精确定义,克莱因那句话现在可以一比一翻译:

爱尔兰根纲领(严格版,预告) 一门几何 = 一个群作用 $G\curvearrowright X$;
研究对象 = $X$ 上的全体 $G$-不变量(函数与关系);
两个图形"在这门几何里等价" $\Leftrightarrow$ 它们同处一条 $G$-轨道。
几何学 = 变换群 + 该群的不变量。

同一片空间 $X$,换一个作用群,就是一门新几何——这正是"层级"的来历(第 14 课严格化):$E\subset\mathrm{Sim}\subset\mathrm{Aff}\subset\mathrm{PGL}\subset\mathrm{Homeo}$,群越来越大,不变的越来越少,但结论越来越普适。

4自测

Q1 "$f$ 是 $G$-不变量"等价于下列哪一句?
对。轨道里的点形如 $g\cdot x$,而 $f(g\cdot x)=f(x)$,故 $f$ 在整条轨道上不变。反之,在每条轨道取常值 ⟹ $f(g\cdot x)=f(x)$。
回忆定义 $f(g\cdot x)=f(x)$。轨道里所有点都是某个 $g\cdot x$,所以这条等式说的就是"$f$ 在每条轨道上不变"。
Q2 $E(2)$ 作用在"点对"$(P,Q)$ 上,完备不变量是——
对。等距把任意一对相距 $d$ 的点送到另一对相距 $d$ 的点。方向、中点位置都不是不变量(平移、旋转会改它们)。
平移会改方向角和中点,旋转会改方向角——它们都不是 $E(2)$-不变量。只有"两点间距"在等距下不变,且能完备分类。
Q3 群变大(从 $O(2)$ 扩到 $E(2)$ 又扩到 $\mathrm{Aff}$),不变量的个数——
对。群越大 ⟹ 轨道越粗(能区分的越少)⟹ 不变量越少。但幸存的不变量更普适(如交比对一切射影变换都不变)。
群变大 = 能"动"得更狠 = 轨道更粗 = 区分能力下降 = 不变量更少(但更普适)。

5习题

证 设 $G\curvearrowright X$,$f$ 是 $G$-不变量。证明:$f(x)=f(y)$ 是 $X$ 上的等价关系;其等价类恰是若干条 $G$-轨道的并。何时 $f$ 是完备不变量?
想 $O(2)$ 作用于三角形(三顶点的无序组)。列举几个 $O(2)$-不变量;哪个是完备的?(提示:三条边长。)
进阶 证明:若 $H\le G$,则每个 $G$-不变量自动是 $H$-不变量,反之不然。用此解释"为什么欧氏几何的结论对仿射几何不一定成立,而仿射的结论对射影一定成立"——即层级方向。

小结

  • 不变量 = 在群作用下不变的函数;$f(g\cdot x)=f(x)$。
  • 不变量 ⟷ 轨道:不变量在轨道上取常值;完备不变量能区分所有轨道。
  • 距离是 $E(2)$-点对的完备不变量(= 全等判据的根源);群越大,不变量越少越普适。
  • 克莱因纲领 = $(G,X)$ + $G$-不变量。层级:$E\subset\mathrm{Sim}\subset\mathrm{Aff}\subset\mathrm{PGL}\subset\mathrm{Homeo}$。
