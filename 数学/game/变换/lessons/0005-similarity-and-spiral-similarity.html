相似与旋转相似

塔的第二层:把"保距"放宽成"等比放缩",得到相似群 $\mathrm{CO}(n)$。在 2D,正向相似恰好是复数乘法 $z\mapsto az+b$——而"旋转 + 放缩"的组合,就是 IMO 几何的头号武器旋转相似(spiral similarity)。

1相似群 $\mathrm{CO}(n)$

🎯 定义　$f$ 是相似,若存在常数 $\lambda>0$ 使 $\|f(x)-f(y)\|=\lambda\|x-y\|$ 对一切 $x,y$。$\lambda$ 叫相似比。全体相似记 $\mathrm{Sim}(n)$。

命题 相似的代数形式

每个相似形如 $f(x)=\lambda A x+b$,$A\in O(n)$、$\lambda>0$。其线性部分全体 $\mathrm{CO}(n)=\{\lambda A:\lambda>0,\,A\in O(n)\}\cong\mathbb{R}_{>0}\times O(n)$。

证明. $\frac{1}{\lambda}f$ 是等距(相似比归一),由第 04 课 $\frac{1}{\lambda}f(x)=A'x+b'$,$A'\in O(n)$。故 $f(x)=\lambda A'x+\lambda b'=Ax+b$,$A=\lambda A'\in\mathrm{CO}(n)$。$\blacksquare$

不变量:相似保角(conformal)、保长度之比。它不保长度本身($\lambda\ne1$ 时距离被缩放)。故相似几何介于欧氏(保距)与仿射(只保比/共线)之间。

22D 的奇迹:相似 = 复数变换

把 $\mathbb{R}^2$ 看成复平面,$z=x+iy$。则:

定理 平面相似的复数形式

平面上的相似,在复坐标下恰为 $z\mapsto az+b$(正向,$|a|=\lambda$,$\arg a=\theta$)或 $z\mapsto a\bar z+b$(反向)。其中 $a\in\mathbb{C}\setminus\{0\}$、$b\in\mathbb{C}$。

证明. 正向相似的线性部分 $\lambda R_\theta\in\mathrm{CO}(2)$。而 $\lambda R_\theta$ 在复数下正是"乘 $a=\lambda e^{i\theta}$":$z\mapsto az$ 旋转 $\theta$ 再放缩 $\lambda$。再加平移 $b$。反向情形 $\bar z$ 给出反射(共轭)。$\blacksquare$

💡 为什么复数乘法同时"转又拉"?因为 $a=\rho e^{i\theta}$,乘 $a$ = 转 $\theta$、拉 $\rho$。这把"旋转 + 相似"统一成一个复数。$O(2)\subset\mathrm{CO}(2)$ 就是"$|a|=1$"的子情形(纯旋转)。整门 2D 相似几何,被压缩成"复平面上的仿射变换 $z\mapsto az+b$"。

3旋转相似:IMO 头号武器

🎯 定义　旋转相似(spiral similarity)= 有不动点 $O$ 的正向相似:以 $O$ 为中心,转角 $\theta$、相似比 $\rho$。复数下即 $z\mapsto a(z-O)+O$,$a=\rho e^{i\theta}$。

🔑 核心事实:旋转相似把任一线段 $AB$ 送到任一线段 $CD$(当 $|CD|/|AB|=\rho$)。其中心 $O$ 满足

$$\triangle OAB\sim\triangle OCD,\qquad \angle AOC=\angle BOD=\theta,\quad \frac{OA}{OC}=\frac{OB}{OD}=\frac{|AB|}{|CD|}.$$

构造中心:$O$ 是"过 $A,C$ 的圆"与"过 $B,D$ 的圆"的另一个交点(若 $AB\parallel CD$ 则退化)。这正是 Miquel 点的化身——多条共圆关系交汇处。

✏️ 手算:旋转相似把 $A=1,B=i$ 送到 $C=-1,D=-i$(都绕原点)。

$AB$ 从 $1$ 到 $i$;$CD$ 从 $-1$ 到 $-i$。把 $1\mapsto-1$、$i\mapsto-i$ 的相似:中心 $O=0$,比值 $\rho=|-1|/|1|=1$,转角 $\theta=180°$。复数:$a=-1$,$z\mapsto-z$。

核验 $\triangle OAB\sim\triangle OCD$:都是腰为 $1$ 的等腰直角三角形 ✓。$\angle AOC=\angle(1\to-1)=180°=\theta$ ✓。

★竞赛联结:旋转相似秒杀什么

🔑 旋转相似是 2D 几何最强工具之一(Evan Chen《EGMO》专章)。典型题:

  • 共圆判定:若旋转相似把 $AB$ 送 $CD$,则 $A,B,C,D$ 四点共圆(中心 $O$ 也在某些圆上)。
  • Miquel 点 / 三圆共点:三角形三边上各取一点,三个小三角形的外接圆共点——本质是若干旋转相似中心的巧合。
  • "两个正方形/等边三角形"问题:两个正方形外/内接,某线段相等垂直——构造一个转 $90°$、比 $1$ 的旋转相似(或转 $60°$ 的)一步证完。

用我们的语言:这些都是 $\mathrm{CO}(2)$ 里某个特定元素 $a=\rho e^{i\theta}$(常见 $\theta=90°,60°$)的不变量性质。妙招不再是"灵感",而是"找一个合适的复数 $a$"。

4自测

Q1 相似变换 $z\mapsto az+b$($a\ne0$)的相似比 $\lambda$ 和转角 $\theta$ 是——
对。$a=\lambda e^{i\theta}$,乘 $a$ = 放缩 $\lambda$、转 $\theta$;$b$ 只是平移,不参与。
$a=\lambda e^{i\theta}$,$|a|=\lambda$、$\arg a=\theta$。$b$ 是平移,与比值、转角无关。
Q2 相似变换不保下列哪个量?
对。相似把一切距离乘 $\lambda$,故绝对长度改变;但角度、长度比、共线性都保。
相似把每条距离乘同一常数 $\lambda$,所以"比"被消掉、角度(余弦=点积/长度积)也被消掉。唯独"绝对长度"被放大。

5习题

证 证明:旋转相似的中心 $O$ 满足 $\triangle OAB\sim\triangle OCD$。由此说明 $A,B,C,D$ 四点共圆的充要条件(用 $O$ 看到的角)。
手算 求把线段 $AB$($A=0,B=1$)送到 $CD$($C=2,D=2+i$)的旋转相似的中心 $O$、转角、比值。(提示:写方程 $a\cdot 0+b=2$、$a\cdot1+b=2+i$。)
竞赛 在同一顶点 $A$ 外接两个正方形 $ABCD$ 与 $AB'C'D'$(共顶点 $A$)。用"$90°$ 旋转相似"证明:$CC'=DD'$ 且 $CC'\perp DD'$。(经典"两正方形"题。)

小结

  • 相似 = 距离乘常数 $\lambda$;$\mathrm{CO}(n)=\mathbb{R}_{>0}\times O(n)$;保角、保比,不保长度。
  • 2D 奇迹:相似 $=z\mapsto az+b$;$a=\lambda e^{i\theta}$ 同时编码"放缩 + 旋转"。
  • 旋转相似 = 有不动点的正向相似,把 $AB$ 送 $CD$,中心满足 $\triangle OAB\sim\triangle OCD$;通向 Miquel、共圆、"两正方形"。
  • 每个竞赛妙招 = $\mathrm{CO}(2)$ 里某个 $a=\rho e^{i\theta}$(常 $90°$、$60°$)的性质。
