## 关键约束(用户明确)

- **不参考 `../geometry/`**:那是用户之前为中学生写的科普讲义。本 `/teach` 工作区**独立设计**,不复用其结构、配色、CSS、内容。把这里当成一套全新的、为用户自己掌握/教学而建的严格课程。
- **唯一已验证的严格地基 = 线性代数**(向量空间、线性映射、特征值、行列式、O(n)/U(n) 的矩阵推导)。群论/轻量分析/李论在本工作区内从零补,但**以矩阵为锚**。
- **终点 = 能在大学水平严格地教**(可证明、可手算、带习题与误解纠正)。
- **与高中数学竞赛结合**:每个几何章节配"竞赛联结"+真题试炼;用矩阵群工具解释竞赛"妙招"(旋转相似、反演、调和点列、复数法、极点极线)。会解竞赛题 = 机器玩得转的最硬证据。
- **起点 = 从科普水平重写**,但严格度高于科普。

- 重思想与方法,不重机械作图。
- 前置知识从头讲并详解,哪怕群公理、群作用也从零。
- 核心推导可跟进、可手算、给数值核对。
- 互动标记:🤔想一想 / ✏️手算 / 💡洞见 / 🎯定义 / 📐证明。公式用 LaTeX(`$…$` / `$$…$$`,KaTeX 渲染)。
- 语言通俗亲切,用类比;不假设会抽象代数/流形。
- 详解优先于评论/故事。

## 课程设计杠杆(贯穿全工作区)

**把每种几何重铸为矩阵群:**
- 等距 → O(n) + 平移 → E(n)
- 相似 → CO(n) = R* × O(n)
- 仿射 → Aff(n) = GL(n) ⋉ Rⁿ
- 射影 → PGL(n+1) 作用在 Pⁿ

这样"变换群"永不悬空,"不变量"问题 = "这个矩阵群保什么双线性型/什么量"。

## 竞赛联结(贯穿全工作区)

- 矩阵塔每一站 → 对应竞赛金矿:
  - 相似 → **旋转相似(spiral similarity)** = 复数乘法,Miquel 点、共圆。
  - 仿射 → 仿射秒杀共线、线段比、极值(把椭圆问题仿射成圆)。
  - 射影 → **交比、调和点列**,完全四点形,灭点。
  - 反演 → 反演秒杀(切线、共圆、距离比)。
  - 复数法 → $GL(2,\mathbb{C})$ 在 $\mathbb{C}$ 上的作用,几何题代数化。
  - 极点极线 → 射影对偶的化身。
- 用户**已中译** Skopenkov《Mathematics via Problems · Part 2 几何》(`../../mathcircle/mvp_geometry/`),该书把 Evan Chen《EGMO》列为参考——可复用其题库与中文表述。
