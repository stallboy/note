# 08 收费与资金管理方案

> **核心原则**：**零利润、AA 制、完全透明**。这是数学圈不变质的根本保障，也是莫斯科数学圈 80 年的传统——**主持人不取酬，活动不为钱**。
>
> 一旦开始盈利，数学圈就会在 3 个月内退化为"另一种课外班"。

---

## 一、为什么必须坚持"零利润"？

### 1.1 莫斯科数学圈的铁律

莫斯科数学圈（MCCME、IUM 体系）从 1930 年代至今，**所有面向中学生的数学圈都是免费的**。主持人是大学数学家、博士生，他们**不拿一分钱报酬**。原因：

| 若收费 | 后果 |
|--------|------|
| 家长会把它当"课外班" | 用"成绩提升""获奖"衡量，3 个月内应试化 |
| 主持人会变成"老师" | 开始追求"让学生满意"，不敢布置难的题 |
| 招生会变成"卖课" | 选生源时倾向"能出成绩的"，背离初衷 |
| 家长关系会异化 | 从"教育合伙人"变成"消费者与服务者" |

### 1.2 本地化的现实选择

我们不是大学数学家，但**"不取酬"的原则可以照搬**。家长主持人出的是"时间"和"心血"，**这是对社区的贡献，不是商业服务**。

> **关键话术（对家长、对自己）**：
> "我不是在'教课'，我是在**组织一群孩子一起学数学**。我的孩子也在其中，我也是受益者。"

## 二、资金来源与用途（AA 制模型）

### 2.1 唯一合法的资金来源：**全体家庭 AA 分摊**

**收入项**（按学期预收，期末多退少补）：

| 项目 | 估算（每家庭/学期） | 说明 |
|------|-------------------|------|
| **场地费** | 0–400 元 | 若用社区图书馆免费研讨室则为 0；若租用咖啡馆/活动室约 20–50 元/次×16 次 |
| **资料费** | 50–100 元 | 打印问题单、文件夹、文具 |
| **活动费** | 50–100 元 | 学期末"数学派对"、证书、小纪念品 |
| **应急储备** | 50 元 | 应对突发支出 |
| **合计** | **150–650 元/家庭/学期** | 远低于任何商业课外班 |

> **对照**：北京市场上一节"奥数小班课"约 200–400 元/次，一学期 16 次约 **3200–6400 元**。我们的数学圈**最多是它的 1/10**。

### 2.2 资金用途的"红线"

✅ **可以花的**：
- 场地租金、水电
- 打印、文具、教具（白板、马克笔、计时器）
- 学期末活动的零食、证书制作
- 学生小礼物的统购（如数学书籍，见下）

❌ **绝对不能花的**：
- 主持人的"课酬""辛苦费"（**这是铁律**）
- 主持人的交通、餐饮
- 任何家长的"劳务费"
- 商业性支出（如请名师讲座的出场费——若请客座讲师，由讲座方自理）

### 2.3 "学生书籍团购"——唯一可议价的灰色地带

W3 后可考虑为学生**团购经典教材**（如《俄罗斯数学奥林匹克试题集》《A Moscow Math Circle》中译本）。处理原则：
- **按成本价转售**，不加价。
- **完全自愿**，不买也行（主持人可提供 PDF 复印件）。
- 在账目中**单列**，不与运营资金混同。

## 三、收费模式选择（3 种，任选其一）

### 模式 A：**学期预付制（推荐）**

**操作**：
- 学期开始时，每家庭预交 **300–500 元**（根据场地成本估算）。
- 学期末结算：多退少补。
- 中途退出的家庭，按已上课次数折算退还剩余。

**优点**：账目简单，无每周收钱的尴尬。
**缺点**：学期初一次性支出，部分家庭可能有顾虑。

**适用**：场地费稳定、家庭信任度高的情况。

### 模式 B：**按次分摊制**

**操作**：
- 每次课后，按实际到场人数分摊当次场地费。
- 例如：场地费 80 元/次，到 7 人，每人 80÷7 ≈ 11.4 元，收 12 元（向上取整，差额入储备金）。

**优点**：最公平，不来不交钱。
**缺点**：每周收钱麻烦，家长群里发红包混乱。

**适用**：场地费低或不固定、人数波动大的情况。

### 模式 C：**基金池制（最简单）**

**操作**：
- 学期初每家庭交 **固定金额**（如 200 元）入"基金池"。
- 所有支出从基金池扣除。
- 学期末若有结余，**不退还，转为下学期基金**；若不足，再补。

**优点**：最省事，无需精确结算。
**缺点**：需要家长高度信任，结余处理需提前说清。

**适用**：6–8 人稳定小团体、家长彼此熟悉。

> **💡 推荐**：**首学期用模式 A**（预付 300 元/家庭），W4 试运行结束后根据实际支出调整为模式 A 或 C。

## 四、账目管理（透明化 SOP）

### 4.1 三个角色

| 角色 | 职责 | 由谁担任 |
|------|------|---------|
| **主持人** | 决定支出项（买什么） | 发起家长 |
| **出纳** | 管钱、记账 | 另一位家长（**不能是主持人**，形成制衡） |
| **全体家长** | 监督 | 每人都有查账权 |

> **关键**：**主持人不管钱，出纳不管教学**——这是 NGO 财务的基本原则，防止"一言堂"。

### 4.2 账目公开制度

- **每周**：出纳在家长群发送**当次支出明细**（一行：日期、项目、金额、余额）。
- **每月**：出纳发送**月度汇总表**（Excel/腾讯文档，3 列：日期、支出项、金额）。
- **学期末**：出纳发送**学期总账**，并提议结余处理方案。

### 4.3 账目模板（直接套用）

**共享腾讯文档/石墨表格**，所有家长可查看：

```
回龙观数学圈 · 2026 秋季学期账目

| 日期       | 项目         | 收入  | 支出  | 余额  | 备注           |
|-----------|-------------|-------|-------|-------|---------------|
| 2026-09-01 | 学期预付×7  | 2100  |       | 2100  | 300元/家×7家   |
| 2026-09-07 | 场地费 W1   |       | 80    | 2020  | XX图书馆研讨室 |
| 2026-09-07 | 打印问题单×8 |       | 24    | 1996  | 3元/份×8       |
| 2026-09-14 | 场地费 W2   |       | 80    | 1916  |               |
| ...       | ...         | ...   | ...   | ...   | ...           |
| 期末结算   |             |       |       | ???   | 多退少补       |
```

### 4.4 票据管理

- 所有支出**保留票据**（电子收据、微信转账截图均可）。
- 出纳每月整理一次，存入共享云盘。
- **无票据的支出不予报销**——保护出纳，也保护主持人。

## 五、中途退出的退费规则

**铁律：退出自由，退费公平**。

| 退出时间 | 退费规则 |
|---------|---------|
| W1–W2（试运行期） | **全额退还**已交款项（扣除已发生的场地费） |
| W3–W8 | 退还**未发生**的场地费（按剩余周数 × 单周场地费） |
| W9–W16 | **不退费**（学期过半，资金已锁定）；但结余可转入下学期 |

> **话术**："试运行期全额退费，这是我们对'自愿原则'的承诺。"

## 六、与家长的财务沟通（话术库）

### 6.1 开班家长会上的"收费说明"（必须说清）

> "关于费用，我先说清楚三点：
> 1. **这不是课外班，主持人不收任何课酬**。我的孩子也在其中，我也是受益者。
> 2. **所有费用 AA 制，零利润**。每学期预收约 300 元，只用于场地、资料、活动，**每月公开账目**。
> 3. **试运行 4 周内，任何家庭可全额退出退费**。4 周后我们共同决定是否继续。
>
> 我希望我们之间是**教育合伙人的关系，不是消费者与服务商的关系**。"

### 6.2 应对"要不要给主持人一点心意"

**家长可能说**："您辛苦了，我们想给您包个红包 / 送张卡。"

**回应**：
> "非常感谢您的心意。但**我必须婉拒任何报酬**，这不是客气，是原则——
> 一旦我收了钱，这件事就变味了。我会开始'讨好'孩子，不敢布置难题，开始追求'让家长满意'，**这就背离了数学圈的初衷**。
> 如果您真心想表达感谢，**最好的方式是：偶尔轮值当助教，或帮我们介绍一两个合适的孩子**。"

### 6.3 应对"能不能商业化，扩大规模"

**家长可能说**："这个模式这么好，要不要做成商业项目？"

**回应**：
> "商业化是数学圈的毒药。一旦为了'扩大规模'而收费，3 个月内就会变成'另一种课外班'。
> 我们的理想状态是：**今年 1 个数学圈，明年裂变成 2–3 个**，每个都由一位家长志愿主持。这就是莫斯科数学圈从 1 个变成 100 个的方式——**靠志愿者，不靠商业**。"

## 七、长期可持续性：为什么"零利润"反而最持久？

| 短期看 | 长期看 |
|--------|--------|
| 主持人"亏"了时间 | 主持人孩子的数学能力提升（**最大的回报**） |
| 主持人"亏"了精力 | 主持人在社区建立了声望和人脉 |
| 没有商业收入 | **无需迎合市场**，可以坚持纯粹的数学圈精神 |
| 看似"做不大" | **可裂变**：每个毕业的家长都可能成为下个数学圈的主持人 |

> **真实案例**：莫斯科数学圈的 MCCME 体系，从 1991 年 IUM 成立算起，**30 多年完全免费**，却培养出数十位国际数学奖项得主。原因正是——**它不为钱，所以不会变味。**

## 八、预算样表（第一学期，16 周，7 个家庭）

### 假设条件
- 场地：社区图书馆研讨室，**免费**
- 人数：7 个家庭
- 模式：学期预付

### 预算明细

| 项目 | 单价 | 数量 | 小计 |
|------|------|------|------|
| **场地费** | 0 | 16 次 | 0 |
| **打印问题单** | 3 元/份 | 8 份×16 次 | 384 |
| **文件夹×8** | 15 元 | 8 个 | 120 |
| **白板马克笔** | 10 元 | 10 支 | 100 |
| **计时器** | 30 元 | 1 个 | 30 |
| **学期末活动** | | | |
| - 零食 | | 1 次 | 150 |
| - 证书制作 | 5 元 | 8 份 | 40 |
| - 小纪念品（数学书籍） | 40 元 | 8 本 | 320 |
| **应急储备** | | | 56 |
| **合计** | | | **1200 元** |
| **每家庭分摊** | | | **≈ 171 元** |

> **实际预收建议**：每家庭 **200 元**（预留缓冲），学期末退还结余约 29 元/家庭，或转入下学期。

### 若场地收费（咖啡馆 / 活动室）

| 场地单价 | 16 次场地费 | 每家庭分摊（7 家） |
|---------|-----------|-------------------|
| 50 元/次 | 800 | +114 元 |
| 100 元/次 | 1600 | +229 元 |

> 即便场地 100 元/次，**每家庭学期总支出也仅约 400 元**——是商业课外班的 1/15。

## 九、一句话总结

> **数学圈的钱，是"过路费"——收进来是为了花出去，不为任何个人留存。**
>
> **主持人不取酬，账目全公开，试运行可退费——这三条原则守住，数学圈就不会变味。**
>
> **当有人问"你们怎么收费"，标准答案是："我们不收费，我们 AA。主持人是我，我的孩子也在里面。"**
