## W1 摸底：6 道分层诊断题

> **目的**：诚实评估每个孩子在 4 个领域（代数/几何/数论/组合）的真实水平。**不评分，只观察**。

### 摸底 1（代数 · 二次函数）
> 已知抛物线 y = x² − 2mx + m² − 1。
> (1) 求 m = 2 时抛物线与 x 轴交点坐标。
> (2) 若抛物线与 x 轴两交点距离为 4，求 m。
> (3) **讨论**：m 取何值时，抛物线与 x 轴 (a) 无交点 (b) 一个交点 (c) 两个交点？

**诊断点**：
- 会求判别式 → B 类以上
- 会用韦达定理算交点距离 → A 类
- 能完整分类讨论 → 强 A 类

---

### 摸底 2（几何 · 相似与圆）
> AB 是 ⊙O 直径，C 在 ⊙O 上，CD ⊥ AB 于 D。已知 AB = 8，CD = 2√3。
> (1) 求 AD · DB。
> (2) 求 AC · BC。
> (3) **推广**：能否用射影定理把 (1)(2) 统一成一个结论？

**诊断点**：
- 知道射影定理 CD² = AD·DB → B 类以上
- 知道 AC·BC = AB·CD（面积法）→ A 类
- 能联想"幂"的统一性 → 数学直觉好

---

### 摸底 3（数论）
> (1) 求 7¹⁰⁰ 除以 11 的余数。
> (2) 证明：对任意素数 p > 3，p² − 1 是 24 的倍数。
> (3) 求 2²⁰²⁶ + 3²⁰²⁶ 的个位数字。

**诊断点**：
- 会用费马小定理 → A 类（若没学过，能独立"周期性观察"也算）
- 会分 p=6k±1 讨论 → 强 B 类
- 个位数能化简到周期 4 → B 类

---

### 摸底 4（组合 · 计数）
> 圆上有 10 个点，每 3 点确定一个三角形。
> (1) 共能组成多少个三角形？
> (2) 其中**顶点按顺时针编号 1–10**，编号之**和为奇数**的三角形有多少个？
> (3) **推广**：若圆上 n 个点，和为奇数的三元组数？

**诊断点**：
- (1) C(10,3) → 全员应会
- (2) 奇偶分类 → B 类
- (3) n 的奇偶讨论 → A 类

---

### 摸底 5（不等式）
> 已知 a, b > 0，a + b = 4。
> (1) 求 ab 的最大值。
> (2) 求 a² + b² 的最小值。
> (3) 求 1/a + 1/b 的最小值。

**诊断点**：
- 基本不等式 → 全员应会
- a²+b² = (a+b)²−2ab 转化 → B 类
- 1/a+1/b 用柯西或基本不等式变形 → A 类

---

### 摸底 6（综合 · 几何与函数）
> △ABC 中，∠C = 90°，AC = 3，BC = 4。D 在 AB 上（含端点）运动。过 D 作 DE ⊥ AC 于 E，DF ⊥ BC 于 F。设 AD = x。
> (1) 用 x 表示矩形 CEDF 的面积 S。
> (2) 求 S 的最大值及此时 D 的位置。
> (3) **推广**：若 ∠C 不是直角，结论如何？

**诊断点**：
- 能建系或用相似表示 DE、DF → B 类以上
- 求二次函数最值 → A 类
- 能讨论非直角情形 → 强 A 类

## W2 ｜ 二次函数 I：图象、性质与最值

### 钩子题（开场）
> **一个"反直觉"的最值问题**：
> 求 f(x) = |x² − 4x + 3| 在 x ∈ [0, 4] 上的最大值和最小值。

**引导提问**：
- 先别求最值，**画图**——y = x²−4x+3 的图象长什么样？
- 取绝对值后，哪部分被"翻上去"了？
- 最大值在端点还是顶点？最小值呢？

**解答要点**：
- y = x²−4x+3 = (x−1)(x−3)，根 1, 3；对称轴 x=2，顶点 (2,−1)。
- 取绝对值：x∈[1,3] 部分翻上去，顶点变 (2, 1)。
- 最小值 0（在 x=1, 3），最大值在端点：f(0)=f(4)=3。
- **反直觉点**：最大值不在顶点，而在端点。孩子容易错答"最大值是 1"。

**推广**：
- 若区间改为 [0, 3]？[1, 4]？
- 若函数改为 |x² − 4x + 5|（无实根）？图象有何不同？

---

### 核心题组

#### 🟢 核心题 1（全员）
> 已知二次函数 y = ax² + bx + c 图象过 (0, 2)、(1, 1)、(2, 2)。
> (1) 求 a, b, c。
> (2) 求顶点坐标和对称轴。
> (3) 当 x 取何值时，y ≥ 2？

**解答要点**：代入三点解方程；顶点 (1, 1)；y ≥ 2 即 x ≤ 0 或 x ≥ 2。

#### 🟡 核心题 2（多数）
> 已知 f(x) = x² − 2ax + 3 在 [0, 2] 上的最小值为 2，求 a。

**引导提问**：
- 对称轴 x = a 是动轴！分类讨论：轴在区间**左、内、右**三种情况。
- 每种情况最小值在哪？

**解答要点**（**初三压轴常考的"动轴定区间"模型**）：
- a < 0：最小值在 x=0，f(0)=3 ≠ 2，舍。
- 0 ≤ a ≤ 2：最小值 f(a) = 3 − a² = 2 → a = ±1，取 a = 1。
- a > 2：最小值在 x=2，f(2) = 7 − 4a = 2 → a = 5/4，但 5/4 < 2，舍。
- **答**：a = 1。

> **这是中考/竞赛的高频题型**，务必让孩子**自己拼出"三段分类"的逻辑**。

#### 🔴 挑战题
> 已知 f(x) = x² − 2ax + a² − 1（注意：可因式分解为 (x−a)² − 1）。
> (1) 求证：无论 a 取何值，f(x) 与 x 轴总有交点。
> (2) 若 f(x) 与 x 轴两交点都在区间 [0, 2] 内，求 a 的范围。
> (3) 若 f(x) = 0 的两根之差的绝对值不超过 2，求 a 的范围。

**解答要点**：
- (1) Δ = 4 > 0 恒成立。
- (2) 两根 a±1 都在 [0,2] → a ∈ [1, 1]。哦不，a−1 ≥ 0 且 a+1 ≤ 2 → a ∈ [1, 1]，即 a = 1。

  **修正**：a−1 ≥ 0 且 a+1 ≤ 2 → a ≥ 1 且 a ≤ 1 → a = 1。

- (3) 两根之差 = 2，所以"不超过 2"即恒成立。

> **注意**：本题若发现 (2)(3) 答案特殊，是出题有意——让孩子意识到"代数约束有时会塌缩到单点"。

#### ⚫ 研究题（可不做）
> 设 f(x) = x² + bx + c，已知 |f(1)| ≤ 1，|f(−1)| ≤ 1，|f(0)| ≤ 1。求 |b| + |c| 的最大值。

**这是经典的"二次函数系数约束"问题**，答案 3。供 A 类孩子研究。

## W3 ｜ 二次函数 II：含参讨论与方程结合

### 钩子题
> 方程 |x² − 4| = a 有几个解？（**对 a 分类讨论**）

**引导提问**：
- 画 y = |x² − 4| 的图象。
- y = a 是一条水平线，与图象交点个数随 a 变化吗？

**解答要点**：
- y = |x²−4|：x²≥4 时 y=x²−4；x²<4 时 y=4−x²。
- 图象："W" 形，在 x=±2 处值为 0，x=0 处值为 4。
- a < 0：0 解；a = 0：2 解；0 < a < 4：4 解；a = 4：3 解；a > 4：2 解。

**推广**：换成 |x² − 4x + 3| = a 呢？

---

### 核心题组

#### 🟢 核心题 1
> m 为何值时，方程 x² − 2x + m = 0
> (1) 有两个正根？
> (2) 有一正一负根？
> (3) 两根都大于 1？

**解答要点**：
- (1) Δ≥0, 两根和 > 0, 积 > 0 → m ≤ 1 且 m > 0 → m ∈ (0, 1]。
- (2) 积 < 0 → m < 0。
- (3) **难点**：两根 > 1，不能只看和与积。用变换：令 y = x − 1，方程变 (y+1)²−2(y+1)+m=0 → y² + m − 1 = 0，需两 y 根 > 0。

> **(3) 是初三竞赛的核心技巧——"平移变换化简根的分布"**。

#### 🟡 核心题 2（含参综合）
> 已知抛物线 y = x² + (2m − 1)x + m² − 1 与 x 轴交于 A、B，顶点为 C。
> (1) 求证：抛物线恒与 x 轴有交点。
> (2) 当 △ABC 面积最小时，求 m。

**解答要点**：
- (1) Δ = (2m−1)² − 4(m²−1) = −4m + 5。Δ ≥ 0 → m ≤ 5/4。
  - **修正**：题目说"恒"，但 Δ 并非恒非负。需要把题目改为"当 m ≤ 5/4 时"。
- (2) AB = √Δ / |a| = √(5−4m)。高 = |顶点纵坐标| = (4−(2m−1)²)/4 ... 面积 = AB·高/2。求最小值。

#### 🔴 挑战题
> 设 x₁, x₂ 是 x² − (m−1)x + m = 0 的两根。求 x₁² + x₂² 的最小值。

**解答要点**：
- x₁² + x₂² = (x₁+x₂)² − 2x₁x₂ = (m−1)² − 2m = m² − 4m + 1 = (m−2)² − 3。
- 最小值看似 −3（在 m=2 时），但要检查 Δ ≥ 0：(m−1)² − 4m ≥ 0 → m² − 6m + 1 ≥ 0 → m ≤ 3−2√2 或 m ≥ 3+2√2。
- m = 2 不满足 Δ ≥ 0！
- **答**：在 m = 3 − 2√2 时取最小值，需重新计算。**这是经典"忘记判别式约束"的陷阱题**。

> **本题的教学价值**：让孩子记住——**韦达定理算最值，必须检查根的存在性！**

#### ⚫ 研究题
> 三次方程 x³ − 3x + 1 = 0 有几个实根？用图象法分析。

## W4 ｜ 几何进阶：相似、圆幂定理、四点共圆

### 钩子题（经典"反直觉"题）
> **蝴蝶定理**：AB 是 ⊙O 的弦，M 是 AB 中点。过 M 任作两弦 CD、EF。连接 CF、DE 分别交 AB 于 P、Q。求证：MP = MQ。

**引导提问**：
- 这个结论**反直觉**——为什么过 M 随便画两条弦，P、Q 都关于 M 对称？
- 关键工具：**圆幂定理**。从 M 出发，MD·MC = MA·MB = ME·MF。
- 能否用相似三角形把比例关系串起来？

**解答要点**（略，标准证明用到圆幂 + 相似）。**本题的价值不在答案，在于让孩子体会"圆幂定理统一了相交弦、割线、切线"**。

---

### 核心题组

#### 🟢 核心题 1（射影定理复习）
> Rt△ABC，∠C=90°，CD ⊥ AB 于 D。AC=6，BC=8。
> (1) 求 AB, CD, AD, BD。
> (2) 求 △ACD 与 △ABC 的相似比。

**解答要点**：AB=10, CD=4.8, AD=3.6, BD=6.4。射影定理：CD²=AD·DB, AC²=AD·AB, BC²=BD·AB。

#### 🟡 核心题 2（圆幂定理应用）
> P 是 ⊙O 外一点，过 P 作切线 PA（A 为切点）和割线 PBC（B、C 在圆上，B 在 P、C 之间）。PA = 6, PB = 4。求 BC。

**引导提问**：
- 切割线定理：PA² = PB·PC。
- BC = PC − PB。

**解答要点**：PC = 36/4 = 9, BC = 5。

#### 🟡 核心题 3（四点共圆判定）
> 在 △ABC 中，AD 是高，H 是垂心。M 是 BC 中点。求证：A、B、C 的三个垂足与一些点共圆。（**经典九点圆预热**）

**简化版**：证明△ABC 的垂足三角形（三高线足）的三顶点共圆。

**引导提问**：
- 两个垂足 D、E（AD⊥BC, BE⊥AC），∠ADB = ∠AEB = 90°。
- D、E 与 A、B 什么关系？（**对角互补 → 共圆**）

**解答要点**：∠ADB + ∠AEB = 180°，故 A、B、D、E 共圆。类似可证其他两组。

#### 🔴 挑战题（托勒密定理）
> 证明：圆内接四边形 ABCD 中，AC·BD = AB·CD + AD·BC。（**托勒密定理**）

**引导提问**：
- 找一点 P 在 AC 上，使 ∠ABP = ∠DBC。
- 证明 △ABP ∼ △DBC，△ABD ∼ △PBC（或类似）。
- 两个比例关系相加。

**解答要点**：经典证明（略）。**本题是初三几何竞赛的"基石定理"**，务必花一节课讲透。

**推广**：
- 托勒密不等式：任意四边形 ABCD，AC·BD ≤ AB·CD + AD·BC（等号当且仅当共圆）。
- **应用**：证明三角不等式、求最值。

#### ⚫ 研究题
> **塞瓦定理**：△ABC 内一点 O，AO、BO、CO 分别交对边于 D、E、F。求证 (BD/DC)·(CE/EA)·(AF/FB) = 1。

> **梅涅劳斯定理**：△ABC 与截线交 BC 于 D、CA 于 E、AB（延长）于 F。求证 (BD/DC)·(CE/EA)·(AF/FB) = −1（有向比）或 1（绝对值）。

**这两个定理是初三几何竞赛的"瑞士军刀"**，可在 W5 之后专题深入。

### W4 悬念题
> 圆与二次函数能结合吗？**抛物线 y = x² 上一点 P，求 P 到直线 y = 2x − 1 的最短距离**——这其实是高中解析几何，但用初等方法能做吗？（**答**：能，用代数化简为二次函数最值）。

## 一句话总结

> **准初三的数学圈，核心是"用深度换应试"**——不刷题，但每道题做到极致；不押题，但每个工具讲到底。
>
> **二次函数和圆是两大核心专题**，务必在暑假吃透。秋季在此基础上扩展到数论、组合、不等式。
>
> **目标**：让 1+3 学生在初三开学时，**数学能力已超过同龄人一个身位**——不是为了赢中考（他们免中考），而是为了**在高中/竞赛中占据先发优势**。
