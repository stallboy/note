# 回龙观数学圈（实践方案）

> 借鉴莫斯科数学圈（Math Circle）模式，在北京昌平二中回龙观校区周边组织面向初中生（重点是已通过/拟冲击"1+3"项目的学生）的每周讨论班。
>
> **目录创建日期**：2026-06-22

---

## 为什么这个方案可行

| 条件 | 现状 | 对数学圈的意义 |
|------|------|---------------|
| **学生时间充裕** | 1+3 学生免中考，4 年贯通；准 1+3 学生备考压力相对小 | 数学圈需要长期、稳定的每周投入，这正是它的土壤 |
| **生源质量** | 昌平二中"佳域杯"全区一等奖占 8/10，全国高中数学联赛多人获奖 | 周边有足够多的有数学天赋的孩子 |
| **家长配合** | 1+3 / 准 1+3 家庭普遍重视长期能力培养 | 不会把数学圈当作"课外班"对待 |
| **物理空间** | 回龙观社区有图书馆、社区中心、咖啡馆等 | 不依赖学校教室，降低门槛 |
