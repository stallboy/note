# 莫斯科数学讨论班：章程与流程横向总结

> 把六大讨论班的运作规则提炼到一张总表，便于横向对比。

## 一、核心结论

**苏俄讨论班几乎不存在"公司/学会式"的正式成文章程**。它们的"章程"实际上由三部分构成：

1. **主持人即章程**——规则由主持人的人格、习惯与权威决定；
2. **固定的形式要求**（如朗道的 Theoretical Minimum 考试大纲、Arnold 的问题列表传统）；
3. **口头传统与共同体文化**（如 Gelfand 的"Creative Discomfort"）。

| Mandelstam | 物理系研究生为主 |
| **朗道** | ✅ **Theoretical Minimum（朗道势垒）**：1 门数学 + 8 门理论物理口试；历史上仅约 43 人全部通过 |

### 3. 报告风格

| 讨论班 | 报告风格 |
|--------|---------|
| 鲁津 | 即兴提问，分派问题；鼓励学生反驳导师 |
| 柯尔莫哥洛夫 | **温和、引导式**；强调全面视野与开放问题 |
| **Gelfand** | **"Creative Discomfort"**：报告人常不在自己专长报告；Gelfand 随时打断、追问本质；可能"请下台"；强调严格证明 |
| **Arnold** | 强调**几何/物理直觉**；反对纯形式抽象；报告人若不解释"为什么"会被打断；每次开班公布 10–20 道问题 |
| Mandelstam | 强调物理直觉与实验联系 |

| Arnold | 奇点理论、动力系统、拓扑、辛几何、经典力学、数学物理 |

| 朗道 | 理论物理全领域 |

## 三、共性与差异

### 共同点（莫斯科学派的"DNA"）

1. **每周固定、雷打不动**——这种**节律性**是苏俄讨论班文化的核心。
2. **主持人绝对权威**——讨论班风格由主持人定，更换主持人则讨论班变样。
3. **高度开放**——除朗道外，多数讨论班欢迎外来者旁听，没有"会员制"。
4. **跨学科倾向**——莫斯科学派反感"分科壁垒"，鼓励跨领域对话。
5. **人才培养优先**——讨论班的首要功能是**选拔与培养**新秀，而非"展示成果"。
6. **强调严格与本质**——反对华而不实的"灌水"报告。

### 差异点

1. **Gelfand 与 Landau 风格最近**——都是"高压式"主持人，但 Gelfand 强调"创造性不适"（心理压力），Landau 强调"理论最低标准"（知识门槛）。
2. **Arnold 与 Kolmogorov 风格较温和**——更鼓励直觉与发现，但 Arnold 对形式抽象毫不留情。
3. **Luzin 与 Mandelstam 时代较早**——讨论班形式更接近"师徒围坐"，制度化程度低。

## 四、如何重建一个"莫斯科式"讨论班？

基于上述规则，可总结出**重建一个苏俄风格讨论班的最小要素**：

1. ✅ **固定时间**（每周一次，雷打不动）；
2. ✅ **固定地点**（一个"神圣"的房间）；
3. ✅ **一位权威主持人**（能即兴提问、引导方向）；
4. ✅ **完全开放**（不设门槛，欢迎旁听）；
5. ✅ **报告人不在专长领域报告**（Gelfand 法则，迫使其当场思考）；
6. ✅ **可随时打断、追问**（不允许"念稿式"报告）；
7. ✅ **每学期公布问题列表**（Arnold 法则，给共同体设定方向）；
8. ✅ **跨学科主题**（鼓励不同领域对话）；
9. ✅ **主持人亲自参与推导**（而非"评论家"角色）；
10. ✅ **以培养新秀为核心目标**（讨论班 ≠ 汇报会）。
