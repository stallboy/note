# 莫斯科第 57 中学（Moscow School 57）

> 俄罗斯顶尖中学之一，以**数学班**著称，是莫斯科精英数学家最重要的输出地之一。

## 二、数学班的特色

### 1. 设立的年级
- **五年级数学班**（小学阶段入口）
- **八年级数学班**（初中阶段入口）

这是俄罗斯数学精英教育中**最早**的入口之一——五年级就开始选拔，远早于大多数其他国家。

### 2. 入学选拔
- 每年**四至五月**组织入学考试。
- 八年级考生需参加**专项科目考核**（数学为主）。
- 录取极为严格，每年只招数十人。

### 3. 师资
- 教师多为**莫斯科大学、斯捷克洛夫研究所、独立大学（IUM）的数学家和博士生**。
- 许多教师本身是著名数学家的学生，继承了 Gelfand、Arnold 学派的讨论班传统。

### 4. 课程理念
- **重证明、重直觉、重开放问题**——与应试完全对立。
- 大量采用**问题驱动教学**，鼓励学生独立探索。
- 教学风格延续了 Gelfand/Arnold 讨论班的精髓：随时打断、追问"为什么"。

## 三、与大学讨论班体系的关系

第 57 中学的数学班与莫斯科大学的顶级讨论班形成"**直通车**"：

```
[57 中学数学班]  →  [莫斯科大学数力系 / IUM]
                              ↓
                  [Gelfand / Arnold / Novikov 讨论班]
```

许多 57 中学的毕业生在大学低年级就能跟上顶级讨论班的节奏，因为他们中学阶段已经习惯了讨论班式学习。

## 四、校友群

第 57 中学是俄罗斯数学家密度最高的中学之一。其校友包括多位国际知名数学家、菲尔兹奖/沃尔夫奖得主的合作者、ICM 报告人，以及国际数学奥林匹克金牌得主。具体校友名单参见：
- [维基百科 School 57 页面](https://en.wikipedia.org/wiki/Moscow_State_School_57)（含详细 alumni 列表）
