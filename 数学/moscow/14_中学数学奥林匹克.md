# 莫斯科中学数学奥林匹克与会议

> 中学数学讨论班体系的"**竞赛出口 + 研究展示出口**"。

---

## 一、莫斯科数学奥林匹克（MMO）

### 基本档案

| 项目 | 内容 |
|------|------|
| **全称** | Moscow Mathematical Olympiad（Московская математическая олимпиада, MMO） |
| **首届** | **1935 年** |
| **地位** | 世界**第二古老**的数学奥林匹克（仅次于 1934 年列宁格勒首届） |
| **对象** | 莫斯科市中学生（6–11 年级） |
| **主办方** | 莫斯科大学、MCCME、莫斯科数学会 |
| **频率** | 每年一届（通常 2 月或 4 月） |

### 历史意义
- 1934 年**列宁格勒**举办世界首届以"奥林匹克"命名的中学数学竞赛。
- **1935 年莫斯科**紧随其后举办，从此形成传统。
- MMO 的题目以**思路巧妙、不依赖超纲知识**著称，是俄罗斯数学讨论班思想的"考题版"。
- 来源：[历史上的首届"奥林匹克"数学竞赛（PDF）](https://www.sciopen.com/local/article_pdf/10.19789/j.1004-9398.2024.01.005.pdf)

### 题型特色
| 类别 | 特点 |
|------|------|
| **几何** | 强调几何变换（旋转、反演）、复数法、射影思想 |
| **不等式** | AM-GM、Cauchy-Schwarz 的巧妙应用 |
| **组合** | 不变量、鸽笼、构造 |
| **数论** | 同余、整除、二次剩余 |
| **逻辑** | 经常含趣味性极强的"游戏策略"题 |

### 历届题目档案
- **MMO 1935–1997 几何题汇总**（136 页）：https://imogeometry.blogspot.com/p/moscow_17.html
- **第 63 届 MMO 试题（Scribd）**：https://www.scribd.com/document/126547016/LXIII-Moscow-Mathematical-Olympiad-Russia
- **AoPS Olympiad Geometry Problems**：https://artofproblemsolving.com/wiki/index.php/Category:Olympiad_Geometry_Problems

- 苏联 1980 年发起，现已发展为国际赛事。
- 题目风格延续了 MMO 的"思路巧妙"传统。

## 三、研究展示出口：莫斯科中学生数学会议

### 1. 莫斯科中学生数学会议（MMCHSS）
- **全称**：Moscow Mathematical Conference for High School Students
- **性质**：中学生**学术报告会议**，不是比赛。
- **目标**：让中学生**经历完整的科研—报告—答辩流程**——讨论班思想的极致体现。
- **研究论文（ResearchGate）**：[Research Projects and Moscow Mathematical Conference for High School Students](https://www.researchgate.net/publication/399174983)
- **arXiv（俄文 PDF）**：https://arxiv.org/pdf/2512.22191

### 2. 柯尔莫哥洛夫读书会（Kolmogorov Readings）
- 见 [10_柯尔莫哥洛夫寄宿学校.md](./10_柯尔莫哥洛夫寄宿学校.md)。
- 中学生学术报告会议，由 AESC MSU 主办。

## 六、讨论班思想在奥赛中的体现

MMO 的题目设计哲学与 Gelfand/Arnold 讨论班一脉相承：

| 讨论班理念 | MMO 题目体现 |
|-----------|-------------|
| **追问本质** | 题目常需"想清楚"而非"算到底" |
| **反对形式化** | 不依赖超纲定理，鼓励初等解法 |
| **多种解法** | 几何题常有 3–5 种本质不同的证法 |
| **物理直觉**（Arnold 传统） | MMO 有时含物理味浓厚的应用题 |
| **开放问题** | 一些题目是开放研究问题的"初等版" |
