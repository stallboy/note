# 《Kvant（量子）》杂志——中学生的"纸质讨论班"

> 1970 年创刊的苏联中学生数理科普月刊，是俄罗斯数学精英教育体系中最独特的"跨地区讨论班"。

---

## 一、基本档案

| 项目 | 内容 |
|------|------|
| **杂志名** | **Kvant（Квант）**，意为"量子" |
| **创刊** | **1970 年** |
| **主办方** | 苏联科学院 + 莫斯科大学（创刊时） |
| **对象** | **中学生、大学生、中学教师** |
| **学科** | 物理 + 数学（并重） |
| **周期** | 月刊（创刊时）/ 双月刊（后期） |
| **巅峰发行量** | **约 20 万份** |
| **数字化档案** | **https://www.kvant.digital/** （1970 年至今全部期刊） |

## 二、定位与作用

《Kvant》是苏联数学精英教育的"**线上讨论班**"——在没有互联网的年代，它把全国的天才少年连成一个学术共同体：

1. **面向全国天才少年**——尤其是没有机会进入莫斯科/列宁格勒特科中学的外地学生。
2. **顶级作者**：阿诺德（V. I. Arnold）、柯尔莫哥洛夫（A. N. Kolmogorov）、曼宁（Yu. I. Manin）、盖尔范德等**第一流数学家亲自撰稿**。
3. **问题栏目**：每期公布一批精心设计的数学/物理问题，欢迎中学生提交解答，**优秀解答在后续期刊登**——这是讨论班"问答—展示"模式的延伸。
4. **专题文章**：每期 2–4 篇深入浅出的专题，从经典几何到前沿物理（如超弦、规范场）。

## 三、运作机制（"章程"）

1. **每月一期**（创刊时），含约 64 页内容。
2. **栏目结构**：
   - **专题文章**（数学/物理）
   - **问题栏目**（"Задачник Кванта" / Kvant's Problem Book）——每期 10+ 道新题
   - **学生解答展示**（上期问题的优秀解答）
   - **实验室**（物理实验）
   - **"小问答"**（脑筋急转弯式问题）
   - **书评与参考文献**
3. **问题解答竞赛**：每题设"**解答积分**"，年度积分最高的学生获奖励（如免费参加夏令营、推荐升学）。
4. **与奥赛体系联动**：许多 IMO、全苏奥赛选手都是 Kvant 的活跃投稿者。
5. **"Kvant Library"丛书**：阿诺德等人推动的衍生书系，把杂志专题结集出版。

## 四、关键作者与影响

### 主要撰稿人（数学）
- **V. I. Arnold（阿诺德）**：长期撰稿，许多文章后来收入《Arnold's Problems》。
- **A. N. Kolmogorov（柯尔莫哥洛夫）**：创刊人之一，撰写多篇概率论、信息论科普。
- **Yu. I. Manin（曼宁）**：代数几何、数论。
- **V. I. Arnold 的学生群**：奇点理论专题。

### 影响力
- **20 万份发行量**——在没有互联网的时代，这是**世界上发行量最大的数理科普杂志之一**。
- 直接孕育了一代俄罗斯数学家：很多菲尔兹奖得主、沃尔夫奖得主童年时期都是 Kvant 的读者和解题者。
- 阿诺德推动莫斯科大学数学专业学生在 Kvant 上发表大量论文，形成"**中学生—大学生—研究者**"的接力。

## 五、与《Quanta Magazine》的区分（重要！）

| 杂志 | 全称 | 创办 | 性质 |
|------|------|------|------|
| **Kvant（《量子》）** | Квант | 1970，苏联 | 中学生数理科普月刊（俄文） |
| **Quanta Magazine** | — | 2013，西蒙斯基金会 | 英文在线科普杂志，面向大众 |

**两者并非同一刊物**，不要混淆。

## 七、Kvant 的当代延续

- 俄文版仍在出版（双月刊），数字档案馆完全免费。
- 当代衍生品：**"Kvant Library"** 丛书（AMS 翻译出版部分英文版）。
- 对中国《数学文化》《数学通讯》等科普杂志有深远影响——但中文杂志的发行量（数千份）远不及 Kvant 的 20 万份。
