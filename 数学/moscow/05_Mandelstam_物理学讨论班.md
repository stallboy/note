# 曼德尔施塔姆物理学讨论班（Mandelstam Seminar，1930s–1944）

> 莫斯科大学物理学派的中心讨论班之一，奠定苏联非线性振动、无线电物理、量子力学诠释传统。

## 一、基本档案

| 项目 | 内容 |
|------|------|
| **主持人** | Leonid Isaakovich Mandelstam（Л. И. Мандельштам，曼德尔施塔姆，1879–1944） |
| **起讫** | **1930 年代初 – 1944 年**（Mandelstam 1944 年逝世后由学生 Papalexi、Andronov 等延续） |
| **频率** | 每周固定举行 |
| **地点** | 莫斯科大学物理系 / 苏联科学院物理问题研究所 |
| **主题** | 非线性振动、无线电物理、光学、量子力学诠释、统计物理 |

## 二、讨论班特点

1. **1930 年代起聚焦"非线性振动"**——Mandelstam 是该领域奠基人之一。
2. **强调物理直觉与实验观察**，与莫斯科数学学派的形式化倾向形成互补。
3. 培养了 **A. A. Andronov（安德罗诺夫）**、**N. D. Papalexi**、**M. A. Leontovich**、**S. M. Rytov** 等学派骨干。
4. 与 **朗道讨论班** 形成 20 世纪苏联理论物理的两大中心（前者偏实验/无线电，后者偏纯理论）。
5. 在**量子力学诠释**（系综诠释）方面影响深远——Mandelstam 学派主张统计（系综）诠释，反对哥本哈根诠释的某些激进推论。

## 三、与莫斯科数学学派的关系

- Mandelstam 讨论班的参与者中，许多人（如 Khinchin、Alexandrov、Landau 等）也是莫斯科学派跨学科圈子的一员。
- 这种"**数学—物理联合讨论**"是莫斯科学派的标志性特征，区别于西欧纯理论物理圈子。
