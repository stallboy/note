# 阿诺德讨论班（Arnold's Seminar on Singularity Theory，1960s–2010）

> **档案最完整的莫斯科数学讨论班**——PDMI 网站保留了 talks 时间表、问题列表、参与者论文等大量原始资料。

## 一、基本档案

| 项目 | 内容 |
|------|------|
| **主持人** | Vladimir Igorevich Arnold（В. И. Арнольд，弗拉基米尔·阿诺德，1937–2010） |
| **起讫** | **1960 年代 – 2010 年**（Arnold 2010 年 6 月 3 日在巴黎逝世） |
| **频率** | **每周二 16:20 – 18:00** |
| **地点（莫斯科）** | 莫斯科大学主楼 **14-14 教室** |
| **地点（巴黎，1993 起）** | 巴黎高等师范学校（École Normale Supérieure），**周二 16:20 – 18:00 同步举行** |
| **主题** | 奇点理论（Singularity Theory）及相关：动力系统、拓扑、代数几何、微分方程、辛几何、经典力学、数学物理等 |
| **官方网站** | http://www.pdmi.ras.ru/~arnsem/ （由圣彼得堡斯捷克洛夫数学研究所 PDMI 托管） |

## 二、"章程"（实际运作规则）

1. **固定时间地点**：每周二 16:20–18:00，主楼 14-14 室，雷打不动数十年。
2. **每次开班首先由 Arnold 公布一批问题**（problem list），通常 **10–20 道**，涵盖奇点理论、动力系统、几何、经典力学等。
3. **问题列表每半年更新一次**（春秋两季），形成流传后世的 **"Arnold's Problems"** 系列。
4. **报告人轮换**，来自莫斯科大学、PDMI、独立大学（IUM）及国际访客。
5. **风格**：Arnold 强调**几何直觉与物理直觉**，反对纯粹形式化的"法国式"抽象。报告人若只念公式而不解释"为什么"，常被当场打断。
6. **开放式讨论**：欢迎本科生、研究生旁听；Arnold 乐于与年轻人讨论。
7. **强调"发现"**：Arnold 认为"数学是物理的一部分（实验科学）"，鼓励从具体问题出发，寻找新的数学现象。

## 五、Arnold 的教学风格与轶事

- **习惯给学生出大量技巧性练习题**，精选后结集为 **《Arnold's Problems》**。
- **不满 20 岁即解决希尔伯特第 13 问题**（连续函数叠加表示问题），师承柯尔莫哥洛夫。
- 1995 年接受采访时回忆："当年顶级数学家在莫斯科齐聚一堂"（见下方专访）。
- 反对 Bourbaki 形式主义，认为"数学是实验科学"。
