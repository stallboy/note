# Kvant（《量子》）杂志中文译丛

> 俄罗斯/苏联经典数理科普杂志 **Kvant（Квант，《量子》）** 的中文精选译丛，服务于"回龙观数学圈"。
> 1970 年由数学家 **柯尔莫哥洛夫（Kolmogorov）** 与物理学家 **基科因（Kikoin）** 联合创办，是 20 世纪最有影响力的中学数理科普杂志之一，与匈牙利 KöMaL 齐名。巅峰期发行约 20 万册，涌现大量 IMO 金牌与未来数学家。2011 年纸刊停刊，电子版由 MCCME 维护。

```
├── ocr/<篇>/                      ← 主译丛 OCR 备料（ru.md + meta.json）
└── scripts/                       ← 流水线脚本
```

**三层解耦结构**（OCR 与翻译分离，重译不重跑 MinerU）：
- 扫描页（`scans/` / `primary/scans/`）→ OCR 备料（`ocr/ru.md` + `meta.json`）→ 译文（`articles/`）

## 流水线（已就绪，可复用）

每篇：**定位页码 → 下载扫描页 → MinerU OCR（cyrillic, pipeline）→ 归档三层 → 翻译 + review**

核心脚本（`scripts/`）：
- `parse_authors.py` — 抓 MCCME 作者页定位页码（slug 规则：kolmogorov_a / solovev_yu / vasilev_n / sharygin_i）
- `download_pages.py` / `batch_prepare_*.py` — 下载（kvant.digital jpg 或晚期 MCCME pdf）
- `archive_ocr.py` — MinerU 产物归档（ru.md + meta.json + fig_pXX_NN.png 裁图）
- `batch_prepare_kmsh_todo.py` — 小学 70 篇批量备料（并发5）

**关键坑（已验证）**：
- MinerU bbox 是内部坐标非原图像素，裁图用 `extract -f md` 自动导出，别手动用 bbox 裁
- MCCME 作者页 windows-1251 + `&nbsp;`（需 `html.unescape`）
- 1998 年等晚期扫描在 MCCME `/pdf/` 而非 kvant.digital
- MinerU 并发 5 稳定，47 并发触发 429

翻译用 **Workflow 并行**（每 agent 一篇：读 ru.md + meta.json → 翻译 → zai 图像分析抽查公式 + grep 图引用 review）。
