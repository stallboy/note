## 流水线（已就绪，可复用）

1. 抓取全量 `scripts/scrape_kmsh.py` → `_draft/kmsh_full.json`（819 篇）
2. 翻译标题+评分 `kmsh-translate-819` Workflow → `_draft/kmsh_zh_page_*.json`
3. 全量目录 `primary/full_list.md`（819 篇含中文名/评分/难度）
4. 选目+定位 `scripts/locate_kmsh_todo.py` → `_draft/kmsh_todo_located.json`
5. 下载+OCR+归档 `scripts/batch_prepare_kmsh_todo.py`（并发5）→ `primary/ocr/<PID>/ru.md`
6. 翻译+review Workflow（并发5/2）→ `primary/articles/<PID>_<标题>.md`

**目录结构**：
```
primary/
├── scans/<PID>/p*.jpg + fig_*.png   # 扫描页 + 裁图
├── ocr/<PID>/ru.md + meta.json      # OCR 备料(可重译)
├── articles/<PID>_<标题>.md         # 中文译文(120篇)
├── full_list.md                    # 819篇全量目录
└── README.md                       # 本文件
```
