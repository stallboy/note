# 翻译工作规范

> 本文件规定 Kvant 中文译丛的统一体例，确保 50 篇译文风格、格式、质量一致。

---

## 一、技术发现（已验证的工作流）

经过对 MCCME 旧站与 kvant.digital 新站的实测，确认：

### 1.1 图片源
**kvant.digital 新站**提供整期按页扫描的 JPG，URL 格式稳定：
```
https://www.kvant.digital/data/kvant_YYYY_N/jpg/NNNN.jpg
```
- `YYYY`：年份（1970–1990s 验证可用）
- `N`：期号（1–12）
- `NNNN`：页码（0000 起算，0000 = 封面）

示例：1970 年第 1 期第 16 页 → `https://www.kvant.digital/data/kvant_1970_1/jpg/0016.jpg`

### 1.2 MCCME 旧站（kvant.mccme.ru）
- 1970/01/index.htm 等目录页**已不含文章链接**（改版后变空导航）
- 作者索引页 `au/作者.htm` 仍可用，用于选目
- 旧站的单页 GIF 链接已失效或结构变化，**统一改用 kvant.digital**

### 1.3 单期页数
- 每期通常 60–80 页（0000–0064 等）
- 一篇文章通常占 4–10 页连续页码

## 二、文件命名规范

### 2.1 译文文件
```
articles/NNN_作者姓氏_年份_期号_中文短标题.md
```
示例：
- `001_arnold_1970_01_速度合成.md`
- `002_kolmogorov_1971_03_数学真理.md`

### 2.2 图片目录
```
images/YYYY_NN_作者_短标题/pXX.jpg
```
示例：`images/1970_01_arnold_speed/p16.jpg`

### 2.3 图片下载脚本
每篇文章对应一个下载任务，下载该文章占用的全部页码：
```bash
for n in 16 17 18 19; do
  curl -s -o "images/1970_01_arnold_speed/p${n}.jpg" \
    "https://www.kvant.digital/data/kvant_1970_1/jpg/00${n}.jpg"
done
```

### 2.4 从整页扫描中提取真正的插图

整页扫描 `pNN.jpg` 里 90% 是俄文文字，真正的插图（几何图、函数图、装置图）
只占一小块。**译文里应引用裁出的插图，而不是整页**，阅读体验更好。

**命名规范**：
```
images/YYYY_NN_作者_短标题/fig_pXX_NN_描述.png
```
- `fig_` 前缀区分"裁出的插图"与"整页扫描 pNN.jpg"
- `pXX`：来自哪一页
- `NN`：该页上的第几张图（01、02…）
- `描述`：中文简短描述（如 `samopisets`、`verkhnyaya_polukrug`）
- 示例：`fig_p35_01_samopisets.png`

**工作流（5 步，已验证）**——用根目录下的 `extract_figures.py`：

**第 1 步：密度分析，定位候选区域**
```bash
python extract_figures.py analyze images/1970_01_kolmogorov_function/p35.jpg
```
脚本输出该页上"黑像素密度异常高"的连续区块（插图通常峰值 > 0.4），
作为给 MCP 重点核查的候选。

> ⚠ 注意：**密集的数学公式段落也会触发高密度**（如连分数展开式）。
> 密度分析只能定位"候选"，**不能**单独判定是不是图。

**第 2 步：生成缩略图**
```bash
python extract_figures.py thumb images/.../p35.jpg 900
```
生成 `p35_thumb.png`（约 900×1343），供下一步上传。

**第 3 步：MCP 精确判定（在对话中手动操作）**
1. 用 **Read 工具**读取刚生成的 `p35_thumb.png`——它会把图上传到 CDN 并返回 URL
   （不能直接读本地图：MCP 的 `analyze_image` 只接受远程 URL；
   也不能直接喂 kvant.digital 的 URL——某些期号会报 1210 解析错误）
2. 把返回的 CDN URL 喂给 **`analyze_image`**，提示词模板：
   ```
   这是《Квант》[年份]№[期号]第[NN]页，尺寸 [W]x[H]。
   找出页面上所有真正的插图（几何图、函数图、装置图——不是文字、不是公式）。
   对每张给出像素边界框 top,bottom,left,right（在这张 [W]x[H] 图上），
   并简述内容。如果全是文字和公式，请明确说"无插图"。
   ```
3. 记下 MCP 返回的每张图的 `(left, top, right, bottom)` 和缩略图尺寸

**第 4 步：按坐标裁剪**
```bash
# 按缩略图坐标裁（脚本自动换算回原图 + 8px 余量）
python extract_figures.py crop images/.../p35.jpg 900 1343 450 270 820 560 \
    images/.../fig_p35_01_samopisets.png
# 或直接按原图坐标
python extract_figures.py crop-orig images/.../p35.jpg 600 360 1093 746 \
    images/.../fig_p35_01_samopisets.png
```

**第 5 步：MCP 二次验证**
脚本会同时输出 `_preview.png`（≤500px）。再用 Read + analyze_image 让 MCP 确认：
"这张图完整吗？切边了吗？混入文字了吗？" 通过后才算完成。

**在译文中引用**：
```markdown
![图：自记仪（самописец）的原理——旋转记录筒与笔，裁自第 35 页](../images/1970_01_kolmogorov_function/fig_p35_01_samopisets.png)

*（上图从原文整页扫描 `p35.jpg` 中裁出；整页见 [p35.jpg](../images/1970_01_kolmogorov_function/p35.jpg)。）*
```

> 既给出"干净的插图"，又保留"整页原文"的链接——读者既能看清图，
> 又能对照原文核对。

**何时跳过提取**：如果某页全是文字和公式（MCP 明确说"无插图"），
译文里就**不要**插图，直接用文字描述即可。不要为了"每页都有图"
而强行塞整页扫描——那只会让译文变得难读。

## 三、译文格式规范

### 3.1 文档头（每篇译文统一）
```markdown
# [中文标题]

> **原标题**：[俄文原标题]
> **作者**：[作者俄文名 + 中文音译]（[生卒年/身份]）
> **译自**：Квант [年份], № [期号], с. [起页–止页]
> **原文扫描**：[kvant.digital URL]
> **主题**：[代数/几何/数论/组合/不等式/物理数学/数学思维]
> **难度**：[★/★★/★★★]（★=初中可读，★★=高中，★★★=需大学背景）
> **译者**：[译者/翻译日期]

---

[正文]
```

### 3.2 图片引用
正文图片用相对路径引用本地下载的文件：
```markdown
![图 1：[图示描述]](../images/1970_01_arnold_speed/p16.jpg)
```
- 每张图必须有**图示描述**（说明该图在讲什么）
- 图注另起一行，斜体：`*图 1：...*`

### 3.3 数学公式
- **行内公式**：`$...$`，如 $v = u + w$
- **行间公式**：`$$...$$`
- **矩阵/分段函数**：用 LaTeX 环境重写，不保留原图公式
- **希腊字母**：用 `\alpha`、`\beta` 等，不写 "α"
- **重要**：俄文数学术语的中译对照表见本文件第四节

### 3.4 段落与标题
- 原文的节标题（§1, §2...）保留编号
- 作者强调用 **加粗**，不用下划线
- 长段落适当分段，但忠实原文结构

### 3.5 译者注
正文需补充说明时用：
```markdown
> **译者注**：[说明内容]
```

## 五、质量标准

每篇译文需满足：
- [ ] 原文扫描页已全部下载到 `images/`
- [ ] 译文正文完整（不跳节）
- [ ] 数学公式用 LaTeX 重写
- [ ] 每张图都有描述性图注
- [ ] 术语符合第四节对照表
- [ ] 文末标注原文 URL、作者、期号
- [ ] **校对**：至少一处与原扫描页核对（防止 OCR/翻译串行错误）

---

## 六、翻译质量策略（重要）

由于原文是**扫描图片**（非可复制文字），翻译经过两步：
1. **OCR + 肉眼读图**：从扫描页识别俄文 + 数学公式
2. **中译**：基于识别文本翻译

风险与对策：
| 风险 | 对策 |
|------|------|
| OCR 错认俄文字母（ш/щ、и/й） | 关键术语对照术语表 |
| 数学公式识别错误（指数、下标） | 每个公式与扫描页核对 |
| 俄语长句结构复杂 | 允许拆分为多个中文短句 |
| 苏联时代用语（如"同志"、"五年计划"） | 保留时代感，不意译为现代词 |

## 七、关于本译丛的定位（再次明确）

- **目标**：服务于回龙观数学圈的**讨论素材**，不是出版级译作
- **读者**：初二到高中学生、家长、数学圈主持人
- **取舍**：宁可漏译广告/读者来信，不可漏译**正文数学内容**
- **版权**：自用、非商业；如对外公开须先获 MCCME 授权
