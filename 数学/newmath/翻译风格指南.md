# 新数学丛书翻译风格指南（Sawyer / Niven / Pólya 三本通用）

> 制定日期：2026-07-05
> 适用：NML/2《What Is Calculus About?》、NML/1《Numbers: Rational and Irrational》、NML/26《Mathematical Methods in Science》
> 技术路线：MinerU→LaTeX→人工校译→XeLaTeX→纯中文 PDF

---

## 一、总体原则

1. **忠实 + 流畅**：数学科普书的灵魂是"把思想讲清楚"。译文要让中文读者读得懂、读得顺，而不是逐字死译。
2. **不增删原意**：原文的例子、类比、提问、口吻一律保留；译者不擅自补充内容或删减。
3. **结构与原文严格对应**：章节、段落、公式、图、题号一一对应，**不重排、不合并、不拆分**，方便中英对照核查。
4. **保留作者风格**：Sawyer 口语化、亲切；Niven 严谨清晰；Pólya 启发式、对话感——各保留其笔调。

## 二、LaTeX 处理规则（最关键）

- **数学公式一律原样保留**：行内 `$...$`、行间 `\[...\]`、`equation/align` 环境内的符号、字母、数字**一个字符都不改**，只翻译公式外的正文。
- **只翻译"自然语言文字"**：正文、标题、图注（caption）、表头、列表项。
- **保留所有结构命令**：`\section{}`、`\subsection{}`、`\textbf{}`、`\emph{}`、`\begin{itemize}` 等，只翻译花括号/环境内的文字。
- **图片引用 `\includegraphics{...}` 路径原样保留**，不动文件名。
- **清理 mineru 噪声**：去掉重复的页眉页脚、孤立的页码、OCR 产生的乱码标记。注意 `re.sub` 含反斜杠时用 `lambda` 而非字符串替换（避坑）。
- **章节标题去重去噪**：去除 mineru 偶尔产生的重复标题、难度标记等。
- **交叉引用**：原文 "see Chapter 4" 译为"见第 4 章"，"Figure 3" 译为"图 3"，"Exercise 5" 译为"习题 5"。

## 三、术语规范

- **首次出现**重要数学术语时，括注英文原词：如"极限（limit）"。其后用中文。
- **全书同一术语用同一译名**，建立术语表（每本书开译时维护 `术语表.md`）。
- 通用术语对照（待各书补充细化）：

| 英文 | 中译 |
|---|---|
| number | 数 |
| rational/irrational number | 有理数/无理数 |
| integer | 整数 |
| fraction | 分数 |
| decimal | 小数 |
| limit | 极限 |
| derivative | 导数 |
| integral | 积分 |
| function | 函数 |
| variable | 变量 |
| continuous | 连续 |
| infinity | 无穷 |
| proof | 证明 |
| theorem | 定理 |
| lemma | 引理 |
| corollary | 推论 |
| exercise | 习题 |
| example | 例 |

## 四、人名处理

- 数学家/科学家：**首次**给"中文译名（英文原名）"，**其后**用中文译名。
- 沿用通行译名：如 Pythagoras 毕达哥拉斯、Euclid 欧几里得、Archimedes 阿基米德、Newton 牛顿、Leibniz 莱布尼茨、Einstein 爱因斯坦、Euler 欧拉、Pólya 波利亚。
- 不知名人名首次可保留英文，后用音译。

## 五、标点与排版

- **正文中文全角标点**：，。：；？！""''（破折号 ——，省略号 ……）。
- **公式内标点沿用原 LaTeX**（英文逗号、句号）。
- 数字、公式编号、章节号用**半角**。
- 中英文混排时中英文之间自然空格由 xeCJK 自动处理。

## 六、xeCJK 配置（preamble 模板）

- **正文中文字体**：霞鹜文楷（LXGW WenKai），与之前 mvp 项目一致。
- 数学字体：用 `mathpazo` 或默认 Computer Modern（视效果）。
- preamble 草案（待 mineru 输出后按实际微调）：

```latex
\documentclass[11pt]{book}  % 或按 mineru 输出
\usepackage{xeCJK}
\setCJKmainfont{LXGW WenKai}  % 霞鹜文楷
\setCJKsansfont{LXGW WenKai}
\setCJKmonofont{LXGW WenKai Mono}
\usepackage{amsmath,amssymb,amsthm}
\usepackage{graphicx}
\graphicspath{{images/}}  % mineru 提取的图片目录
\usepackage{geometry}
\usepackage{hyperref}
% 其它按 mineru 输出补全
```

## 七、图片处理

- mineru 提取的图片保留在各书 `images/` 目录，**文件名不改**。
- `.tex` 中 `\includegraphics` 路径指向这些图片。
- **图注（caption）翻译为中文**。
- 检查图片清晰度；若图中的英文标注是理解关键且模糊，在图注中补译说明。
- 排版上图片位置尽量贴近原文出现处。

## 八、质量检查清单（每轮 review 用）

**第 1 轮 · 准确性（对照原文）**
- [ ] 逐段对照，无漏译、无错译
- [ ] 数字、日期、人名无误
- [ ] 题号/章节号连续正确

**第 2 轮 · 数学规范**
- [ ] 所有公式完整、未被破坏（符号未丢失或变形）
- [ ] 术语全书统一、符合数学规范
- [ ] 定理/证明结构正确

**第 3 轮 · 中文与排版**
- [ ] 中文流畅、无翻译腔
- [ ] 标点规范（全角正文 / 半角公式）
- [ ] 图片显示正常、位置合理
- [ ] 交叉引用正确
- [ ] 编译无 error（warning 逐个评估）

## 九、工作流（每本书）

1. MinerU extract → `latex + images`（保留中间结果）
2. 检查 .tex 结构，清理噪声
3. 加 xeCJK preamble，**先编译原文 LaTeX 确认能跑通**（建立基线）
4. 分章节翻译（subagent 并发，最多 5）
5. 合并 → xelatex 编译 → 修错
6. 三轮 review（准确性 → 数学规范 → 中文排版）

## 十、已知技术坑（来自既往项目）

- **Read 报 PDF 页数会误导**，须 pypdf 验真页数。
- **MinerU 超 200 页须 `--pages` 分批**（这三本都 <200 页，应无此问题，但 Pólya 较厚需留意）。
- **`re.sub` 含反斜杠须用 `lambda`**，避免反斜杠转义错误。
- **图片文件名 hash 偶有 OCR 错**，匹配时用前缀模糊匹配。
- **MinerU 有限流**（HTTP 429），三本并发若遇限流则降为串行重试。
