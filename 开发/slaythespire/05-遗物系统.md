# 杀戮尖塔 — 遗物系统

## 一、系统概述

遗物(Relic)是**永久性被动道具**，获取后在本次攀登中持续生效。遗物系统是杀戮尖塔中仅次于卡牌系统的第二重要系统——它提供了跨战斗的持续性增益，能够定义流派、弥补弱点、创造联动。

**系统定位**：遗物是"被动能力层"，与卡牌的"主动操作层"互补，共同构成玩家的完整能力体系。

## 二、核心机制

### 1. 获取途径

| 途径 | 遗物品质 | 频率 |
|------|----------|------|
| Boss击杀 | Boss级（三选一） | 每幕末尾1次 |
| 精英击杀 | 普通/罕见/稀有 | 不确定 |
| 宝箱 | 取决于宝箱大小 | 每幕约1次 |
| 商店购买 | 取决于库存 | 需要金币 |
| 事件 | 特定事件专属 | 不确定 |

### 2. 稀有度与掉率

**一般来源**：

| 稀有度 | 概率 |
|--------|------|
| 普通 (Common) | 50% |
| 罕见 (Uncommon) | 33% |
| 稀有 (Rare) | 17% |

**宝箱掉率递进**：

| 稀有度 | 小宝箱 | 中宝箱 | 大宝箱 |
|--------|--------|--------|--------|
| 普通 | 75% | 35% | 0% |
| 罕见 | 25% | 50% | 75% |
| 稀有 | 0% | 15% | 25% |

**设计思想**：宝箱越大，高品质遗物概率越高。大宝箱保证不出普通遗物，这是一种"奖励递进"——当玩家获得大宝箱（通常来自更高风险的路径选择）时，奖励品质也相应提升。

### 3. 遗物分类

| 类型 | 数量 | 说明 |
|------|------|------|
| 起始遗物 | 4 | 每个角色自带1个 |
| Boss遗物 | ~10 | 击败Boss后三选一，多数带负面效果 |
| 普通遗物 | ~50 | 基础增益效果 |
| 罕见遗物 | ~40 | 较强或特定条件下触发 |
| 稀有遗物 | ~30 | 强力但稀有 |
| 商店遗物 | ~15 | 只在商店出售 |
| 事件遗物 | ~15 | 仅从特定事件获取 |
| 角色专属 | 每角色9-11个 | 铁甲/猎人各11个，机器人/观者各9个 |

### 4. 掉落限制

- **同类不重复**：已获得的遗物不会再次掉落
- **篝火遗物上限**：最多同时持有2个篝火遗物（铲子、杠铃、和平烟斗）
- **条件限制**：部分遗物只在满足条件时出现（如瓶装系列需要牌组中有对应类型的卡）
- **楼层限制**：部分遗物在特定楼层以下才出现，确保辅助性遗物在早期获取

## 三、Boss遗物的风险-收益设计（核心）

Boss遗物是杀戮尖塔中**设计最精妙的系统之一**。击败Boss后，玩家从3个Boss遗物中选1个。绝大多数Boss遗物都附带负面效果。

### 能量类Boss遗物

| Boss遗物 | 收益 | 代价 | 设计分析 |
|----------|------|------|----------|
| Coffee Dripper | +1能量 | 不能在休息点休息 | 考验：你的卡组是否足够自给自足？ |
| Fusion Hammer | +1能量 | 不能在休息点升级卡牌 | 考验：你的卡组是否已经足够好？ |
| Cursed Key | +1能量 | 每次开宝箱获得一个诅咒 | 考验：你能否承受诅咒的污染？ |
| Philosopher's Stone | +1能量 | 敌人每回合获得1点力量 | 考验：你能否快速结束战斗？ |
| Snecko Eye | +1能量+抽2牌 | 所有卡牌费用随机0-3 | 考验：你能否接受极端的方差？ |
| Ectoplasm | +1能量 | 无法再获得金币 | 考验：你能否不靠商店？ |
| Runic Pyramid | +1能量 | 不能在回合结束弃牌 | 考验：你能管理10张手牌上限吗？ |
| Holy Water/Black Blood等 | 强化起始遗物 | 占用Boss遗物位 | 考验：强化角色特性 vs 获取新能力 |

**+1能量为什么如此重要**：

从3能量变为4能量，看似只增加了33%，但实际效果远超这个比例：

1. **额外的出牌机会**：4能量可以打出2张2费卡（3能量只能打出1张+1张1费卡）
2. **更灵活的回合规划**：4能量的组合可能性远多于3能量
3. **改变了"X费用"卡牌的上限**：旋风斩等X费用卡的伤害直接提升33%

**为什么Boss遗物必须有代价**：

如果+1能量没有代价，它将是无脑必选。代价的设计确保了：

- 每个Boss遗物都在"拷问"卡组的一个特定维度
- 选择Boss遗物不是"要不要强化"，而是"用哪个弱点换取强化"
- 有些局你不应该拿任何Boss遗物——这本身就是一个重要的决策

### 其他重要Boss遗物

| 遗物 | 效果 | 设计意义 |
|------|------|----------|
| Calling Bell | 获得3个随机遗物+1个诅咒 | 高风险高回报的"赌博" |
| Pandora's Box | 将所有打击和防御变为随机卡 | 极端的重构——你的基础卡是包袱还是资产？ |
| Busted Crown | +1能量 | 奖励卡三选一变为二选一 |
| Tiny House | 获得5个随机小奖励 | "什么都给一点"的中庸选择 |

### 不提供能量的Boss遗物

**设计思想**：并非所有Boss遗物都给能量。那些不给能量的Boss遗物需要足够强才能与能量类竞争：

- **Runic Cube**：每次受到伤害时抽1张牌——极其强大的过牌引擎
- **Snecko Eye**：虽然给能量，但其核心价值在于"抽2张牌"+费用随机化——它实际上是一个"方差放大器"
- **Pandora's Box**：直接重构你的整个基础牌组——这是一个"重新开始"的机会

## 四、遗物的功能分类

### 流派定义类

这些遗物可以直接定义一个流派的方向：

| 遗物 | 效果 | 驱动的流派 |
|------|------|-----------|
| Necronomicon | 每回合第1张消耗卡再触发一次 | 消耗流 |
| Kunai | 每回合打出3张攻击获得1敏捷 | 多段攻击流 |
| Shuriken | 每回合打出3张攻击获得1力量 | 多段攻击流 |
| Paper Krane | 对有虚弱的敌人受到伤害减少 | 虚弱控制流 |
| Toxic Egg | 所有非基础卡以升级版加入 | 卡组品质提升 |

### 弱点补偿类

这些遗物帮助弥补卡组的不足：

| 遗物 | 效果 | 补偿的弱点 |
|------|------|-----------|
| Orichalcum | 回合结束未获得护甲时获得6护甲 | 缺乏防御 |
| Anchor | 战斗开始获得10护甲 | 首回合脆弱 |
| Bag of Marbles | 战斗开始对全体敌人施加1易伤 | 缺乏debuff |
| Pen Nib | 每打出10张攻击，下一张攻击伤害翻倍 | 缺乏爆发伤害 |

### 资源管理类

| 遗物 | 效果 | 管理的资源 |
|------|------|-----------|
| Smiling Mask | 商店卡牌移除服务固定50金 | 卡组管理 |
| Membership Card | 商店物品打八折 | 金币 |
| Courier | 商店物品打折+战斗后可刷新 | 商店效率 |
| Cauldron | 战斗后获得药水 | 药水 |

## 五、遗物与卡牌的联动设计

遗物和卡牌的联动是杀戮尖塔策略深度的核心来源：

| 遗物 | 联动卡牌 | 效果 |
|------|----------|------|
| Dead Branch | 任意消耗卡 | 消耗一张卡后获得一张随机卡 → 无限消耗循环 |
| Necronomicon | Feel No Pain, Corruption | 消耗触发两次 → 双倍效果 |
| Du-Vu Doll | 任意诅咒 | 诅咒数量 = 力量值 → 诅咒变资产 |
| Evolve + Fire Breathing | 状态/诅咒 | 抽到状态牌时额外抽牌 + 造成伤害 |
| Tingsha | 任意弃牌 | 弃牌时造成3伤害 → 弃牌流获得伤害输出 |

**设计思想**：这些联动不是预先设计的"套装"，而是独立系统自然产生的化学反应。设计师只需要让每个系统足够自洽，联动就会自然涌现。这比预先设计"套装"要优雅得多。

## 七、设计启示

1. **Boss遗物的代价设计**：让强化本身也成为决策，而非无脑选择
2. **遗物驱动流派**：单个遗物可以改变整个卡组构建方向
3. **"涌现"而非"预设"的联动**：独立设计遗物和卡牌，让联动自然产生
4. **补偿型遗物降低Roguelike的挫败感**：当你没有好的防御牌时，Orichalcum提供保底
5. **稀有度=影响范围**：稀有遗物不是"数值更强"，而是"效果更独特"
