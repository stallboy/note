# 杀戮尖塔 — 负面机制设计

## 一、系统概述

杀戮尖塔的负面机制包括诅咒(Curse)、状态牌(Status)和各类Debuff。这些机制不是简单的"惩罚"，而是精心设计的**代价语言**——它们为其他系统的收益提供了"支付手段"，同时自身也可以被策略性地利用。

**核心理念**：在杀戮尖塔中，负面不是纯粹的负面——**惩罚即玩法**。诅咒可以是力量的来源（Du-Vu Doll），状态牌可以是过牌的引擎（Evolve），debuff是对敌人施加压力的手段。

## 二、诅咒系统 (Curse)

### 1. 核心规则

- 诅咒是**战斗后仍留在卡组中**的负面卡牌
- 绝大多数诅咒不可打出
- 诅咒只能变形(Transform)为其他诅咒（不会变成普通卡）
- 每种诅咒都有独特的惩罚方式

### 2. 诅咒完整列表

| 诅咒 | 效果 | 惩罚维度 |
|------|------|----------|
| **Ascender's Bane** | 不可打出，虚无(Ethereal) | 不可移除 |
| **Curse of the Bell** | 不可打出 | 不可移除 |
| **Necronomicurse** | 不可打出，消耗后回到手牌 | 不可移除，永久存在 |
| **Clumsy** | 不可打出，虚无 | 每回合自动消失（最温和） |
| **Decay** | 不可打出，回合结束受2伤害 | 即时HP伤害 |
| **Doubt** | 不可打出，回合结束获1层虚弱 | 持续性debuff |
| **Injury** | 不可打出 | 纯粹的手牌污染 |
| **Normality** | 不可打出，限制出牌不超过3张 | 限制操作空间 |
| **Pain** | 不可打出，打出其他牌时失1HP | 动态惩罚 |
| **Parasite** | 不可打出，被移除时失3最大HP | 移除惩罚 |
| **Regret** | 不可打出，回合结束按手牌数失HP | 根据状态惩罚 |
| **Shame** | 不可打出，回合结束获1层脆弱 | 持续性debuff |
| **Writhe** | 不可打出，固有(Innate) | 首回合必抽到 |

### 3. 三级不可移除诅咒

杀戮尖塔设计了三种**永久不可移除**的诅咒：

| 诅咒 | 来源 | 设计意义 |
|------|------|----------|
| Ascender's Bane | A10开局自带 | 进阶10的永久代价 |
| Curse of the Bell | Calling Bell遗物 | "3遗物+1诅咒"中诅咒的永久性 |
| Necronomicurse | Necronomicon遗物 | 消耗流引擎的永久代价 |

**设计思想**：这三种不可移除的诅咒有着共同的哲学——**永久性的代价匹配永久性的收益**：
- A10的Bane匹配A10-20的持续挑战
- Bell的诅咒匹配3个免费遗物
- Necronomicurse匹配死灵之书的强大消耗触发效果

关键细节：Necronomicurse在消耗后会回到手牌。这意味着它**可以被反复消耗**——配合Feel No Pain或Dark Embrace，每回合可以稳定触发消耗效果。这把"诅咒"变成了"引擎组件"。

### 4. 诅咒的层次化惩罚设计

诅咒的惩罚覆盖了多个不同维度：

```
轻度：Clumsy（虚无，自动消失）
  ↓
中度：Injury（占手牌位）、Decay（2HP/回合）
  ↓
重度：Normality（限制出牌数）、Pain（出牌罚HP）
  ↓
极重：Parasite（移除惩罚）、Writhe（首回合必抽）
```

**设计思想**：不同惩罚维度的设计确保了诅咒不仅是"强度不同"，而是"影响方式不同"：
- **Decay/Doubt/Shame**：每回合的持续性代价——影响长期战斗
- **Normality**：限制操作空间——影响当回合的决策
- **Pain**：动态惩罚——每次出牌都增加代价
- **Regret**：根据手牌数惩罚——惩罚大卡组和保留策略
- **Writhe**：固有(Innate)——首回合的干扰
- **Parasite**：惩罚移除行为——让你犹豫是否花钱移除

### 5. 诅咒的来源

| 来源 | 说明 |
|------|------|
| 事件 | 大量事件以诅咒为代价给予奖励 |
| Boss遗物 | Cursed Key每次开宝箱获得诅咒 |
| Calling Bell | 获得3遗物+1诅咒 |
| A10进阶 | 开局自带Ascender's Bane |
| 特定敌人 | 部分敌人会向牌组塞入诅咒 |

### 6. 诅咒的反转利用

杀戮尖塔最精妙的设计之一是**诅咒可以被策略性地利用**：

| 卡牌/遗物 | 如何利用诅咒 | 设计意义 |
|-----------|-------------|----------|
| Du-Vu Doll | 诅咒数量 = 战斗开始的力量值 | 诅咒 = 力量 |
| Blue Candle | 诅咒可打出（付出HP代价） | 诅咒 = 可打出的牌 |
| Fire Breathing | 抽到诅咒/状态牌时对全体敌人造成伤害 | 诅咒 = 伤害输出 |
| Bonfire Spirits | 献祭诅咒获得Spirit Poop遗物 | 诅咒 = 遗物 |
| Dark Embrace | 消耗非攻击牌时抽1牌 | Necronomicurse = 无限过牌 |

**设计思想**：这种"负面可以被利用"的设计体现了杀戮尖塔的核心哲学——**在限制中发现机会**。诅咒不只是"惩罚"，而是一种可以被聪明玩家转化为优势的"资源"。这极大地提升了游戏的策略深度和重玩价值。

## 三、状态牌系统 (Status Card)

### 1. 核心规则

- 状态牌是**仅在战斗中存在**的负面卡牌
- 战斗结束后**自动移除**
- 由敌人的攻击和技能混入牌库

**与诅咒的关键区别**：
- 状态牌是**临时性的**（战斗限定）
- 诅咒是**永久性的**（除非被移除）
- 状态牌的来源是**战斗中的敌人**
- 诅咒的来源是**事件、遗物、进阶**

### 2. 五种状态牌

| 状态牌 | 效果 | 来源 | 惩罚维度 |
|--------|------|------|----------|
| **Wound（伤口）** | 不可打出 | 多种敌人 | 纯粹的手牌污染 |
| **Slimed（粘液）** | 费用1，可消耗 | 史莱姆类 | 占用手牌和费用 |
| **Burn（灼烧）** | 不可打出，回合结束受2(4)伤害 | Orb Walker等 | 即时HP伤害 |
| **Dazed（晕眩）** | 不可打出 | Repulsor等 | 长期手牌堵塞 |
| **Void（虚空）** | 不可打出，抽到时失1能量，虚无 | Spire Growth等 | 能量惩罚 |

### 3. 状态牌的层次设计

```
最简单：Wound → 纯粹占手牌位
    ↓
轻度：Slimed → 占手牌+1费用（但可以消耗移除）
    ↓
中度：Burn → 每回合HP伤害（但虚无意味着不积累）
    ↓
重度：Dazed → 不可消耗、不可打出、不消失（战斗中永久存在）
    ↓
极重：Void → 抽到时失去能量+自动消失（最致命的即时惩罚）
```

**设计思想**：五种状态牌覆盖了不同维度的战斗干扰：

- **Wound**：最基础的手牌污染——让你少一张可用的牌
- **Slimed**：提供"消耗"的选项——你可以花1费消耗它，这创造了一个小决策
- **Burn**：增加了紧迫感——你不消除它就会持续受伤
- **Dazed**：长期威胁——它会堵塞抽牌堆和弃牌堆，影响整场战斗
- **Void**：最致命——失去1点能量在3能量系统中是巨大的代价

### 4. 状态牌的战术利用

| 卡牌 | 如何利用状态牌 | 角色 |
|------|---------------|------|
| Evolve | 抽到状态牌时额外抽1(2)牌 | 铁甲战士 |
| Power Through | 将2张Wound加入手牌，获得15(20)护甲 | 铁甲战士 |
| Fire Breathing | 抽到状态/诅咒牌时对全体敌人造成6(10)伤害 | 铁甲战士 |
| Second Wind | 消耗所有非攻击牌（含状态牌），每张获得5(7)护甲 | 铁甲战士 |
| Charon's Ashes | 消耗状态/诅咒牌时对全体敌人造成伤害 | 遗物 |

**设计思想**：铁甲战士特别擅长将状态牌转化为正面收益。这体现了**角色差异化设计的深度**——同样的负面机制，对不同角色有不同的影响：
- 对猎人来说，状态牌主要是"需要忍受的干扰"
- 对铁甲战士来说，状态牌可以成为"被利用的资源"

## 四、Debuff系统

### 1. 可施加给玩家的Debuff

| Debuff | 效果 | 应对策略 |
|--------|------|----------|
| 易伤 (Vulnerable) | 受到攻击伤害+50% | 避免被攻击、快速击杀 |
| 虚弱 (Weak) | 造成攻击伤害-25% | 使用非攻击手段 |
| 脆弱 (Frail) | 获得护甲-25% | 依赖非护甲防御 |
| 中毒 (Poison) | 每回合受X伤害，减1 | 清除毒、快速结束战斗 |

### 2. 对Debuff的防御手段

| 手段 | 类型 | 说明 |
|------|------|------|
| 人工制品 (Artifact) | Buff | 抵消X次debuff |
| Orange Pellets遗物 | 遗物 | 同回合打出攻击+技能+能力时清除所有debuff |
| Panacea卡 | 无色卡 | 获得1层人工制品 |
| 特定卡牌 | 各角色 | 如铁甲的Exhilarate、猎人的Expertise |

**设计思想**：Debuff的防御手段是稀缺的。大多数情况下，玩家需要通过策略（如控制战斗节奏、击杀施加debuff的敌人）来避免debuff，而非依赖清除手段。这种"预防胜于治疗"的设计让战斗更有前瞻性。

### 3. Debuff作为玩家武器

同样的debuff系统也是玩家施加给敌人的主要工具：

| Debuff | 对敌人的效果 | 核心卡牌 |
|--------|-------------|----------|
| 易伤 | 敌人受到伤害+50% | Bash, Uppercut, Searing Blow |
| 虚弱 | 敌人造成伤害-25% | Neutralize, Intimidate, Dark Shackles |
| 脆弱 | 敌人获得护甲-25% | Pierce Wail, Terror |
| 中毒 | 敌人每回合受X伤害 | Noxious Fumes, Catalyst, Bouncing Flask |

**设计思想**：Debuff系统的双向性（玩家和敌人都可以施加）创造了"属性战"的维度。玩家不仅要考虑直接的伤害输出，还要考虑如何通过debuff削弱敌人。易伤+50%的伤害加成相当于"1.5倍力量"，这使得debuff成为非常高效的输出放大器。

## 五、惩罚即玩法 — 核心设计哲学

杀戮尖塔的负面机制设计体现了三个层次的设计哲学：

### 第一层：惩罚作为代价

负面机制是获取正面收益的"货币"：
- 事件中接受诅咒换取遗物/卡牌
- Boss遗物以诅咒/HP为代价提供能量
- A10的Ascender's Bane是进阶挑战的"入场费"

### 第二层：惩罚作为教学内容

负面机制教导玩家游戏的核心机制：
- 第一次遇到状态牌时，玩家学会了"抽牌堆管理"
- 第一次被塞入诅咒时，玩家学会了"卡组精简的重要性"
- 第一次被易伤时，玩家学会了"防御比想象中更重要"

### 第三层：惩罚作为策略资源

高级玩家可以将负面机制转化为正面策略：
- Du-Vu Doll把诅咒变成力量
- Evolve把状态牌变成过牌
- Fire Breathing把负面牌变成AOE伤害
- Necronomicurse配合消耗卡创造无限循环

**设计思想**：这三个层次形成了一个"理解深度"的递进：
- 新手只看到第一层："负面是代价"
- 中级玩家理解第二层："负面可以教会我东西"
- 高级玩家掌握第三层："负面可以被利用"

这种"同一个系统在不同技能水平下呈现不同面貌"的设计，是杀戮尖塔能够同时服务新手和硬核玩家的关键。

## 七、设计启示

1. **惩罚不是设计的敌人**：精心设计的惩罚可以成为策略的核心
2. **层次化的惩罚设计**：从"占手牌位"到"限制操作空间"，不同维度的惩罚创造不同的策略考量
3. **"负面可利用"是高级策略深度**：当玩家学会利用惩罚时，游戏体验会产生质变
4. **临时 vs 永久的区别**：状态牌（临时）和诅咒（永久）的区别创造了两个不同层次的威胁
5. **不可移除诅咒的哲学**：永久代价匹配永久收益——这是"公平"的另一种形式
