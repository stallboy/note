# 杀戮尖塔 — 战斗系统

## 一、系统概述

战斗是杀戮尖塔的核心玩法循环。采用**回合制卡牌战斗**，玩家每回合从牌库中抽牌，消耗能量打出卡牌，与敌人进行策略对抗。战斗系统是所有其他系统的价值验证层——你获得的卡牌、遗物、药水，最终都要在战斗中证明自己的价值。

**系统定位**：战斗系统是游戏体验的"每时每刻"，是玩家投入最多注意力的环节。

## 二、核心机制

### 1. 回合流程

```
回合开始
  ↓
获得基础能量(3点)
  ↓
抽5张牌（从抽牌堆 → 手牌）
  ↓
玩家出牌阶段（消耗能量打出卡牌）
  ↓
回合结束
  ↓
弃掉未打出的手牌 → 弃牌堆
  ↓
敌人执行意图中的行动
  ↓
下一回合
```

### 2. 能量系统

| 参数 | 数值 | 说明 |
|------|------|------|
| 基础能量 | 3 | 每回合固定获得 |
| 能量继承 | 否 | 未用完的能量回合结束消失 |
| 能量上限 | 无硬上限 | 但实际很少有超过10的情景 |
| 能量来源 | 遗物/卡牌/药水 | Boss遗物+1、能量药水+2等 |

**设计思想**：

3点能量是一个极其精妙的数值。它恰好足够让玩家打出1张高费卡(2-3费)加1张低费卡(0-1费)，或者2-3张中等费用的卡。这个数值创造了以下效果：

- **不能什么都做**：你不可能在一回合内同时攻击、防御、增益
- **每回合都是新的两难**：攻还是守？铺buff还是打伤害？
- **费用成为卡牌价值的标尺**：1费卡和2费卡的价值差距远大于字面上的1倍

**能量不跨回合**：这是关键设计。如果能量可以储存，玩家会倾向于前几回合"存能量"然后爆发，这会让游戏变成单纯的"算回合"游戏。能量不可储存迫使玩家在**每个回合**都做出最优决策。

### 3. 护甲系统 (Block)

| 参数 | 数值 |
|------|------|
| 基础来源 | 防御类卡牌 |
| 属性加成 | 每点敏捷(Dexterity) +1 |
| 跨回合 | **不跨回合**（回合开始时清零） |
| 上限 | 999 |
| 减益 | 脆弱(Frail)减少25% |

**设计思想**：

护甲不跨回合是杀戮尖塔最重要的设计决策之一。如果护甲可以累积：

1. 玩家可以"堆甲碾压"，前几回合全力防御后无敌
2. 战斗的紧张感会随时间递减（越来越安全）
3. 每回合的"攻守决策"将不复存在

护甲不跨回合意味着**每回合都是独立的"攻守决策点"**，战斗的紧张感从头到尾保持一致。同时，少数例外（路障 Barricade、模糊 Blur）作为卡牌效果存在，变成了珍贵的流派构建选择。

### 4. 意图系统 (Intent System)

**这是杀戮尖塔对卡牌Roguelike最重要的创新。**

每回合开始时，所有敌人**公开显示其下一步行动**：

| 意图类型 | 图示 | 含义 |
|----------|------|------|
| 攻击 | 剑图标 | 将造成X点伤害 |
| 强力攻击 | 红色剑图标 | 将造成大量伤害 |
| 防御 | 盾牌图标 | 将获得护甲 |
| 增益 | 绿色上箭头 | 将对自己施放增益 |
| 减益 | 紫色下箭头 | 将对玩家施放减益 |
| 未知 | ? | 无法预测（少数敌人） |

**为什么公开意图是天才设计**：

1. **将"随机性"转化为"策略"**：传统回合制游戏中，敌人的行动是隐藏的，玩家只能猜测。杀戮尖塔把信息给你，考验的是你**如何应对已知威胁**。

2. **消除"不公平的死亡"**：如果敌人突然打出100伤害而你无法预见，这是"不公平的挫折"。意图系统确保了每一次受伤都可以追溯到玩家的决策。

3. **创造策略节奏**：当敌人意图是攻击时，你出防御；当敌人意图是增益时，你抓紧输出。这种"见招拆招"的节奏感是游戏乐趣的核心来源。

4. **意图不可更改**：意图在敌人回合开始时确定，之后不变。这意味着玩家的计算是**确定性的**——如果你正确地计算了伤害和护甲，结果就是确定的。

5. **Boss有可学习的模式**：部分Boss有固定的行动序列，可以被记忆和预判，这为高端玩家提供了额外的一层策略深度。

### 5. 牌堆管理

```
┌──────────┐     抽牌      ┌──────────┐    打出/弃牌    ┌──────────┐
│ 抽牌堆    │ ──────────→ │  手牌     │ ──────────→  │ 弃牌堆    │
│(Draw Pile)│              │ (Hand)   │               │(Discard)  │
└──────────┘              └────┬─────┘               └─────┬────┘
                               │ 消耗                       │ 抽牌堆为空
                               ↓                            │ 时洗牌
                          ┌──────────┐                      │
                          │ 消耗堆    │←─────────────────────┘
                          │(Exhaust)  │
                          └──────────┘
```

| 参数 | 数值 |
|------|------|
| 手牌上限 | 10张 |
| 每回合抽牌 | 5张 |
| 超出手牌上限 | 多余的牌被弃掉 |

**设计思想**：

牌堆的循环结构（抽牌堆→手牌→弃牌堆→洗牌成为新抽牌堆）意味着**卡组大小直接影响每回合抽到特定卡牌的概率**。10张卡组中每张卡每2回合出现一次；30张卡组中可能4-5回合才出现一次。这直接驱动了"卡组精简"策略——详见[卡牌系统](02-卡牌系统.md)。

### 6. Buff/Debuff系统

**核心增益**：

| Buff | 效果 | 设计角色 |
|------|------|----------|
| 力量 (Strength) | 攻击伤害+1/点 | 铁甲战士的核心数值轴 |
| 敏捷 (Dexterity) | 护甲+1/点 | 防御能力的标尺 |
| 人工制品 (Artifact) | 抵消X次debuff | 对抗debuff的防御手段 |
| 护甲板 (Plated Armor) | 回合结束+X护甲 | 持续防御的被动引擎 |
| 荆棘 (Thorns) | 被攻击时反弹X伤害 | 惩罚攻击型敌人 |
| 虚无化 (Intangible) | 所有伤害降为1 | 终极防御效果（持续1回合） |

**核心减益**：

| Debuff | 效果 | 设计角色 |
|--------|------|----------|
| 易伤 (Vulnerable) | 受到攻击伤害+50% | 增加伤害输出的倍率器 |
| 虚弱 (Weak) | 造成攻击伤害-25% | 降低敌人威胁 |
| 脆弱 (Frail) | 获得护甲-25% | 削弱防御能力 |
| 中毒 (Poison) | 每回合受X伤害，减1 | 猎人的核心终端策略 |
| 燃烧 (Burn) | 回合结束受2伤害 | 状态牌的即时伤害形态 |

**设计思想**：

Buff/Debuff系统是一套"属性语言"。它将复杂的战斗交互抽象为可叠加的数值：

- **力量/敏捷**构成了攻守的基础数值轴
- **易伤/虚弱/脆弱**分别是这三个轴的"反制"
- **中毒**作为独特的"倒计时伤害"，创造了不需要力量的替代终端策略
- 所有效果都可以叠加，创造了"滚雪球"的流派体验

**关键细节：中毒可致死**。与许多游戏不同，毒可以直接杀死敌人而不留1HP。这使得毒系成为一个完全可行的终端策略，而非仅仅"辅助伤害"。

## 三、敌人设计

### 普通敌人

分为不同难度池(Pool)，按楼层出现：
- 第一层：简单池(Easy Pool)
- 后续层：硬池(Hard Pool)

### 精英敌人

| 章节 | 精英 | 设计目的 |
|------|------|----------|
| Act 1 | Gremlin Nob, Lagavulin, 三哨兵 | 考验卡组的基础战斗力 |
| Act 2 | Book of Stabbing, Gremlin Leader, Slavers | 考验AOE和持续战斗能力 |
| Act 3 | Giant Head, Nemesis, Reptomancer | 考验卡组的综合成熟度 |

**精英的设计哲学**：每个精英都在"拷问"卡组的一个特定维度。Gremlin Nob惩罚技能牌多的卡组；Lagavulin考验持续输出能力；Book of Stabbing考验防御能力。这意味着**击败精英不仅需要运气，还需要卡组在对应维度上有足够的投资**。

### Boss设计

每幕末尾从三个Boss中随机选一个（Act 4除外）：

| 章节 | Boss | 核心挑战 |
|------|------|----------|
| Act 1 | Slime Boss / Guardian / Hexaghost | 基础战斗力的检验 |
| Act 2 | Automaton / Collector / Champ | 流派深度的检验 |
| Act 3 | Donu & Deca / Time Eater / Awake One | 卡组完整性的检验 |

**Boss的层递设计**：
- Act 1 Boss考的是"你能不能打好基础"
- Act 2 Boss考的是"你的流派有没有成型"
- Act 3 Boss考的是"你的卡组能不能应对复杂机制"

## 五、设计启示

1. **公开敌人意图是降低挫败感的关键**：当玩家知道"为什么输了"，失败就变成了学习
2. **护甲不跨回合保持了战斗的持续紧张感**：每回合都有攻守抉择
3. **3能量是精妙的数值设计**：恰好不够用，创造取舍
4. **精英作为"卡组体检站"**：每个精英拷问一个特定维度，这种设计可以用于任何Roguelike
5. **确定性优于随机性**：意图公开、效果确定——让策略而非运气决定胜负
