# 杀戮尖塔 — 进阶系统与难度设计

## 一、系统概述

进阶(Ascension)系统是杀戮尖塔的**全局难度调节框架**。共有20个等级，每级新增一个负面修正，所有修正累加生效。进阶系统不是简单地"增加数值"，而是逐步从所有维度施压——从敌人属性到AI行为，从经济系统到药水系统。

**系统定位**：进阶系统是"终极考验层"——它为已经精通基础游戏的玩家提供了近乎无限的挑战空间。

## 二、核心机制

### 1. 解锁规则

| 规则 | 说明 |
|------|------|
| 解锁条件 | 用某角色击败三幕Boss后解锁该角色进阶1 |
| 递进解锁 | 在当前进阶级别获胜后解锁下一级 |
| 失败不降级 | 失败后仍然在当前级别 |
| 第四幕也算 | 在Act 4失败仍解锁下一级 |
| 自由选择 | 可选择已解锁的任意级别游玩 |

**设计思想**：

- **失败不降级**确保了"每次尝试都有进步"——这消除了Roguelike中最令人沮丧的"倒退感"
- **Act 4也算**承认了Act 4的难度——即使你没能通关Act 4，你的努力仍然被认可
- **自由选择**允许玩家在挑战高难度时随时回到低难度练习

### 3. 进阶的阶段性设计

进阶20级可以清晰地分为四个阶段：

```
A1-A5：基础压力（主要影响数值）
  ↓
A6-A9：持续数值压力（敌人HP增加）
  ↓
A10-A15：机制压力（开始改变游戏规则）
  ↓
A16-A20：终极考验（AI+经济+双Boss）
```

## 三、设计思想

### 1. "先量变后质变"的递进哲学

| 阶段 | 等级 | 主要影响 | 玩家感受 |
|------|------|----------|----------|
| 数值压力 | A1-A9 | 敌人更硬更痛 | "我可以应对，但容错更低了" |
| 机制压力 | A10-A15 | 改变游戏规则 | "我需要重新思考策略" |
| AI压力 | A16-A20 | 敌人更聪明 | "没有安全打法了" |

**设计思想**：这种递进确保了：

1. **学习曲线平滑**：前9级只是数值增加，不改变游戏规则，让玩家逐步适应
2. **转折点明确**：A10是一个明显的转折——永久诅咒改变了卡组管理的策略
3. **终极挑战**：A20的双Boss是对卡组完整性的终极检验

### 2. 系统覆盖的全面性

进阶系统几乎影响了游戏的每一个子系统：

```
A1   → 地图系统（精英频率）
A2-A4 → 战斗系统（敌人伤害）
A5   → 地图系统（Boss间回复）
A6   → 角色系统（起始HP）
A7-A9 → 战斗系统（敌人HP）
A10  → 诅咒系统
A11  → 药水系统
A12  → 卡牌系统
A13  → 经济系统（收入）
A14  → 角色系统（最大HP）
A15  → 事件系统
A16  → 经济系统（支出）
A17-A19 → 战斗系统（敌人AI）
A20  → 战斗系统（双Boss）
```

**设计思想**：通过在不同级别影响不同系统，设计师确保了：

- **没有"一招鲜"的攻略**：如果你用经济策略通关A15，A16的物价上涨会打乱你的节奏
- **全面的卡组要求**：每个进阶级别都在"拷问"卡组的不同维度
- **逐步剥夺"安全网"**：药水减少(A11)、事件变差(A15)、经济紧张(A13+A16)——你依赖的每一个安全网都会被逐一剥夺

### 3. 关键进阶级别的分析

#### A1：精英频率+60%

**为什么是第一个修正**：

精英是游戏中最重要的高风险高回报节点。增加精英频率意味着：
- 更多的遗物获取机会
- 但更大的战斗风险
- 路径规划的策略权重大幅增加

**设计思想**：将"精英频率"作为A1而非数值修改，是因为它首先影响的是**策略决策**而非战斗执行。它迫使玩家从第一个进阶级别就开始更认真地思考路径选择。

#### A10：永久诅咒

**为什么是最大的转折点**：

Ascender's Bane是一个不可移除的诅咒。这意味着：
- 你从第一层就有一张"废牌"在手牌中
- 任何移除服务都无法清除它
- 它直接影响卡组精简策略——你永远至少有一张需要"忍受"的牌

**设计思想**：A10将进阶的"量变"推进到"质变"。从A10开始，你不只是在"应对更强的敌人"，你还在"应对游戏规则的改变"。这个诅咒还是不可移除的设计确保了它的影响是永久性的——你不能"花钱消除"这个代价。

#### A11：药水槽-1

**为什么减药水槽比减其他更重要**：

药水槽从3减到2，看起来只是少了一个槽位，但实际上：

- **减少了33%的药水储备**——不是少一瓶，而是少了三分之一的战略储备
- **更频繁的"用还是留"决策**——槽位更少，每次获得药水都更紧张
- **降低了容错空间**——少一瓶药水意味着少一次"紧急救援"

**设计思想**：A11剥夺了玩家的一个"安全网"。在A11之前，药水是可以依赖的应急手段；A11之后，药水的使用必须更加谨慎和精准。

#### A15：事件结果恶化

**为什么在中间而非后面**：

事件结果恶化改变了"未知房间"的风险-收益评估：
- 之前：未知房间≈"可能的惊喜"
- 之后：未知房间≈"可能的陷阱"

**设计思想**：A15放在A17（敌人AI）之前，是因为它首先改变的是**路径选择策略**——玩家会更倾向于避开未知房间，选择更确定的路线。这改变了地图系统的"元策略"。

#### A20：双Boss

**终极挑战的设计意义**：

A20要求玩家在Act 3结尾连续击败两个Boss。这意味着：
- 你不能针对单个Boss优化卡组
- 你的卡组必须足够全面，能应对两种不同的Boss策略
- 精英、商店、事件等资源分配必须为双Boss做准备

**设计思想**：双Boss是对"卡组完整性"的终极检验。在A20之前，你可以"运气好"遇到一个你的卡组克制的Boss；在A20，你需要面对两个随机Boss，运气的权重被大幅降低。

### 4. 进阶分数系统

- 每级额外增加5%分数
- 最高A20为100%加分
- 进阶级别不影响连胜统计

**设计思想**：分数系统为竞速和排行榜提供了公平的比较基准。A20玩家获得100%加分，这承认了高进阶的额外难度。

## 四、进阶对策略的影响

### 低进阶（A0-A9）的策略特点

| 特点 | 说明 |
|------|------|
| 容错空间大 | 数值压力可通过技巧弥补 |
| 路径灵活 | 可以选择自己喜欢的路径 |
| 经济宽裕 | 金币基本够用 |
| 药水充裕 | 3个槽位提供足够保障 |

### 中进阶（A10-A15）的策略特点

| 变化 | 影响 |
|------|------|
| 永久诅咒 | 卡组永远不完美 |
| 药水减少 | 需要更谨慎的资源管理 |
| 事件恶化 | 路径选择更保守 |
| 经济收紧 | 每枚金币都重要 |

### 高进阶（A16-A20）的策略特点

| 变化 | 影响 |
|------|------|
| 物价上涨 | 商店购物需要更精确的优先级 |
| 敌人AI增强 | 不再有"安全打法" |
| 双Boss | 卡组必须全面而非专精 |

**设计思想**：随着进阶提升，"运气成分"被逐步压缩，"策略成分"被逐步放大。在A20中，几乎所有的胜利都可以追溯到一系列精确的决策，而非运气好。

## 六、设计启示

1. **累积式而非替换式**：所有修正叠加生效，创造了极其精细的20级难度梯度
2. **"先量变后质变"**：前9级是数值调整，后11级逐步改变机制，学习曲线平滑
3. **系统覆盖全面**：从地图到经济、从敌人属性到AI行为，全方位施压
4. **转折点设计**：A10（诅咒）、A11（药水）、A20（双Boss）是明确的"游戏规则改变点"
5. **失败不惩罚**：失败不降级，确保每次尝试都是进步——这是Roguelike的"善意设计"
6. **剥夺安全网**：进阶逐步剥夺药水、经济、事件等安全网，迫使玩家在更少的资源下做出更精准的决策
