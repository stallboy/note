# Godot 美术资产需求清单

> 基于《塞尔达传说：众神的三角力量》动作状态机拆解报告、敌人受击反馈状态机拆解报告提取。适用于 Godot 4.x 2D 项目。
> 所有角色精灵均需 **四方向（上/下/左/右）** 版本，下方标注帧数为单方向帧数。
> 敌人精灵同样需要四方向，击退方向量化为 8 方向（含对角）。

---

## 一、角色精灵动画 (SpriteFrames → AnimatedSprite2D)

资源路径建议：`assets/sprites/link/`

### 1.1 基础移动

| 资产名称 | 对应状态 | 帧数 | 说明 |
|---|---|---|---|
| `idle.png` | Idle | 1 帧 + 不耐烦变体 4~6 帧 | 静止站立；不耐烦子状态（擦汗、东张西望）作为独立动画或延迟触发帧 |

```
├── effects/
│   ├── particles/         # .tres GPUParticles2D 资源
│   ├── shaders/           # .gdshader 材质
│   ├── enemy/             # 敌人受击/死亡特效
│   │   ├── hurt_shaders/  # 受击调色板 Shader
│   │   ├── death_shaders/ # 死亡动画 Shader
│   │   └── particles/     # 敌人专属粒子
│   └── medallion/         # 三大徽章全屏特效场景
├── tilesets/              # 环境瓦片集
└── audio/                 # 音效（不在本清单范围，但建议同步规划）
```

**关键技术备注：**

- 角色与敌人精灵建议使用 **SpriteFrames** 资源，每个状态对应一个动画名称，通过 `AnimationPlayer` 或 `AnimatedSprite2D.play()` 切换。
- 所有四方向帧建议打包在同一张精灵表中（4 行 × N 列），通过 `hframes` / `vframes` 切分。
- 受击闪烁（Invincibility）、魔法披风（Cape）、死亡变红（Death）使用 **Shader Material** 实现，不制作逐帧精灵。
- 敌人受击闪白（1~2 帧）、冰冻调色板（蓝/白）、燃烧调色板（红/橙）同样使用 **Shader Material** 实现调色板覆写，模拟 SNES OAM Palette Override 机制。
- 全屏施法特效（徽章）建议独立为 `.tscn` 场景，通过 `AnimationPlayer` 控制时序。
- 举物状态下的物品精灵需绑定到角色的 **Marker2D** 骨骼点（头顶位置）。
- 多段体 Boss（Lanmolas、Moldorm）的每个身体节为独立精灵实体，各自占用精灵槽位，需独立管理。
- 镜盾反弹投射物不生成新实体，代码直接取反速度向量 + 切换阵营标签，美术无需额外资产。
- 掉落物为独立精灵实体（使用掉落物槽位），通用"弹跳出现"动画模板可复用于所有掉落物类型。
