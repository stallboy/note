# 06 谜题设计

## 核心问题

ALttP 的谜题系统如何在完全不依赖文字教程的情况下教会玩家理解每一种机关？一个地下城内的谜题如何从"一眼就懂"渐进到"需要组合多种能力"，同时保持每次失败都不会让玩家产生"我不知道该做什么"的绝望感？

## 机制描述

### 谜题类型学

ALttP 的谜题可以归纳为八种基本类型：

| 类型 | 核心操作 | 变体数量 | 首次出现的地下城 |
|------|----------|----------|-----------------|
| 开关谜题 | 踩下/射击/砸击开关，改变地形状态 | 多（水晶开关、地面开关、射击开关） | Eastern Palace |
| 推石谜题 | 将石头推入特定位置（坑洞/开关上） | 少 | Tower of Hera |
| 点火/灭火谜题 | 使用 Lamp 或 Fire Rod 点燃火盆 | 少 | Skull Woods |
| 钩爪谜题 | 使用 Hookshot 跨越悬崖/拉取道具/触发开关 | 中 | Swamp Palace |
| 水位谜题 | 拉动开关改变水位，改变可达路径 | 少（但复杂度高） | Swamp Palace |
| 冰面滑动谜题 | 在滑冰地面上推动方向后自动滑行到障碍物 | 少 | Ice Palace |
| 传送/世界切换谜题 | 用 Magic Mirror 在两个世界间切换解决空间通达 | 少 | 多个 Dark World 地下城 |
| 综合组合谜题 | 将多种机关组合使用 | 多 | 后期地下城 |

### 开关谜题的细分

开关是 ALttP 中使用频率最高的谜题元素，有三种主要变体：

**水晶开关（Crystal Switch）**：翻转状态（蓝↔红），影响对应颜色的平台/方块。蓝色方块降下时可以通过，红色方块降下时可以通过。玩家每次击打水晶开关，所有同色方块同时切换状态。这创造了一种全局状态管理的挑战——玩家需要在脑中追踪"当前是什么状态"以及"切换后会怎样"。

**地面开关**：踩下即触发，松开可能复位（取决于设计）。部分地面开关需要压重物才能持续触发——Cane of Somaria（索马里亚之杖）生成的方块可以放在开关上作为配重。这类开关通常控制门的开闭或特定平台的升降。

**射击开关**：需要用弓箭或回旋镖远程触发的开关。常见形态是墙壁上的"眼睛"——射击后触发机关。这类开关将战斗系统（远程射击）和谜题系统直接耦合。

### 推石谜题的规则

推石谜题是塞尔达系列的传统谜题类型，从初代（1986）即已存在。ALttP 的推石规则：

- 大多数石头只能被推动一次，推动后锁定在最终位置
- 部分石头可以反复推动（但每次只能推动一格）
- 石头可以推入坑洞中填平坑洞，创造通行路径
- 石头可以推到地面开关上持续触发
- 部分石头需要 Power Glove / Titan's Mitt 才能搬起（而非推动）

推石谜题的核心认知挑战是**空间推理**：玩家需要在脑中模拟"推这块石头到那里，会不会挡住推另一块石头的路径"。当多块石头共享同一空间时，推动顺序成为关键。

### 无文字教学的设计框架

ALttP 的谜题教学中存在一个严格的隐含规则：

**新物品获得后的第一个谜题房间一定满足以下条件：**
1. 没有敌人（零威胁环境）
2. 目标物体在玩家必经之路上（不可忽略）
3. 谜题的解法只有一种（对新物品的最明显用途）
4. 房间布局将玩家引导到正确位置（空间暗示）

以 Palace of Darkness 的魔法锤教学为例：

```
获得锤子 → 离开宝箱房间 → 进入相邻房间
→ 房间内有一个明显的桩（Hammer Peg）
→ 桩挡住了前进路径
→ 房间内没有敌人
→ 玩家自然会尝试对新获得的锤子使用
→ 砸击桩 → 桩降下 → 路径打开
```

整个过程不需要任何文字提示。教学完全通过空间布局和上下文完成。

### 教学三阶段的详细结构

以 Palace of Darkness 为典型案例的完整三阶段：

**阶段1——教学（零风险）：**

获得魔法锤后，紧邻宝箱的房间中有一个锤击桩。房间内无敌人、无时间压力。桩的位置恰好在玩家从宝箱房间出来的必经之路上。玩家尝试砸桩，桩降下，路径打开。

教学完成。玩家学到了：锤子可以砸桩，砸桩会改变地形。

**阶段2——应用（有干扰）：**

后续房间中，锤击桩的操作开始出现在有敌人的环境中。玩家需要一边处理敌人威胁一边寻找并砸击桩。部分房间的桩不再只是"挡路的障碍"，而是与开关联动——砸桩会触发机关，改变其他房间的地形。

应用阶段引入的新变量：环境压力（敌人干扰）和连锁效应（一个机关影响多个房间）。

**阶段3——精通（Boss 综合）：**

Boss 战（Helmasaur King）要求用锤子砸碎 Boss 的面具。这不再是"对着静止的桩砸一下"——Boss 在移动、攻击，玩家需要在闪避的间隙找到锤击窗口。面具有多段耐久度，需要反复砸击。

精通阶段将"锤击"从解谜操作升华为战斗操作。玩家在极端压力下运用已学技能，完成从认知到本能的转化。

### Swamp Palace 水位系统（经典案例详细分析）

Swamp Palace 的水位谜题是 ALttP 中最复杂的状态管理谜题。核心机制：

**空间结构**：地下城有 2 层（B1、B2），水从顶层（B1）流入。

**水位控制**：不同楼层有拉动式开关（Drain Switch），拉动后改变水位。水位的改变直接影响哪些区域可通行。

**关键路径中的水位操作**：

1. 入口阶段：B1 层干燥，正常推进
2. 获得钩爪后：用钩爪跨越水面到达 B1 层的排水开关，将水排入 B2 层
3. B2 层水位上升后：原本的干涸区域被淹没，但同时也创造了新的水上路径——玩家可以在水面上游泳到达之前无法到达的区域

**设计精髓**：同一份空间因水位不同产生多种配置。B2 层在低水位时是一片干涸的凹地（无法通行），在高水位时是一片可以游泳通过的水域（可以通行）。一份地图数据，两种截然不同的空间体验。

这是"底层复用 + 状态变化"策略的典范 `[推测]`：在容量有限的 SNES 卡带中，用状态翻转（有水/无水）让同一片空间产出两套路径，相当于用一半的数据量提供了双倍的有效探索空间。

### 地下城间谜题复杂度的递进

| 地下城 | 谜题复杂度 | 核心新概念 | 组合使用的能力数 |
|--------|-----------|-----------|----------------|
| Eastern Palace | 低 | 水晶开关的状态翻转 | 1（弓） |
| Desert Palace | 低-中 | 地下层的推石 + 钥匙管理 | 2（弓 + 基础操作） |
| Tower of Hera | 中 | 多层垂直空间的推石传导 | 2（弓 + 推石） |
| Palace of Darkness | 中 | 锤击桩 + 暗室视野限制 | 2-3 |
| Swamp Palace | 中-高 | 水位状态管理 + 钩爪跨越 | 3-4 |
| Skull Woods | 高 | 多入口散布 + 火焰远程点火 | 3-4 |
| Ice Palace | 高 | 滑冰物理 + 6层垂直钥匙搬运 | 4-5 |
| Turtle Rock | 最高 | 多元素联动 + 高密度机关 | 5+ |

## 设计分析

### 1. 谜题的"词汇-语法-段落"层级

ALttP 的谜题设计可以类比为语言学习中的三个层级：

**词汇层（基础元素）**：开关、石头、火盆、悬崖、坑洞、水面、冰面。每种元素有明确的、一致的交互规则。开关总是可以触发，石头总是可以推，火盆总是可以点燃。玩家在第一个地下城学到的"词汇"在整个游戏中保持一致——不存在"这个地下城的开关行为不一样"的情况。

**语法层（元素组合）**：单个元素按特定方式组合形成谜题。例如"射击开关 → 门打开"是最基础的语法。"推石头到开关上 → 平台升起 → 跳上平台 → 射击远处开关"是更复杂的语法。地下城内部的谜题就是在教授玩家越来越复杂的"语法"。

**段落层（多房间连锁）**：后期地下城中，一个房间的操作会影响其他房间的状态。Swamp Palace 的水位系统就是"段落"——在整个地下城的尺度上，一次水位操作改变了多个房间的可达性。玩家需要构建整个地下城的心理地图，才能理解"在这个房间操作会怎样影响那个房间"。

这种三层层级的关键设计意义在于：**词汇层的规则永远不变，复杂性只来自语法和段落层**。如果基础元素的交互规则在不同地下城中改变（例如"这个地下城的开关要砸而不是踩"），玩家的认知负荷将急剧增加——每次进入新地下城都需要"忘掉旧规则、学习新规则"。ALttP 通过保持词汇层的一致性，确保玩家总是可以在已知的规则基础上推理新谜题。

### 2. 无文字教学的三重保障机制

ALttP 不使用文字教谜题，而是通过三重机制确保玩家总能"自己想出来"：

**保障一：空间引导（Spatial Affordance）**

目标物体被放置在玩家无法忽略的位置。教学房间中，需要操作的开关/桩/石头总是在玩家前进路径的正前方或紧邻入口。玩家不需要"寻找"目标——目标就在眼前，唯一的认知负担是"用什么操作它"。

这种设计利用了格式塔心理学中的"图形-背景"原则：在一个简洁的房间中，唯一突出的可交互元素自然成为注意力的焦点。

**保障二：上下文暗示（Contextual Cue）**

新物品获得的房间本身就是暗示。宝箱旁边通常有需要该物品才能通过的地形——玩家拿到钩爪后，第一个面对的就是一个需要用钩爪跨越的悬崖。获得物品和使用物品的上下文被压缩在同一个空间中。

更精细的暗示：如果谜题需要组合使用两种能力，这两种能力的触发条件通常被放在彼此的可视范围内。例如，需要"踩开关 + 射击远处目标"的谜题，开关和目标在同一个房间内可见，不需要玩家记忆。

**保障三：安全失败（Safe Failure）**

ALttP 的谜题失败不产生严重惩罚。推石头推错了？退出房间再进来，石头会复位。踩了错误的开关？再踩一次就切回来。即使被陷阱击中，也只是损失少量 HP，回到房间入口。

这种设计背后的原则是：**谜题的挑战应该来自"想出解法"，而非"执行解法"**。如果执行解法的过程本身充满惩罚（一步走错就要重来整个谜题），玩家的注意力会从"思考"转移到"小心操作"，谜题的认知乐趣被操作焦虑取代。

### 3. 谜题作为"教学→应用→精通"的载体

谜题在 ALttP 中承担的教学功能远超其表面上的"解谜"乐趣。每个新物品的教学不是通过文字说明，而是通过一系列精心排列的谜题完成的：

```
宝箱房间（获得物品）
    ↓
教学房间（零风险使用）
    ↓
应用房间（有干扰使用）
    ↓
后续多个房间（组合使用）
    ↓
Boss 战（高压综合使用）
```

这条教学链的关键特征：

- **单调递增的变量**。每个阶段只增加一个新变量——教学→应用增加了"敌人干扰"，应用→精通增加了"时间压力和移动目标"。绝不在同一阶段同时引入两个新变量。
- **不可跳过的步骤**。教学房间通常在获得物品后的必经之路上，玩家无法跳过。这保证了所有玩家都会经历基础教学。
- **即时的正反馈**。每次正确使用物品都有明确的环境反馈——桩降下、门打开、路径出现。这种即时反馈强化了"我用对了"的认知。

### 4. 水位谜题的深层设计分析

Swamp Palace 的水位系统值得单独深入分析，因为它是 ALttP 中"状态管理"类谜题的巅峰。

**核心设计问题**：如何在 2D 空间中让玩家感知和管理"状态"？

**水位系统的答案**：让状态变化产生**视觉上可感知的空间变化**。水位上升不是抽象的数字变化——玩家可以看到水面出现、路径被淹没、新的游泳路径打开。状态是可见的、可触的。

**设计约束转化为优势** `[推测]`：SNES 无法在同一画面中同时渲染"有水"和"无水"两种状态下的完整环境细节。水位系统的巧妙之处在于——水面本身就是一个简洁的视觉层，不需要为两种状态分别维护完整的瓷砖集。干涸的凹地 + 水面瓷砖 = 水域。底层复用，顶层状态切换。

**水位操作的认知模型**：

玩家需要构建一个三层认知模型：
1. **当前状态**：水位是高还是低？
2. **操作后果**：拉这个开关后水位会怎样变化？
3. **空间影响**：水位变化后，哪些区域变得可达/不可达？

这三个层次逐步构建。游戏先让玩家在简单场景中理解第 1 层（看到水位变化），再在稍复杂的场景中理解第 2 层（知道是哪个开关导致的），最后在整个地下城尺度上理解第 3 层（综合规划水位操作顺序）。

### 5. 冰面滑动谜题——从确定性走向推理

Ice Palace 的滑动地板引入了一种不同的认知挑战。玩家在冰面上推动方向后，角色会沿该方向持续滑行直到碰到障碍物。这创造了一种"确定性运动 + 障碍物规划"的谜题类型。

与推石谜题的区别：推石谜题中玩家可以逐步试探（推一格、看效果），冰面谜题中一旦推动就是不可逆的滑行过程。这要求玩家在行动前完成所有的空间推理——"推这个方向→滑到那个墙→再推那个方向→滑到目标位置"。

冰面谜题实质上是**路径规划谜题**，类似于经典的滑冰谜题（Ice Puzzle）。这类谜题的特点是：
- 规则极其简单（推方向 + 滑到障碍）
- 但解法可能需要多步规划
- 每一步的选择都影响后续选项（推错了可能卡住）
- 需要在脑中模拟多步推演

### 6. 世界切换谜题——双世界的空间互锁

Magic Mirror 在地下城谜题中的应用创造了一种独特的空间通达问题。部分 Dark World 地下城的某些区域无法从内部到达，需要：

1. 在 Dark World 地下城内使用 Magic Mirror
2. 被传送到 Light World 的对应位置
3. 在 Light World 完成某些操作（如推动石头、进入建筑）
4. 从 Light World 重新进入 Dark World 地下城的另一区域

这种设计的精妙之处在于：它将两个世界的空间结构"互锁"了。Dark World 地下城不再是封闭的系统——它的可达性取决于 Light World 的地形。这要求玩家同时持有两个世界的心智地图，并在两者之间建立对应关系。

## 设计过程推导

### 从初代塞尔达到 ALttP 的谜题进化

初代塞尔达（1986）的谜题非常原始：主要是推石头的"哪个方向推"和炸墙的"哪面墙能炸"。谜题类型单一，复杂度低。

Zelda II（1987）转向横版动作，谜题几乎消失。

ALttP 需要在 SNES 上重新定义塞尔达的谜题设计 `[推测]`。设计团队面对的核心问题是：

- **硬件能力提升带来的新可能性**：SNES 比 NES 多了模式 7、更多精灵图、更大容量。这意味着可以在谜题中使用更复杂的环境变化（如水位升降、状态翻转）。
- **双世界系统带来的新设计维度**：世界切换本身可以成为一种谜题元素，这在初代中完全不存在。
- **物品数量增加带来的组合空间**：初代只有约 8 种物品，ALttP 约有 15 种核心物品，物品间的组合使用空间大幅扩展。

推导出的设计方向 `[推测]`：
1. 不再只用单一的谜题类型，而是每种新物品对应一种新的谜题类型
2. 引入状态管理类谜题（水晶开关、水位系统），利用 SNES 的表现力
3. 利用双世界系统创造"空间互锁"类型的谜题
4. 通过地下城内的教学链，让玩家逐步掌握组合使用多种能力

### "词汇不变、语法升级"策略的发现

这种策略很可能是从教学效率的考量中推导出来的 `[推测]`：

- 如果每个地下城都引入全新的谜题类型（新词汇），13 个地下城意味着 13 套规则。玩家的认知负荷会持续累积，到第 7-8 个地下城时可能出现认知过载。
- 如果所有地下城都用同一套谜题类型，复杂度不递增，玩家在第 3-4 个地下城时就会感到重复。
- 中间路线：**基础元素（词汇）保持一致，但元素的组合方式（语法）逐步升级**。开关永远是开关，但后期地下城中开关与水位、推石、钩爪的组合方式变得前所未有地复杂。

### 教学房间的设计起源

新物品获得后紧邻无敌人教学房间的设计，可能从初代塞尔达的问题中推导而来 `[推测]`：

初代塞尔达没有专门的教学机制。玩家在地下城中获得新物品后，通常立即面临有敌人的环境。这导致玩家经常在还没理解新物品功能时就陷入战斗，注意力被分散，无法形成对新物品的清晰认知。

ALttP 的设计团队可能意识到了这个问题：**在认知资源被战斗消耗时，学习新机制是低效的**。解决方案很直接——为新机制的学习创造一个认知资源不被干扰的环境，即无敌人的教学房间。

### 水位系统的设计起源

Swamp Palace 的水位系统可能从 SNES 的硬件特性中获得了灵感 `[推测]`。SNES 的模式 7 支持背景层的缩放和旋转，可以用来表现水位变化这种"大面积环境状态切换"。同时，水面的渲染比其他环境变化更经济——只需要一个半透明的蓝色层覆盖在已有瓷砖上。

从设计约束的角度反推：地下城容量有限，但不能让玩家觉得"太短"。水位系统用一份地图提供了两种空间配置，这在容量效率和体验丰富度之间取得了最优平衡。

## 反事实推演

### 假设一：如果每个地下城都有全新的谜题基础元素

假设 Ice Palace 不再使用开关和推石，而是引入一种全新的"冰冻/融化"基础元素。Turtle Rock 又引入全新的"岩浆路径"基础元素。

后果：
- 玩家每次进入新地下城都需要从零学习基础规则。认知负荷持续累积而非在已知规则上叠加
- 前几个地下城积累的"谜题语感"被浪费——玩家学到的是"每个地下城的规则都不同"，而非"我对这些元素的理解越来越深"
- 开发成本急剧增加——每种基础元素需要独立的代码、精灵图和测试
- 容量限制下，13 种基础元素的数据量可能超出卡带容量

→ 结论：保持"词汇不变、语法升级"是有限资源下最大化谜题深度的最优策略。基础元素的一致性不是偷懒，而是一种认知效率的优化。

### 假设二：如果去掉安全失败机制（推石推错不可复位）

假设推石一旦推动就不能再复位，推错了只能退出地下城重来。

后果：
- 谜题的操作焦虑急剧上升。玩家在推每一块石头前都会犹豫很久，因为一步走错可能导致整个地下城重来
- 玩家行为从"实验性探索"变为"保守性规避"——宁可绕路也不冒险推石
- 教学房间的低压力环境被破坏——即使没有敌人，推石的不可逆性本身就构成压力
- 谜题的乐趣核心从"想出解法"转移到"精确执行解法"，与 ALttP 的设计哲学相悖

→ 结论：谜题的安全失败机制是维持"思考型解谜"（而非"操作型解谜"）体验的关键保障。没有它，玩家的行为模式会从探索转向规避。

### 假设三：如果去掉教学房间（新物品获得后直接面对有敌人的环境）

后果：
- 部分玩家可能在首次获得新物品时因敌人干扰而未能理解物品功能
- 后续谜题设计必须假设"玩家可能不理解这个物品"——要么增加文字提示（违反无文字教学原则），要么反复设置同一类型的基础谜题作为补救教学（浪费空间）
- Boss 战作为"精通测试"的前提条件被破坏——如果玩家没有在低压力环境中学过物品的基础用法，Boss 战就从"精通测试"退化为"首次学习 + 高压测试"，挫败感极高

→ 结论：教学房间是"教学→应用→精通"三段式得以成立的必要前提。没有安全的教学阶段，后续的应用和精通阶段无法有效运作。

### 假设四：如果所有谜题都是单房间独立谜题（无跨房间连锁）

假设去掉 Swamp Palace 的水位系统，每个房间的谜题完全独立，不影响其他房间。

后果：
- 后期地下城的认知挑战大幅降低。玩家可以"逐房间清扫"，不需要构建整个地下城的心理地图
- 地图和指南针的导航功能被削弱——如果每个房间独立，玩家不需要理解地下城的全局结构
- 地下城从"连贯的空间体验"退化为"一系列独立关卡的串联"
- 地下城的尺度感消失——13 个房间的独立谜题和 13 个房间的连锁谜题，后者让地下城感觉更大、更复杂、更值得探索

→ 结论：跨房间连锁谜题是地下城从"关卡序列"升格为"空间体验"的关键设计。没有它，地下城的"建筑感"将大幅减弱。

## 可迁移经验

### 1. 词汇-语法-段落三层层级

设计一个包含大量关卡的谜题系统时，将谜题拆分为三个层级：

- **词汇层**：定义有限的基础交互元素（开关、石头、火盆等），确保每种元素在整个游戏中的行为规则一致
- **语法层**：通过元素的组合方式制造复杂度递进。早期关卡只使用简单语法（单个元素直接交互），后期关卡使用复杂语法（多元素组合 + 条件依赖）
- **段落层**：在最高复杂度时引入跨关卡/跨区域的状态影响，要求玩家构建全局心智模型

**核心原则**：词汇层永远不变，复杂度只来自语法和段落层。这确保玩家的认知投入总是在"已有知识上叠加"，而非"忘掉旧规则学习新规则"。

### 2. 无文字教学的三步法则

为新机制设计教学时，遵循三步法则：

**第一步：安全环境 + 必经之路 + 单一解法**
- 无敌人、无时间压力、无惩罚
- 目标物体放在玩家必经之路上
- 只有一种显而易见的正确操作

**第二步：增加一个新变量**
- 引入敌人干扰，或引入连锁效应，或引入时间限制
- 只增加一个新变量，不同时增加两个

**第三步：高压综合测试**
- 通常在 Boss 战或关卡末尾的大型谜题中
- 要求在压力下流畅运用已学技能

每步之间的间隔由多个"应用房间"填充，让玩家反复使用新技能直到内化。

### 3. 安全失败是思考型解谜的前提

如果希望谜题的核心乐趣来自"想出解法"而非"精确执行"，必须确保：

- 失败的惩罚极低（最多损失少量 HP 或时间）
- 谜题状态可以方便地复位（退出重进、再操作开关）
- 执行解法的过程不构成主要难度来源

当失败的惩罚过高时，玩家的行为模式会从"实验性探索"切换为"保守性规避"，谜题的乐趣核心随之丧失。

### 4. 状态管理谜题的空间可视化

当设计涉及"状态管理"的谜题时（如水位、开关、平台位置），确保状态变化是**视觉上可感知的**。

- 水位上升：玩家看到水面出现
- 开关翻转：玩家看到方块颜色变化（蓝↔红）
- 平台移动：玩家看到平台在空间中位移

抽象的状态变化（如"内部计数器+1"）不适合作为谜题的核心，因为玩家无法通过观察推断当前状态。好的状态管理谜题允许玩家仅通过视觉检查就能判断"当前是什么状态"以及"需要做什么操作"。

### 5. 物品-谜题对应的教学链闭环

地下城内获得的核心物品应该就是该地下城谜题的关键道具。这确保了：

- 物品获得后立即在解谜中使用（教学）
- 物品在后续谜题中被反复使用（内化）
- 物品在 Boss 战中被综合使用（精通）
- 整个教学链在同一个地下城内完成闭环

如果物品的教学跨地下城分散（在 A 地下城获得、在 B 地下城教学），中间的间隔会削弱学习效果，且玩家可能在 B 地下城中忘记物品的用法。

### 6. 跨区域连锁创造空间感

在关卡设计中，让一个区域的状态变化影响其他区域的可达性，可以：

- 创造关卡的全局感——玩家不再将每个房间视为独立的
- 奖励构建心智地图的玩家——"我记得那个房间有个被水淹的通道，现在排水了可以回去看看"
- 用最小内容增量扩大有效探索空间——状态变化让同一片空间产生多种配置

## 补充材料

### 对比参考

- **NES 初代塞尔达**：谜题以推石和炸墙为主，类型单一。无教学机制，无跨房间连锁。ALttP 在每个维度上都实现了质的提升。
- **Ocarina of Time**：从 2D 空间谜题升维到 3D 空间谜题。增加了高度维度、时间维度（昼夜切换影响谜题）、物理维度（重量、浮力）。但"词汇-语法-段落"的三层结构和"教学→应用→精通"的三段式被完整继承。
- **A Link Between Worlds（2013）**：直接复用 ALttP 的世界地图，谜题设计理念相似。关键区别在于"租借物品"系统使得谜题的体验顺序更灵活，但也削弱了"物品-地下城"严格对应的教学链强度。
- **Portal（2007）**：将 ALttP 的"安全失败 + 渐进教学"原则推到了极致。每个新机制都在完全安全的玻璃墙后展示，然后才让玩家在真实环境中使用。GLaDOS 的旁白本质上是对 ALttP 无文字教学的"有文字版本"。
- **La-Mulana（2005）**：与 ALttP 的"词汇一致"策略相反，几乎每个区域都引入全新的谜题规则。结果是认知负荷极高，体验偏向硬核考古学。这个对比印证了"词汇不变、语法升级"策略的普适价值。
