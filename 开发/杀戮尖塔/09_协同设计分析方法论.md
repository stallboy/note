# 09 协同设计分析方法论

## 一、分析目标

前8份报告回答了"系统是什么"和"系统为什么好"。
本系列回答一个更深层的问题：**策划在设计卡牌/遗物/药水之间的协同时，遵循了什么思维框架？这个框架能否被提炼为可复用的设计方法论？**

分析分三层：

```
第一层：协同效应清单（是什么协同）
  ↓
第二层：策划设计意图还原（策划为什么这样设计）
  ↓
第三层：设计方法论提炼（策划用什么方法做设计）
```

---

## 二、核心概念定义

### 2.1 什么是"协同"

在杀戮尖塔中，**协同**是指两张以上卡牌、或卡牌与遗物/药水/角色机制之间，组合使用时产生的效果**大于各自单独使用之和**。

反例（非协同）：两张相互无关的强力卡牌，各自独立发挥最大效果——这只是"堆叠"，不是协同。

### 2.2 协同的类型学

基于杀戮尖塔的实际设计，协同分为以下类型：

| 类型 | 定义 | 示例 |
|------|------|------|
| 乘法放大 | A提升某属性，B让该属性的收益倍增 | 力量 + 多段攻击 |
| 引擎循环 | A产出资源→B消耗资源产出更多→循环 | 消耗牌 + 消耗触发效果 |
| 条件解锁 | A创造前提条件，B在该条件下获得额外收益 | 易伤 + 高伤害攻击 |
| 缺陷互补 | A的弱点恰好被B弥补 | 低费弱卡 + Snecko Eye随机化费用 |
| 资源转化 | A产出资源X，B将X转化为需要的Y | 牺牲HP + 自伤时获得力量 |
| 被动触发 | A改变行为模式使B的被动效果高频触发 | 多段攻击 + "打出N次攻击触发"遗物 |

这六种类型不是互斥的——一个强协同可能同时是"乘法放大"和"引擎循环"。

### 2.3 "设计意图" vs "涌现效应"

分析时需要区分两种情况：

**有意设计的协同**：策划明确设计了两张牌之间的配合。证据包括：
- 卡牌关键词明确指向某个子系统（如"消耗"标签的牌明显与消耗触发效果配合）
- 角色卡池中有多张卡牌围绕同一主题（如铁甲战士有多张力量相关牌）
- 遗物的条件触发明显鼓励特定行为（如Kunai要求"每回合3次攻击"）

**涌现的协同**：策划没有预设，但系统之间的自然交互产生了协同。证据包括：
- 跨系统交互（如Dead Branch + Corruption，一个是遗物一个是卡牌）
- 玩家社区的"发现"而非官方攻略的暗示
- 效果异常强大，如果是有意设计通常会被平衡

分析时需要标注每条协同是"有意设计"还是"涌现"。

## 三、分析方法

### 方法1：卡池关键词聚类

**操作**：将角色的完整卡池按关键词/标签分类，识别每个关键词对应的卡牌数量和稀有度分布。

**目的**：如果一个关键词（如"消耗"、"力量"、"毒素"）对应了多张卡牌，说明策划**有意围绕这个关键词构建了一个协同群**。关键词出现越密集，设计意图越明显。

**输出格式**：
```
关键词：消耗（Exhaust）
├─ 攻击：Fiend Fire, Sever Soul, Pummel...
├─ 技能：True Grit, Warcry, Second Wind, Burning Pact...
├─ 能力：Dark Embrace, Feel No Pain, Charon's Ashes(遗物)...
└─ 设计结论：消耗是铁甲战士的核心设计主题之一
```

### 方法2：资源流追踪

**操作**：为每个角色绘制"资源流动图"，识别哪些卡牌产出资源、哪些消耗资源、哪些转化资源。

**目的**：协同的本质是**资源的链式转化**。追踪资源流可以揭示策划设计的"经济系统"——每种资源如何产出、消耗、转化。

**资源类型**：
- 能量（Energy）
- 抽牌（Draw）
- 力量/敏捷/专注（统计属性）
- Block（防御资源）
- HP（生命资源）
- 充能球/姿态/毒素（角色专属资源）
- 消耗（Exhaust，作为"移除"资源）

**输出格式**：
```
资源流：HP → 力量
├─ Bloodletting: -3HP → +2能量
├─ Rupture: 自伤 → +1力量（能力牌）
├─ Offering: -6HP → +2能量 + 抽3牌
└─ 设计结论：HP是铁甲战士的"可消耗货币"，策划有意让HP→力量/能量成为一条合法路径
```

### 方法3：遗物触发条件反向推导

**操作**：收集所有"条件触发型"遗物，分析它们的触发条件指向什么行为。

**目的**：遗物的触发条件是策划**对玩家发出的隐性引导**。"打出3次攻击触发"不是随机选择——策划希望玩家构建多段攻击流。反向推导这些条件，就能理解策划期望的协同方向。

**输出格式**：
```
触发条件：打出N张攻击牌/回合
├─ Kunai: +1敏捷
├─ Shuriken: +1力量
├─ Ornamental Fan: +4 Block
└─ 设计结论：策划希望"多段低费攻击"成为一种通用协同方向
```

### 方法4：稀有度分层验证

**操作**：检查同一个协同群中的卡牌稀有度分布。

**目的**：如果某个协同的核心卡牌是普通/非凡，而放大器是稀有，说明策划的设计意图是：
- **核心易得**（普通/非凡概率高，确保大多数局能获取基础协同）
- **放大器稀有**（稀有概率低，让协同的"完全体"成为偶尔的奖励而非常态）

如果反过来（核心是稀有，放大器是普通），则说明策划认为这个协同是"高级策略"，不期望新手轻易发现。

### 方法5：跨角色对比

**操作**：将不同角色处理同一问题（AOE、单体爆发、防御、能量生成）的方式并列对比。

**目的**：不同角色用不同机制解决同一问题，揭示了策划对"同一设计目标可以有多种实现方式"的理解。对比这些实现方式，可以提炼出比具体角色更通用的设计原则。

### 方法6：药水协同分析

**操作**：分析角色专属药水的效果与角色卡池的交互。

**目的**：角色专属药水是策划对角色"应急需求"的理解——每种专属药水都弥补了角色某个方面的紧急需求或强化了某个核心方向。

## 四、从"设计意图"推导"设计方法论"

这是本系列最核心的分析步骤。在识别了具体协同和策划意图之后，需要进一步抽象：

**策划在做出这些设计决策时，用的是什么思维工具？**

假设的推导框架：

### 4.1 "核心资源 + 转化链"思维

策划可能先确定角色的"核心资源"（铁甲=HP/力量，静默=毒素，机器人=充能球/专注，观者=姿态/能量），然后围绕这个资源设计"产出→转化→消耗"的完整链条。

### 4.2 "弱点即设计空间"思维

策划可能先确定角色"不擅长什么"，然后设计协同比弥补弱点更有趣——将弱点转化为"有条件才能解决"的挑战。

### 4.3 "乘法点"识别

策划可能有意识地在系统中放置"乘法点"——某个属性（力量、专注、毒素层数）可以被多张牌放大，创造非线性增长。

### 4.4 "安全阀 + 赌注"二元设计

策划可能为每个强力协同设计一个"安全阀"（保底机制）和一个"赌注"（高风险高回报的放大器），让协同有不同层级的实现。
