# 02 战斗系统：可读的博弈棋盘

## 核心问题

杀戮尖塔的战斗系统如何在"策略深度"和"可理解性"之间取得平衡？敌人意图显示这一设计为什么是整个游戏的基石？

---

## 一、战斗回合机制

### 1.1 基础框架

每场战斗由交替的玩家回合和敌人回合组成，直到一方HP归零。

**玩家回合流程**：

| 阶段 | 动作 |
|------|------|
| 回合开始 | 抽5张牌，获得3点能量，Block重置为0 |
| 行动阶段 | 自由出牌（消耗能量和手牌），可使用药水 |
| 结束回合 | 手牌弃入弃牌堆，剩余能量清零 |
| 敌人回合 | 敌人按意图行动，展示下回合意图 |

> 数据来源：[Combat Mechanics - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Combat_Mechanics)

**牌库循环**：抽牌堆 → 手牌 → 弃牌堆。当抽牌堆为空时，弃牌堆洗入抽牌堆。这个循环意味着——**你牌组中的每张牌最终都会被抽到**，只是时机不确定。

### 1.2 核心数值参数

| 参数 | 默认值 | 设计意义 |
|------|--------|---------|
| 每回合能量 | 3 | 限制每回合的出牌数量，创造取舍 |
| 每回合抽牌 | 5 | 提供足够的手牌选择，但不暴露全部牌组 |
| Block重置 | 每回合开始归零 | 防御必须每回合重建，无法囤积 |
| 未用能量 | 回合结束时清零 | 鼓励能量利用最大化 |

这四个参数构成了战斗的"预算系统"：每回合你有**3点能量预算**和**5张牌的随机供给**，需要在进攻和防御之间做出分配。

## 二、攻防二元论：伤害与格挡

### 2.1 伤害-格挡交互

```
敌人攻击 → 先扣除Block → Block不足时扣除HP
```

Block是即时性的防御资源，每回合重置。这意味着：
- **防御无法积累**：你必须在敌人攻击的当回合堆出足够的Block
- **过度防御是浪费**：如果敌人打11伤害而你堆了20 Block，多出的9点Block毫无意义
- **防御有时机性**：必须在正确的回合防御，提前或推后都无效

### 2.2 攻防权衡的本质

每回合玩家面对的核心问题是：

> "我这回合有限的3点能量，分配给打伤害还是堆格挡？"

这不是一个静态问题，因为敌人意图是**可见的**：

- 敌人下回合攻击15 → 我需要至少15点Block（或更快击杀）
- 敌人下回合强化 → 我可以全力输出
- 敌人下回合施加debuff → 我需要权衡是否接受debuff来输出

这种"**信息可见的攻防博弈**"是杀戮尖塔战斗的核心乐趣。

## 三、敌人AI设计：可读性与不确定性的平衡

### 3.1 意图系统

每个敌人在行动前会**公开展示下一步意图**（攻击多少伤害、施加什么效果、强化什么属性）。这是杀戮尖塔最重要的设计之一。

意图类型：

| 意图图标 | 含义 | 玩家应对 |
|---------|------|---------|
| 攻击（数字） | 造成X点伤害 | 堆Block或击杀 |
| 攻击+debuff | 造成伤害并施加负面效果 | Block + 考虑是否值得承受debuff |
| 强化 | 敌人获得增益 | 窗口期，全力输出 |
| 施加debuff | 不造成伤害但施加负面效果 | 可能可以承受 |

### 3.2 行为模式：约束随机

敌人并非完全随机行动，而是遵循**有约束的随机模式**。以两个经典敌人为例：

**颚虫（Jaw Worm）—— 第一幕普通怪**：

| 技能 | 效果 | 概率 |
|------|------|------|
| 撕咬（Chomp） | 11伤害 | 首回合固定使用，之后25% |
| 咆哮（Bellow） | +3力量，+6 Block | 45%，不能连续使用 |
| 蹂躏（Thrash） | 7伤害，+5 Block | 30%，不能连续3次 |

> 数据来源：[Jaw Worm - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Jaw_Worm)

**哥布林酋长（Gremlin Nob）—— 第一幕精英**：

| 技能 | 效果 | 概率 |
|------|------|------|
| 怒吼（Bellow） | +2激怒（每打出一张技能牌+2力量） | 首回合固定 |
| 冲锋（Rush） | 14伤害 | 67% |
| 骷髅猛击（Skull Bash） | 6伤害 + 施加2层易伤 | 33% |

> 数据来源：[Gremlin Nob - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gremlin_Nob)

### 3.3 行为模式的设计层次

从这两个例子可以提炼出敌人AI的三个设计层次：

**层次一：首回合固定**
几乎所有敌人首回合的行为是固定的（颚虫必用撕咬，酋长必用怒吼）。这给玩家一个**可预期的开局**，降低了第一回合的不确定性。

**层次二：概率分布 + 使用限制**
后续回合基于概率分布，但有"不能连续使用X次"的限制。这确保了：
- 行为有**统计上的倾向性**（45%咆哮意味着颚虫倾向于强化自己）
- 不会出现极端情况（如连续3次使用同一个技能）
- 玩家可以基于概率做**风险管理**

**层次三：机制性惩罚**
哥布林酋长的"激怒"机制是最高层次的设计——**它不随机，而是对玩家的行为做出响应**。打出技能牌（包括大部分防御牌）会触发力量增长。这迫使玩家做出反直觉的决策：宁可挨打也不防御。

> 这种"惩罚玩家特定行为"的设计在精英和Boss中广泛使用，是杀戮尖塔难度设计的关键手段。

## 四、状态效果系统

### 4.1 通用状态效果

这些效果可以同时作用于玩家和敌人：

| 效果 | 作用 | 叠加方式 |
|------|------|---------|
| 虚弱（Weakened） | 攻击伤害-25% | 持续回合数叠加 |
| 易伤（Vulnerable） | 受到攻击伤害+50% | 持续回合数叠加 |
| 力量（Strength） | 攻击伤害+N | 数值叠加，可负数 |
| 荆棘（Thorns） | 被攻击时反弹N伤害 | 数值叠加 |
| 人工制品（Artifact） | 抵消N次debuff | 数值叠加 |
| 再生（Regen） | 每回合初回复N HP | 数值-回合双重 |

### 4.2 玩家专属状态

| 效果 | 作用 |
|------|------|
| 虚弱状态（Frail） | 打出的Block卡牌-25%效果 |
| 敏捷（Dexterity） | 打出的Block卡牌+N效果 |
| 纠缠（Entangled） | 无法打出攻击牌 |

### 4.3 设计哲学

状态效果系统遵循几个关键原则：

**乘法 vs 加法**：易伤（+50%受到伤害）和虚弱（-25%造成伤害）是百分比修改，而力量是固定数值。这意味着：
- 易伤对高伤害技能的增幅更大（乘法效应）
- 力量对低费攻击牌的性价比提升更大（加法效应固定，但费用更低）
- 两者的交互创造了**非线性**的伤害计算

**可清除性**：大多数debuff有持续时间，会在几回合后自然消失。这避免了"一旦被debuff就永远劣势"的恶性循环。

## 五、战斗节奏：三阶段模型

每场战斗通常经历三个阶段：

### 阶段一：开局应对（前1-2回合）

- 观察敌人意图和初始行为
- 评估手牌质量（这回合抽到了什么？）
- 决定战斗策略（速杀 vs 持久战）
- 是否使用药水（爆发型药水适合开局建立优势）

### 阶段二：中期博弈（回合3-N）

- 攻防循环：根据敌人意图反复在"打伤害"和"堆Block"之间切换
- 资源管理：什么时候打出Power牌？什么时候使用消耗型卡牌？
- 局势判断：当前是在"胜势"还是"劣势"？这决定了是保守还是激进

### 阶段三：收尾（最后1-2回合）

- 精确计算伤害：能否这回合/下回合击杀？
- 计算Block需求：还需要防多少才能活过敌人的下一击？
- "够用就行"——过度输出和过度防御都是浪费

### 阶段转化的关键

战斗乐趣的核心在于**阶段之间的转化时机**——什么时候从中期博弈转入收尾？过早转入收尾可能因伤害不够而失败，过晚则可能浪费了本应用于防御的资源。这个判断就是"游戏感"的来源。

## 六、反事实推演

### 如果移除意图显示？

战斗将变成一个纯概率游戏。玩家不知道敌人下一击是打15还是强化自己，于是：
- 防御决策变成赌博——"猜敌人会攻击" vs "猜敌人会强化"
- 游戏从"我判断失误"变成"运气不好"，挫败感大幅上升
- 高难度战斗（精英、Boss）变得极其令人沮丧
- 所有围绕"读意图"构建的策略深度全部消失

意图显示是杀戮尖塔**将Roguelike的随机性转化为可管理的风险**的关键机制。没有它，游戏就退化为纯粹的手牌运气。

### 如果Block不每回合重置？

Block可以跨回合积累，这意味着：
- 前几回合可以"纯防御"，堆出巨额Block后再全力输出
- 战斗的时间压力大幅下降
- Block牌的价值飙升，攻防权衡消失（先堆够Block再打）
- 战斗变得冗长且缺乏紧张感

Block重置确保了**每回合都是一个新的攻防决策**，无法通过积累来回避这个核心权衡。

### 如果能量可以跨回合存储？

- 玩家可以"蓄力"——前几回合不出牌，攒能量后一波爆发
- 这创造了另一种策略维度，但也让"每回合做取舍"的核心乐趣消失
- 低费卡牌的价值下降，高费卡牌的价值上升
- 战斗节奏从"每回合都有事做"变成"前几回合空过，然后一回合定胜负"

## 七、可迁移经验

### 1. 信息可见的博弈设计
让玩家在做决策前看到对手的下一步意图，将"运气成分"转化为"风险管理"。玩家应该因为误判而失败，而非因为不知情而失败。

### 2. 约束随机而非纯随机
敌人的行为用"概率分布 + 使用限制"来约束，确保行为有统计倾向但不完全可预测。极端情况被人为排除，提升了体验的稳定性。

### 3. 资源重置创造决策循环
Block每回合重置、能量不可存储——这些"无法积累"的设计迫使玩家**每回合都做新的决策**，而非一次性规划后自动执行。

### 4. 行为响应式惩罚
哥布林酋长的"激怒"机制是优秀设计范例：不靠数值碾压来增加难度，而是通过惩罚玩家的习惯性行为（防御），迫使玩家改变策略。这种"打破舒适区"的难度设计比单纯增加伤害/血量更有趣。

### 5. 固定开局 + 随机后续
敌人首回合行为固定，后续随机。这给了玩家一个可学习的"入场考试"，同时保持了后续的不确定性。
