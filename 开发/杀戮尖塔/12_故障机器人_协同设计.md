# 12 故障机器人：协同设计与策划方法论

## 第一部分：协同效应清单

### 1.1 乘法放大型

| 协同组合 | 乘法机制 | 强度 |
|---------|---------|------|
| 专注 + 所有充能球 | 专注提升每颗球的被动/激发效果 | 极高（核心乘法点） |
| 专注 + 冰霜球 | 每点专注=每颗冰霜球+1Block | 极高（防御） |
| 专注 + 闪电球 | 每点专注=每颗闪电球+1伤害 | 高（输出） |
| 充能球槽 + 专注 | 球槽越多，每点专注的总收益越高 | 极高 |
| Electrodynamics + 闪电球 | 闪电球击中全体敌人 | 高（AOE化） |
| Echo Form + 任意强力牌 | 首张牌打出两次 | 极高 |

**策划意图**：专注是故障机器人的**唯一乘法点**——类似于铁甲战士的力量，但专注同时放大攻击（闪电）和防御（冰霜），是双维度的乘法。

### 1.2 引擎循环型

| 协同组合 | 循环机制 |
|---------|---------|
| Storm + Power牌 | 每打出1张Power牌充能1闪电球 → Power越多闪电越多 |
| Heatsinks + Power牌 | 每打出1张Power牌抽1牌 → Power越多抽越多 |
| Creative AI + Power牌 | 每回合随机获得1Power → 持续喂养Storm/Heatsinks |
| Recycle + 牌组过滤 | 消耗1牌→+1能量 → 精简牌组+能量 |
| Hello World + 稳定Power | 每回合获得1随机Power |
| Loop + 最右侧充能球 | 每回合最右侧球被动效果触发两次 |

**策划意图**：故障机器人是最典型的"铺垫型"引擎角色——前几回合积累Power和充能球，后期每回合自动获得大量资源。策划有意识地设计了"Power触发器"（Storm、Heatsinks、Mummified Hand），让Power牌成为"投入一次，持续收益"的引擎燃料。

### 1.3 条件解锁型

| 协同组合 | 条件机制 |
|---------|---------|
| Auto-Shields | 当前无Block时获得12(18)Block |
| Force Field | 每打出1张Power牌费用-1，最低0 |
| Barrage | 充能球越多伤害越高（每球触发一次） |
| Blizzard | 战斗中充能过的冰霜球数×2(3)全体伤害 |
| Thunder Strike | 战斗中充能过的闪电球数×2(3)随机伤害 |
| FTL | 手牌≤3张时费用0 |
| Equilibrium | 回合结束时保留手牌（不弃牌） |

**策划意图**：Force Field是最典型的条件解锁——初始3费天价，但每打出1张Power减1费。在Power密集的牌组中，Force Field变成0费Block牌。策划通过费用调节来奖励玩家对Power主题的投入。

### 1.4 资源转化型

| 协同组合 | 转化路径 |
|---------|---------|
| Plasma球 + 能量 | 激发等离子球获得2能量 |
| Fusion | 1费充能1等离子 → 逐步积累能量引擎 |
| Nuclear Battery (遗物) | 每场战斗开始充能1等离子 → 免费能量 |
| Recycle | 消耗1牌 → +1能量 |
| Aggregate | 抽牌堆每4张牌获得1能量 |
| TURBO | 获得2能量 → 下回合-1能量（透支型） |
| Double Energy | 能量翻倍 |
| Meteor Strike | 5费但充能3等离子 → 净赚3能量（如果激发） |

**策划意图**：等离子球是"能量即资源"的具象化——它存储在充能球槽中，可以被激发释放。策划让能量不再是"每回合3点"的固定值，而是可以**主动积累和释放**的可变资源。

### 1.5 缺陷互补型

| 协同组合 | 缺陷 → 互补 |
|---------|------------|
| Biased Cognition (+5专注但每回合-1) + Core Surge/Core Artifact | Core Surge给予1人工制品→抵消首回合debuff→保留+5专注永久 |
| Biased Cognition + Orange Pellets (遗物) | 同回合打Power+Attack+Skill→清除debuff |
| Consume (+2专注-1球槽) + Capacitor/Inserter | 增加球槽来抵消Consume的球槽减少 |
| Reprogram (+2力量+2敏捷-1专注) | 放弃专注→用力量/敏捷代替 |
| Claw (0费，+2伤害每打出1张Claw) + All for One | Claw消耗→All for One回收所有0费牌→Claw伤害累积 |

### 1.6 被动触发型

| 遗物/能力 | 触发条件 | 效果 |
|----------|---------|------|
| Data Disk | 每场战斗 | +1专注 |
| Gold-Plated Cables | 每回合 | 最右侧球被动多触发1次 |
| Symbiotic Virus | 每场战斗 | 开局充能1黑暗球 |
| Emotion Chip | 上回合受伤 | 本回合所有球被动触发 |
| Frozen Core (Boss遗物) | 回合结束有空球槽 | 自动充能1冰霜球 |
| Mummified Hand | 打出Power牌 | 手牌随机1牌本回合费用0 |
| Bird-Faced Urn | 打出Power牌 | 回复2HP |
| Inserter (Boss遗物) | 每2回合 | +1球槽 |

## 第二部分：卡池关键词聚类

### 2.1 充能球（Orbs）群

故障机器人的充能球系统有四种球体：

| 球体 | 被动效果 | 激发效果 | 定位 |
|------|---------|---------|------|
| 闪电 | 回合结束造成伤害 | 造成更高伤害 | 输出 |
| 冰霜 | 回合结束获得Block | 获得更多Block | 防御 |
| 黑暗 | 回合结束累积伤害 | 释放全部累积伤害 | 蓄力输出 |
| 等离子 | 回合开始获得能量 | 获得更多能量 | 资源 |

**充能球生成牌**：

| 牌 | 生成球体 | 费用 | 稀有度 |
|----|---------|------|--------|
| Zap | 1闪电 | 1(升级0) | 起始 |
| Dualcast | 激发最右球×2 | 1 | 起始 |
| Ball Lightning | 1闪电 | 1 | 普通 |
| Cold Snap | 1冰霜 | 1 | 普通 |
| Compile Driver | 1闪电 | 1 | 普通 |
| Glacier | 2冰霜 | 2 | 非凡 |
| Coolheaded | 1冰霜+抽1牌 | 1 | 普通 |
| Darkness | 1黑暗+强化所有黑暗球 | 1(升级0) | 非凡 |
| Doom and Gloom | 1黑暗 | 1 | 非凡 |
| Fusion | 1等离子 | 1(升级0) | 非凡 |
| Tempest | X个闪电 | X | 非凡 |
| Chaos | 随机充能球 | 1(升级0) | 非凡 |

**聚类结论**：每种球体都有对应的生成牌，且分布在不同稀有度。策划确保了玩家在**只出普通牌的情况下也能构建基础球组**（Ball Lightning + Cold Snap + Coolheaded + Compile Driver，全部普通）。

### 2.2 专注（Focus）群

| 卡牌 | 效果 | 稀有度 |
|------|------|--------|
| Defragment | +1(升级+2)专注 | 非凡 |
| Biased Cognition | +5专注但每回合-1 | 非凡 |
| Consume | +2(升级+3)专注但-1球槽 | 非凡 |
| Reprogram | +2力量+2敏捷-1专注（反方向） | 非凡 |
| Data Disk (遗物) | 每场战斗+1专注 | 普通 |

**聚类结论**：专注群只有**4张卡牌+1遗物**，远小于铁甲战士的力量群（8张）或静默猎人的毒素群（10张）。这是策划的有意选择——**专注太强了，所以来源稀少**。每获得1点专注，所有充能球同时变强，这在多球槽时是指数级收益。策划通过限制专注来源来控制这种指数增长的速度。

### 2.3 Power牌群

故障机器人有全角色最多的Power牌（14张），这直接支持了"Power触发器"引擎：

| 触发器 | 触发条件 | 效果 |
|--------|---------|------|
| Storm | 打出Power | 充能1闪电球 |
| Heatsinks | 打出Power | 抽1牌 |
| Mummified Hand (遗物) | 打出Power | 随机1牌费用0 |
| Bird-Faced Urn (遗物) | 打出Power | 回复2HP |
| Force Field | 打出Power | 费用-1 |

**聚类结论**：Power牌在故障机器人的设计中扮演了"引擎燃料"的角色——Power牌本身提供永久增益，同时触发多个"打出Power时"效果。这让打出Power牌的收益**叠加**——你不仅获得了Power本身的永久效果，还触发了充能、抽牌、回复、降费等连锁反应。

## 第三部分：资源流追踪

### 3.1 故障机器人的完整资源流图

```
                ┌──────────┐
                │ Power牌  │ ← 核心投入（永久性）
                └────┬─────┘
                     ↓ (打出Power)
          ┌──────────┼──────────┐
          ↓          ↓          ↓
     ┌─────────┐ ┌────────┐ ┌─────────┐
     │充能球   │ │ 触发器 │ │ 永久增益 │
     │(Storm)  │ │(Heatsinks)│ │(Defragment)│
     └────┬────┘ └───┬────┘ └────┬────┘
          ↓          ↓          ↓
     ┌─────────┐ ┌────────┐ ┌──────────┐
     │被动伤害  │ │抽牌    │ │专注提升   │
     │被动防御  │ │更多Power│ │所有球加强  │
     │被动能量  │ │继续循环 │ │乘法放大   │
     └─────────┘ └────────┘ └──────────┘
```

### 3.2 关键转化链

**链路1：Power → 充能球 → 被动输出/防御（通用引擎）**
```
打出Defragment → +1专注（永久）
  → 打出Coolheaded → 充能1冰霜球
  → 冰霜球被动Block由专注放大
  → 打出Capacitor → +2球槽
  → 更多冰霜球 → 专注的总收益进一步放大
```

**链路2：Power → 触发器链（Power引擎）**
```
Creative AI → 每回合获得1随机Power
  → Storm → 每打出Power充能1闪电
  → Heatsinks → 每打出Power抽1牌
  → Force Field → 每打出Power费用-1
  → Mummified Hand → 每打出Power随机1牌0费
  → Power越多 → 触发越多 → 更多Power → 指数增长
```

**链路3：等离子 → 能量 → 高费牌（能量引擎）**
```
Fusion → 充能1等离子
  → 激发等离子 → +2能量
  → Meteor Strike → 5费但充能3等离子 → 净产出能量
  → Double Energy → 能量翻倍
  → 高费牌不再是瓶颈
```

## 第四部分：策划设计意图还原

### 4.1 核心设计决策："专注是稀缺的乘法点"

**证据**：
- 专注来源只有4张牌+1遗物，远少于铁甲战士的力量来源（8张）
- Biased Cognition有持续衰减的代价
- Consume有减少球槽的代价
- 没有任何0费无条件+专注的牌

**还原的意图**：策划意识到专注在多球槽时是**指数级收益**（专注×球数=总收益），所以严格限制了专注来源。代价型专注（Biased Cognition的衰减、Consume的减球槽）让获取专注成为一个**有时限或有限制的赌注**——你获得了巨大的即时收益，但必须在代价兑现前利用好。

### 4.2 核心设计决策："Power牌是双重投资"

**证据**：
- 故障机器人有14张Power牌，全角色最多
- 5个"打出Power时触发"的效果
- Power牌打出后永久移除（不占手牌），但效果持续到战斗结束

**还原的意图**：策划让Power牌同时承担两个角色——**它既是永久增益，又是引擎触发器**。这让打出Power牌的决策变得丰富：你不只是在考虑"这张Power给我什么效果"，还在考虑"打出它触发了哪些连锁反应"。

### 4.3 核心设计决策："冰霜龟——极端防御作为合法策略"

**证据**：
- 冰霜球提供被动Block
- 专注放大冰霜球Block
- Frozen Core（Boss遗物）自动填充冰霜球
- Calipers（稀有遗物）让Block每回合只减15
- Wiki明确描述"Frost Turtle"可以在后期获得数百Block

**还原的意图**：策划有意设计了一种"不可穿透的防御"作为故障机器人的合法终点。这不是一个需要平衡掉的问题——它是故障机器人的**设计目标之一**。玩家需要投入大量回合和资源来建立冰霜龟，但一旦建成，游戏的性质从"求生"变为"如何击杀敌人"。

### 4.4 核心设计决策："Reprogram是反向设计空间"

**证据**：
- Reprogram给予+2力量+2敏捷但-1专注
- 它是唯一一张**主动降低专注**的牌
- 配合它构建的牌组不需要充能球——完全走力量/敏捷路线

**还原的意图**：策划在充能球系统中放置了一个"退出按钮"——如果你运气不好，没有获得专注和球槽扩展牌，Reprompt让你可以完全放弃充能球系统，转用通用属性（力量/敏捷）。这是**安全阀设计**的极端形式：不是弥补弱点，而是提供一条完全不同的路径。

## 第五部分：策划设计方法论提炼

### 方法论1："指数收益 + 稀缺来源"平衡法

**操作步骤**：
1. 设计一个**影响多个子系统的属性**（专注影响所有充能球）
2. 严格限制这个属性的来源数量（4张+1遗物）
3. 让部分来源带有**代价**（衰减、减球槽）
4. 代价型来源提供**即时巨大收益**（+5专注！）但有时限

**为什么有效**：当收益是指数级的（专注×球数），线性地增加来源会导致失衡。解决方案不是削弱收益，而是让来源**稀缺且有代价**。

### 方法论2："永久性投入"作为引擎燃料

**操作步骤**：
1. 设计一类"打出后永久存在"的效果（Power牌）
2. 围绕"打出这类效果"设计多个触发器
3. 每次打出这类效果 = 永久收益 + 即时触发收益
4. 触发器越多，这类效果的价值越高（正反馈循环）

**为什么有效**：传统的"一次性"牌只有一个维度的价值（打出时的效果）。Power牌引入了"永久性"维度，再通过触发器引入"连锁反应"维度——这让同一张牌的价值随着构筑的完善而上升。

### 方法论3："安全阀 = 替代路径"设计

**操作步骤**：
1. 识别核心系统的"失败模式"（没获得专注=充能球弱）
2. 设计一种**完全不同的替代路径**（Reprogram=放弃充能球用力量/敏捷）
3. 替代路径应使用**通用系统**而非独占系统（力量/敏捷是通用属性）
4. 替代路径本身也应足够有趣，而非仅是"退而求其次"

### 方法论4："球槽 = 容量 = 上限"设计

**操作步骤**：
1. 设计一个"容量"参数（球槽数量）
2. 让容量决定乘法点（专注）的总收益上限
3. 提供扩展容量的手段但限制数量
4. 容量扩展与乘法增长应分布在不同的获取渠道——增加策略空间

## 第六部分：可迁移设计工具

### 工具1：指数收益系统的平衡检查

```
1. 核心属性：__________ 影响 __________ 个子系统
2. 来源数量：_____ 张牌/遗物（如果>6，考虑减少）
3. 代价型来源：是否每张都有代价？ □是 □否（应为"是"）
4. 最大理论收益：______ × ______ = ______（如果过高，增加代价）
```

### 工具2：永久性投入设计模板

```
1. 永久性效果类型：__________（如Power牌）
2. 产出：每打出1张获得 __________
3. 触发器清单：
   - 触发器1：打出永久效果时获得 __________
   - 触发器2：打出永久效果时获得 __________
   - 触发器3：打出永久效果时获得 __________
4. 确保至少1个触发器在遗物层面（跨系统协同）
```

### 工具3：替代路径检查

当核心系统依赖运气获取时，检查：
- [ ] 是否存在一条**不依赖核心系统**的替代路径？
- [ ] 替代路径是否使用通用属性（力量/敏捷等）？
- [ ] 替代路径本身是否足够有趣？
- [ ] 替代路径的起点是否在普通稀有度（确保可达）？
