# 05 地图与进程设计：可规划的风险之旅

## 核心问题

地图结构如何让玩家在随机生成的环境中做出有意义的路径决策？三个幕的难度曲线如何与玩家成长曲线匹配？

---

## 一、地图生成规则

### 1.1 基本结构

每个幕的地图由**17层**组成，每层最多**6个房间位置**横向排列。路径在楼层之间连接，玩家从底层向上攀爬。

| 参数 | 数值 |
|------|------|
| 每幕层数 | 17层 |
| 每层最多房间 | 6个 |
| 路径起点 | 底层，玩家可选择 |
| 路径终点 | 顶层Boss，所有路径汇合 |

> 数据来源：[Map Generation - Slay the Spire Wiki (wiki.gg)](https://slaythespire.wiki.gg/wiki/Map_Generation)

### 1.2 固定楼层

并非所有楼层都随机——每个幕有**固定的锚点楼层**，确保基本的节奏结构：

| 层数 | 固定内容 | 设计意图 |
|------|---------|---------|
| 第1层 | 普通战斗 | 无缓冲，直接进入游戏节奏 |
| 第9层 | 宝箱房 | 中点奖励，给玩家一件免费遗物 |
| 第15层 | 火堆 | Boss前的最终准备（休息或升级） |
| 第17层 | Boss | 幕末挑战 |

> 数据来源：[Act 1 - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Act_1)

这些固定楼层的设计目的是**给玩家规划的基础**。在一个高度随机的游戏中，这些锚点让玩家知道："无论路径怎么走，第9层一定有宝箱，第15层一定有休息机会。"

### 1.3 路径规则

地图生成遵循以下约束：
- 路径只能向上连接相邻楼层
- 不能跳过楼层
- 所有路径最终汇合到Boss层
- 同一种敌人遭遇不会在连续3场战斗中重复出现

> 数据来源：[Monsters - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Monsters) — "The same monster encounter cannot be fought again in the next two monster encounters"

## 二、七种房间类型与风险回报谱系

| 类型 | 风险 | 回报 | 可控性 | 设计功能 |
|------|------|------|--------|---------|
| 宝箱房 | 无 | 1件遗物 | 完全可控 | 中点奖励，纯正面 |
| 火堆 | 无 | 30%HP回复或升级1张牌 | 完全可控 | 策略选择，节奏缓冲 |
| 商店 | 低（消耗金币） | 精确购买 | 高度可控 | 填补牌组缺口 |
| 普通战斗 | 低-中 | 3选1牌 + 金币 | 中等 | 基础成长来源 |
| 事件 | 不确定 | 从极好到极差 | 低 | 方差创造惊喜 |
| 精英战斗 | 高 | 额外1件遗物 | 低 | 高风险高回报 |
| Boss | 最高 | 稀有牌 + Boss遗物 | 最低 | 幕末检验 |

### 2.1 商店的精确控制

商店是整个游戏中**可控性最高**的成长节点。每次商店固定提供：

| 商品 | 数量 | 说明 |
|------|------|------|
| 职业卡牌 | 5张 | 前2张攻击、后2张技能、第5张能力 |
| 无色卡牌 | 2张 | 其中1张必为稀有 |
| 遗物 | 3件 | 其中1件为商店专属遗物 |
| 药水 | 3瓶 | 随机 |
| 移除卡牌 | 1次 | 首次75金币，每次+25（笑脸面具可降至50） |

> 数据来源：[Gameplay - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gameplay)

商店的"移除卡牌"服务是牌组精简的核心渠道之一。价格递增机制（75→100→125→...）创造了一个自然的稀缺性——玩家不可能无限删牌，必须选择最值得删的。

### 2.2 火堆的双重选择

火堆提供两个选项：**回复30%最大HP** 或 **升级一张卡牌**。

这个看似简单的选择是中观策略的关键决策点：
- HP较低、后续有精英/Boss → 选择回复
- HP健康、有关键卡需要升级 → 选择升级
- 两者都需要的紧张感 → 正是设计者想要的

**固定在Boss前一层的火堆**是一个精妙的保底设计——无论玩家之前的路径如何，都至少有一次升级或回复的机会来准备Boss战。

## 三、敌人分布与难度曲线

### 3.1 各幕普通敌人

**第一幕**（起步期——教学与基础博弈）：

| 遭遇 | 出现概率 | 特点 |
|------|---------|------|
| 邪教徒（Cultist） | 25% | 首回合强化，教玩家"不要拖" |
| 颚虫（Jaw Worm） | 25% | 攻防兼备，教玩家攻防权衡 |
| 2只虱子（2 Louses） | 25% | 多目标战斗，教玩家AOE价值 |
| 小型史莱姆 | 25% | 多目标，不同史莱姆有不同技能 |

> 数据来源：[Monsters - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Monsters)

第一幕的敌人设计有明确的**教学功能**：邪教徒教玩家"趁弱击杀"，颚虫教"攻防平衡"，多目标战斗引入AOE意识。

**第二幕**（发展期——复杂机制引入）：

| 遭遇 | 出现概率 | 特点 |
|------|---------|------|
| 球形守卫（Spheric Guardian） | 20% | 自带Block，教玩家应对高防御 |
| 天选者（Chosen） | 20% | 复杂debuff机制 |
| 蛇形植物（Snake Plant） | 21% | 后期遭遇中最高概率 |
| 百夫长+秘术师（Centurion and Mystic） | 21% | 互补双怪组合，教玩家优先级判断 |

**第三幕**（冲刺期——压力测试）：

| 遭遇 | 出现概率 | 特点 |
|------|---------|------|
| 3只暗影仔（3 Darklings） | 33.3%/12.5% | 复活机制，教玩家集火 |
| 颚虫群（Jaw Worm Horde） | 12.5% | 第一幕弱敌的强化版 |
| 螺旋生长体（Spire Growth） | 12.5% | 持续强化型 |
| 瞬间体（Transient） | 12.5% | 时间限制型——必须在指定回合内击杀 |

### 3.2 精英与Boss

**精英分布**：
- 每个幕有3种不同的精英
- 精英不能连续两次遇到同一种
- 击败精英奖励：25-35金币 + 1件遗物 + 卡牌奖励

> 数据来源：[Elites - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Elites)

**Boss分布**：
- 每个幕有3种可能的Boss，随机选择1种
- Boss在地图顶部可见（玩家可以提前知道是哪个Boss并针对性构筑）
- 击败Boss后满血恢复
- 奖励：约90-110金币 + 药水 + 3选1稀有卡 + 3选1Boss遗物

> 数据来源：[Bosses - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Bosses)

Boss的**提前可见性**是一个关键设计：玩家在幕初就能看到自己要面对哪个Boss，从而在整个幕的探索中有方向性地构筑牌组。这给了宏观策略一个明确的目标。

## 四、事件系统：受控的随机性

### 4.1 事件分布

| 分类 | 数量 | 可出现的幕 |
|------|------|-----------|
| 通用事件 | 16个 | 多幕 |
| 第一幕专属 | 12个 | 仅第一幕 |
| 第二幕专属 | 16个 | 仅第二幕 |
| 第三幕专属 | 8个 | 仅第三幕 |

> 数据来源：[Events - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Events)

第四幕没有事件（没有问号房间）。

### 4.2 事件的设计哲学

事件是杀戮尖塔中**方差最大的房间类型**。它们大致分为三类：

**纯正面事件**：免费卡牌升级、免费遗物、免费金币。这些是"幸运时刻"，给玩家惊喜。

**代价交换事件**：牺牲HP/金币/最大HP换取稀有奖励。这是"风险-回报"的极致——玩家需要评估当前状态是否"付得起"这个代价。

**纯负面事件**：造成伤害、施加诅咒、强制移除卡牌。这些是"倒霉时刻"，测试玩家在不利条件下的适应能力。

**关键平衡**：如果事件只有正面，问号房间就成了无脑选择；如果只有负面，玩家会极力避开。混合设计让"是否走问号房间"本身成为一个基于当前状态的决策。

## 五、三幕的难度曲线

### 5.1 整体曲线

```
第一幕：学习期          第二幕：应用期          第三幕：检验期
├─ 基础敌人教学          ├─ 复杂敌人机制          ├─ 压力测试
├─ 牌组雏形建立          ├─ 牌组核心确定          ├─ 牌组成熟/固化
├─ 低数值，容错高        ├─ 中数值，开始惩罚错误    ├─ 高数值，容错低
└─ Boss是第一次大考      └─ Boss检验构筑方向       └─ Boss是最终检验
```

### 5.2 难度递增的手段

| 维度 | 第一幕 → 第二幕 → 第三幕 |
|------|-------------------------|
| 敌人HP | 显著递增 |
| 敌人伤害 | 显著递增 |
| 敌人机制复杂度 | 简单机制 → 多层机制 → 组合机制 |
| 敌人数量/组合 | 单体或双怪 → 双怪组合 → 多怪协同 |
| 对牌组的要求 | 基本攻防即可 | 需要明确方向 | 需要完整体系 |
| 容错空间 | 较大 | 中等 | 很小 |

### 5.3 玩家成长与难度的匹配

玩家在三个幕中的成长手段也是递增的：

| 幕 | 可获得的关键资源 |
|----|----------------|
| 第一幕 | 基础卡牌（以普通/非凡为主）、普通遗物、少量金币 |
| 第二幕 | 更多非凡卡牌、稀有卡出现概率提升、更多遗物 |
| 第三幕 | 稀有卡牌概率最高（非商店3%基础）、Boss遗物 |

卡牌稀有度概率（非商店）：
- 普通60% / 非凡37% / 稀有3%（每出一张普通牌，稀有概率+1%）

> 数据来源：[Gameplay - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gameplay) — Card Rarity section

这个"每出一张普通牌稀有概率+1%"的设计极为巧妙——它意味着**前期拿了很多普通牌的玩家，后期获得稀有牌的概率更高**。这在一定程度上补偿了前期牌组质量低的劣势。

## 六、反事实推演

### 如果地图完全随机，没有固定楼层？

- 玩家可能在Boss前遇到连续3场精英，无法规划
- 也可能全是火堆和宝箱，毫无挑战
- 节奏感完全丧失——有的局太紧，有的局太松
- 固定楼层是"公平性的最低保障"

### 如果Boss不可提前看到？

- 玩家无法针对性构筑，只能追求"万能牌组"
- 这会大幅降低构筑的策略性——所有局都倾向于均衡型
- Boss可见性鼓励"这局我要针对X来构筑"的定向思维

### 如果没有商店？

- 牌组精简的主要渠道消失（移除卡牌几乎只能靠事件和火堆的特定选项）
- 牌组质量完全依赖战斗奖励的随机性
- "填补最后一环"的能力消失——玩家无法主动补强弱点
- 游戏的随机性主导感会大幅上升

## 七、可迁移经验

### 1. 固定锚点 + 随机填充
在随机生成的地图中设置固定的结构锚点（中点奖励、Boss前休息），让玩家始终有规划的基础，同时保留随机性带来的新鲜感。

### 2. 房间类型的"风险谱"
将房间类型按风险-回报排列，让路径选择本身成为策略。不同状态的玩家会做出不同的最优路径选择——这正是"决策"的定义。

### 3. 前瞻信息赋予策略方向
Boss在地图顶部可见，让玩家从幕初就有构筑目标。前瞻信息让随机性服务于策略而非替代策略。

### 4. 补偿机制平衡运气
"稀有概率递增"等隐藏机制补偿了运气不佳的玩家，让游戏不会因为早期随机性差而彻底无望。

### 5. 多维难度递增
难度不只通过数值（HP/伤害）提升，还通过机制复杂度（敌人技能组合）、时间压力（回合限制）等多维度递增。这让每个幕都有质的不同，而非只是数值膨胀。
