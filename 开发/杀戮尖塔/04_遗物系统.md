# 04 遗物系统：被动成长的协同艺术

## 核心问题

遗物作为"被动成长"如何与卡牌的"主动构筑"形成互补？Boss遗物的代价设计为何是杀戮尖塔最精妙的风险-回报设计？

---

## 一、遗物系统概览

### 1.1 定义与基本属性

遗物是**全局持续**的被动物品，一旦获得就持续生效到本局游戏结束。与卡牌不同，遗物不需要"打出"——它们自动发挥作用。

> 数据来源：[Relics - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Relics) — "Relics are permanent items that provide a passive bonus for the rest of the run."

### 1.2 稀有度与获取

| 稀有度 | 获取来源 | 概率权重 |
|--------|---------|---------|
| 起始（Starter） | 角色自带 | 固定 |
| 普通（Common） | 宝箱/精英/事件/商店 | 50% |
| 非凡（Uncommon） | 宝箱/精英/事件/商店 | 33% |
| 稀有（Rare） | 宝箱/精英/事件/商店 | 17% |
| Boss | 击败Boss后3选1 | 固定 |
| 商店 | 只能从商店购买 | 固定 |
| 事件 | 只能从特定事件获得 | 固定 |

> 宝箱的稀有度概率不同：49%/42%/9%，略微提高了非凡概率。

### 1.3 遗物总数

每个角色可获得的遗物池包含约170件左右，其中大部分是所有角色共享的通用遗物，少量是角色专属。遗物池是有限的——当所有遗物都被获取后，宝箱会给出特殊的"头冠"（Circlet，无效果）。

## 二、遗物的设计功能分类

### 2.1 基础增强型

直接提供数值加成，无特殊条件：

| 遗物 | 稀有度 | 效果 |
|------|--------|------|
| Vajra | 普通 | 每场战斗开始+1力量 |
| Oddly Smooth Stone | 普通 | 每场战斗开始+1敏捷 |
| Anchor | 普通 | 每场战斗开始10 Block |
| Akabeko | 普通 | 每场战斗第一次攻击+8伤害 |
| Lantern | 普通 | 每场战斗第一回合+1能量 |

这些遗物的价值不取决于牌组类型，对任何构筑都有帮助。它们是**最安全的遗物选择**，也是新手最容易理解的。

### 2.2 条件触发型

在特定条件下生效，需要玩家行为配合：

| 遗物 | 稀有度 | 触发条件 | 效果 |
|------|--------|---------|------|
| Kunai | 非凡 | 一回合打出3张攻击 | +1敏捷 |
| Shuriken | 非凡 | 一回合打出3张攻击 | +1力量 |
| Ornamental Fan | 非凡 | 一回合打出3张攻击 | +4 Block |
| Pen Nib | 普通 | 打出第10张攻击 | 双倍伤害 |
| Ink Bottle | 非凡 | 打出第10张牌 | 抽1牌 |
| Sundial | 非凡 | 第3次洗牌 | +2能量 |

"一回合打出3张攻击"系列（Kunai/Shuriken/Ornamental Fan）是条件触发设计的典范——它们引导玩家的牌组向"多段低费攻击"方向构建，同时三件遗物可以叠加触发。

### 2.3 机制改变型

改变游戏的基本规则：

| 遗物 | 稀有度 | 规则改变 |
|------|--------|---------|
| Ice Cream | 稀有 | 能量可跨回合存储 |
| Runic Pyramid | Boss | 回合结束不弃手牌 |
| Snecko Eye | Boss | 每回合多抽2牌，但所有卡牌费用随机化 |
| Calipers | 稀有 | Block每回合只减15而非清零 |
| Dead Branch | 稀有 | 每消耗一张牌随机获得一张牌 |

这类遗物的影响最为深远——它们不只是"加数值"，而是**改变游戏的底层规则**。获得Ice Cream后，"能量不可存储"这个核心约束就消失了；获得Runic Pyramid后，"回合结束弃牌"的规则就改变了。这些遗物让同一副牌组获得后产生**质变**。

### 2.4 防御保底型

提供安全网，降低最坏情况的影响：

| 遗物 | 稀有度 | 效果 |
|------|--------|------|
| Orichalcum | 普通 | 回合结束无Block时获得6 Block |
| Meat on the Bone | 非凡 | 战斗结束HP≤50%时回复12 |
| Tungsten Rod | 稀有 | 每次失去HP减少1 |
| Lizard Tail | 稀有 | 死亡时回复到50%HP（一次） |
| Fossilized Helix | 稀有 | 每场战斗防止第一次HP损失 |

这些遗物的价值在于**降低风险**。Orichalcum在玩家没有Block牌时提供基础防御；Tungsten Rod把每次伤害减1（在多段攻击中效果叠加）。它们是牌组防御不足时的"保险"。

## 三、Boss遗物：代价设计

### 3.1 "+1能量"系列

Boss遗物中最核心的设计模式：**给予最强的增益（+1每回合能量），但附带一个显著代价**：

| Boss遗物 | 增益 | 代价 |
|---------|------|------|
| Busted Crown | +1能量 | 卡牌奖励少2个选项 |
| Coffee Dripper | +1能量 | 不能在火堆休息 |
| Cursed Key | +1能量 | 开宝箱获得诅咒 |
| Ectoplasm | +1能量 | 不能获得金币 |
| Fusion Hammer | +1能量 | 不能在火堆升级 |
| Philosopher's Stone | +1能量 | 所有敌人开局+1力量 |
| Sozu | +1能量 | 不能获得药水 |
| Velvet Choker | +1能量 | 每回合最多打6张牌 |
| Runic Dome | +1能量 | 看不到敌人意图 |
| Mark of Pain（铁甲） | +1能量 | 每场战斗洗入2张伤口 |

### 3.2 代价设计的精妙之处

**每回合+1能量**意味着从3点变成4点——这是一个**33%的增幅**，几乎等同于每回合多打一张牌。这太强了，如果无条件给予会破坏平衡。

解决方案不是削弱增益，而是**从游戏的其他维度扣除**：
- 扣除信息（Busted Crown少选项、Runic Dome无意图）
- 扣除恢复（Coffee Dripper不能休息、Mark of Pain给伤口）
- 扣除资源（Ectoplasm无金币、Sozu无药水、Cursed Key给诅咒）
- 扣除灵活性（Velvet Choker限制出牌数）

这种设计让Boss遗物的选择变成了一个**个性化评估**：

- 我牌组已经很强，但缺乏后续提升 → Busted Crown代价可接受
- 我HP很健康，不需要火堆休息 → Coffee Dripper代价可接受
- 我有消耗流，伤口反而是燃料 → Mark of Pain代价可忽略
- 我牌组依赖药水 → Sozu代价不可接受

**没有"永远选"或"永远不选"的Boss遗物**——每个选择都取决于当前牌组状态。这是代价设计的最高境界。

### 3.3 非能量型Boss遗物

| 遗物 | 效果 | 评价 |
|------|------|------|
| Runic Pyramid | 不弃手牌 | 极强的计划能力，代价是需精确管理手牌 |
| Snecko Eye | 多抽2牌，费用随机化 | 高费卡变便宜的概率高，但不稳定 |
| Pandora's Box | 变换所有Strike和Defend | 大幅提升牌组质量，但结果不可控 |
| Empty Cage | 移除2张牌 | 牌组精简，确定性高 |
| Astrolabe | 变换3张牌并升级 | 精简+升级，但变换结果不可控 |
| Black Star | 精英掉2件遗物 | 鼓励打精英，但本身不提供即战力 |
| Sacred Bark | 药水效果翻倍 | 仅在药水充足时有效 |

## 四、遗物与卡组的协同效应

### 4.1 协同的层次

遗物与卡组的协同分为三个层次：

**层次一：无脑兼容**——遗物对任何牌组都有帮助
- Vajra（+1力量）让所有攻击牌变强
- Anchor（+10 Block）让每场战斗开局更安全

**层次二：方向性引导**——遗物引导牌组往特定方向发展
- Shuriken（3次攻击后+1力量）→ 鼓励构建多段攻击牌组
- Frozen Egg（Power牌自动升级）→ 鼓励多拿Power牌
- Ornamental Fan（3次攻击后+4 Block）→ 攻击流获得免费防御

**层次三：质变级协同**——遗物+特定卡牌组合改变游戏玩法
- Dead Branch（消耗→随机牌）+ Corruption（技能免费消耗）= 无限引擎
- Snecko Eye（随机费用）+ 高费牌 = 高费牌可能变0费
- Charon's Ashes（消耗→3伤害）+ 消耗流 = 消耗即输出

### 4.2 关键协同案例

**Dead Branch + Corruption**：这是杀戮尖塔中最著名的协同组合。Corruption让所有技能牌费用变0但消耗，Dead Branch让每次消耗产生随机新牌。两者结合后：
1. 所有技能免费打出
2. 每打出一张技能就消耗并随机获得一张新牌
3. 新牌可能是攻击/能力，继续打出
4. 形成近乎无限的循环

这个协同**不是设计者预设的固定组合**——两件都是随机获取的。但当玩家同时获得两者时，游戏体验发生质变。这种"偶然发现的OP组合"是Roguelike乐趣的核心来源之一。

## 五、遗物的叙事功能

### 5.1 "旅程记忆"

遗物不只是数值加成，它们还是**每次独特旅程的物理记录**：

- 从精英手中艰难获得的遗物 → 让你想起那场战斗
- 从事件中冒险换来的遗物 → 让你想起那个抉择
- 商店中咬牙买下的遗物 → 让你想起当时的取舍

当游戏结束时，打开遗物栏看到满满一排遗物，每个都代表一段经历。这是杀戮尖塔"一局游戏就是一次故事"体验的重要组成部分。

### 5.2 角色专属遗物的身份塑造

| 角色 | 起始遗物 | 主题 |
|------|---------|------|
| 铁甲战士 | Burning Blood（战斗结束回6HP） | 以血换血，持久战 |
| 静默猎人 | Ring of the Snake（每场多抽2牌） | 信息优势，灵活应对 |
| 故障机器人 | Cracked Core（每场开局获得闪电充能球） | 科技启动，被动输出 |
| 观者 | Pure Water（每场开局获得奇迹牌） | 精神力量，额外能量 |

起始遗物是角色的"身份标识"，暗示了每个角色的设计方向。

## 六、反事实推演

### 如果Boss遗物没有代价，只有增益？

- +1能量的Boss遗物变成"无脑选"
- Boss遗物的选择不再取决于牌组状态，失去策略性
- 游戏平衡被打破——+1能量太强，无条件获得会让后续过于简单
- 每局Boss战后都"变强了"而非"做出了一个赌注"
- 失去"这个代价我能不能承受？"的紧张决策

### 如果遗物可以选择不拿？

- 牌组已经有了遗物引导的方向，不想要的遗物可以拒绝
- 这会让遗物变得像卡牌一样需要"构筑"
- 但遗物的"不可拒绝"恰恰是它的叙事力量——你得到了什么就是什么，必须适应

**实际上，遗物确实不能主动拒绝**（除了Boss遗物3选1可以选"不选某个"）。这个设计让每次获得遗物都是"惊喜"而非"选择"，强化了Roguelike的随机性和适应主题。

### 如果遗物有耐久度？

- 遗物会在使用后消耗，需要不断获取新的
- 遗物的"旅程记忆"功能消失（它们不会陪你到最后）
- 长期策略规划变得困难（遗物组合可能随时断裂）
- 增加了资源管理维度，但失去了"永久成长"的安全感

## 七、可迁移经验

### 1. 增益-代价对称设计
当某个增益太强时，不要削弱增益，而是添加一个对等的代价。代价应该是**从游戏的其他维度扣除**（信息、资源、灵活性），而非简单的数值平衡。

### 2. 条件触发引导玩家行为
遗物的条件触发机制（如"打出3张攻击后"）可以引导玩家往特定方向构筑，而不直接告诉玩家"你应该这样做"。这是一种隐性的教学和引导。

### 3. 质变级协同创造发现感
最好的Roguelike设计包含"偶然发现的OP组合"。这些组合不应是预设的固定搭配，而是系统之间自然涌现的产物。它们让每次游戏都有可能发现"新玩法"。

### 4. 被动物品的叙事价值
收集品（装备、遗物、道具）不只是数值载体，它们还是玩家旅程的物理记录。让每件物品都有独特的获取方式和效果描述，可以强化"每局都是一次独特冒险"的体验。

### 5. "不能拒绝"的随机性
遗物不可拒绝（除了Boss遗物3选1），这迫使玩家适应获得的一切。这比"完全可控的收集"更能培养玩家的适应能力和创造力。
