# 13 观者：协同设计与策划方法论

## 第一部分：协同效应清单

### 1.1 乘法放大型

| 协同组合 | 乘法机制 | 强度 |
|---------|---------|------|
| 暴怒(Wrath) + 任意攻击 | 伤害×2 | 极高（核心乘法点） |
| 神圣(Divinity) + 任意攻击 | 伤害×3 | 极高（终极乘法点） |
| Wreath of Flame + Ragnarok | 25(升级35)+5×5(升级7×5)=50(70)→加成后伤害翻倍 | 极高 |
| Blasphemy + 任意攻击 | 伤害×3但回合结束死亡 | 极高（终极赌注） |
| Brilliance + 真言累积 | 每次进入姿态+4(升级+6)伤害→可无限叠加 | 高 |
| Fasting + 暴怒 | +3力量在暴怒下被×2 | 高 |

**策划意图**：观者的乘法点不是"属性×N"，而是**姿态本身作为乘数**。暴怒让一切攻击翻倍，神圣让一切×3。策划没有设计"力量×3"这种特定放大器，而是让**战斗模式本身**成为放大器。

### 1.2 引擎循环型

| 协同组合 | 循环机制 |
|---------|---------|
| Eruption+(1费进暴怒) + Inner Peace(1费进平静) | 暴怒→平静退2能量→付暴怒1费→净赚1能量→循环 |
| Eruption+ + Tantrum + Rushdown | 每次姿态切换抽2牌→小牌组中可无限循环 |
| Violet Lotus (遗物) + 退出平静 | 退出平静额外+1能量 |
| Flurry of Blows + 姿态切换 | 每次切换姿态暗器回到手牌→免费攻击 |
| Mental Fortress + 姿态切换 | 每次切换+3(升级+4)Block→无限防御 |
| Talk to the Hand + 多段攻击 | 敌人受到攻击时获得Block→攻击越多Block越多 |

**策划意图**：观者的引擎核心是**姿态切换循环**——在暴怒和平静之间反复切换。平静退出给能量，暴怒给伤害翻倍，切换本身触发各种被动效果。策划将"切换"设计为一种**可循环的行为**，而非一次性选择。

### 1.3 条件解锁型

| 协同组合 | 条件机制 |
|---------|---------|
| Fear No Evil + 敌人攻击意图 | 敌人意图攻击时进入平静(0费) |
| Cut Through Fate + 窥视 | 攻击+窥视2(升级3)+抽1牌 |
| Pressure Points + 叠加 | 施加N层压力→敌人HP=N时死亡 |
| Crush Joints + 姿态切换 | 切换姿态时给敌人1易伤 |
| Wallop + 伤害 | 获得等于伤害值的Block |
| Consecrate + 暴怒 | 暴怒下全体10(升级15)伤害 |

### 1.4 资源转化型

| 协同组合 | 转化路径 |
|---------|---------|
| 平静退出 | 退出平静→+2能量（核心能量来源） |
| Violet Lotus | 退出平静→额外+1能量 |
| Miracle (Pure Water) | 0费→+1能量（每场战斗免费） |
| Deus Ex Machina | 保留→下回合获得2(升级3)Miracle→大量能量 |
| Worship | 2费→5真言（10真言=进入神圣=+3能量+×3伤害） |
| Collect | 保留→下回合获得奇迹（能量=保留回合数） |
| Deva Form | 每回合+1能量（永久增长） |

**策划意图**：观者的能量来源**不是固定的3点/回合**，而是通过姿态系统和奇迹牌动态生成的。平静退出给能量、Miracle给能量、Deva Form每回合加能量——策划让观者成为一个**能量可无限增长**的角色。

### 1.5 缺陷互补型

| 协同组合 | 缺陷 → 互补 |
|---------|------------|
| 暴怒(受击伤害也×2) + Mental Fortress | 切换姿态获得Block→抵消暴怒下的脆弱 |
| 暴怒 + Halt | 暴怒下Halt获得Block×2(升级×3) |
| Blasphemy(回合结束死亡) + 确保本回合击杀 | 终极赌注：用死亡威胁换取×3伤害 |
| Fasting(-1能量/回合) + 姿态能量 | 多余的能量生成抵消Fasting的代价 |
| Scry + 大牌组 | 窥视可以过滤不需要的牌→大牌组也可控 |

### 1.6 被动触发型

| 遗物/能力 | 触发条件 | 效果 |
|----------|---------|------|
| Damaru | 每回合 | +1真言 |
| Duality | 打出攻击 | +1临时敏捷 |
| Teardrop Locket | 每场战斗 | 开局在平静状态 |
| Cloak Clasp | 回合结束 | 手牌每张+1Block |
| Golden Eye | 窥视时 | 额外窥视2张 |
| Melange (商店遗物) | 每次洗牌 | 窥视3张 |
| Violet Lotus (Boss遗物) | 退出平静 | 额外+1能量 |
| Holy Water (Boss遗物) | 每场战斗 | 开局3张Miracle |

## 第二部分：卡池关键词聚类

### 2.1 姿态（Stance）群

**进入暴怒的牌**：

| 卡牌 | 费用 | 额外效果 | 稀有度 |
|------|------|---------|--------|
| Eruption | 2(升级1) | 9伤害 | 起始 |
| Tantrum | 1 | 12伤害+可重复使用 | 非凡 |
| Crescendo | 0(升级保留) | 仅进入姿态 | 普通 |
| Blasphemy | 1(升级保留) | 进入神圣+×3伤害+回合结束死亡 | 稀有 |
| Indignation | 1 | 进入暴怒 | 非凡 |

**进入平静的牌**：

| 卡牌 | 费用 | 额外效果 | 稀有度 |
|------|------|---------|--------|
| Vigilance | 2 | 12Block | 起始 |
| Inner Peace | 1 | 如果在暴怒则抽3牌(升级+抽3) | 非凡 |
| Tranquility | 0(升级保留) | 仅进入姿态 | 普通 |
| Fear No Evil | 1 | 条件：敌人攻击意图时0费 | 非凡 |

**姿态切换触发器**：

| 卡牌/遗物 | 切换时触发 |
|----------|----------|
| Flurry of Blows | 回到手牌(0费攻击) |
| Rushdown | 抽2牌 |
| Mental Fortress | +3(升级+4)Block |
| Crush Joints | 1易伤 |
| Nirvana | 窥视时+Block(配合姿态切换的窥视) |

**聚类结论**：姿态群包含**9张姿态进入牌 + 5张触发器**，是观者最大的协同群。策划的设计逻辑是三层结构：
1. **进入手段**：多张进入不同姿态的牌
2. **触发器**：切换姿态时获得收益
3. **循环引擎**：低成本进出姿态+触发器收益→循环

### 2.2 窥视（Scry）群

| 卡牌 | 窥视数量 | 费用 | 额外效果 |
|------|---------|------|---------|
| Third Eye | 3(升级5) | 1 | +4Block |
| Cut Through Fate | 2(升级3) | 1 | 7伤害+抽1牌 |
| Foresight | 3(升级4) | 1(能力) | 每回合触发 |
| Just Lucky | 1(升级2) | 0 | 3伤害+1Block |
| Evaluate | 窥视后抽1牌 | 1 | 保留→生成Insight |

**窥视触发器**：

| 卡牌/遗物 | 窥视时触发 |
|----------|----------|
| Nirvana | +2(升级+3)Block |
| Weave | 弃掉时回到手牌 |
| Golden Eye (遗物) | 额外窥视2张 |

**聚类结论**：窥视群较小（5张+3个触发器），但窥视的独特性在于它是**信息控制**而非资源产出。窥视让你选择"接下来抽什么牌"，这在精确构筑（如姿态切换）时极其有价值。

### 2.3 保留（Retain）群

| 卡牌 | 保留时效果 |
|------|----------|
| Sands of Time | 每保留1回合费用-1 |
| Windmill Strike | 每保留1回合伤害+4(升级+6) |
| Worship | 保留→可以等待最佳时机进入神圣 |
| Brilliance | 保留时每回合不提供额外效果，但每进入一次姿态+伤害 |
| Establishment | 保留的牌每回合费用-1（所有保留牌通用） |
| Deceive Reality | 保留→生成Safety(12Block) |

**聚类结论**：保留群有6张卡牌。策划的设计意图是：**等待本身是一种资源**。Sands of Time保留2回合后变成0费40伤害——你用"等待"换取了"免费"。这创造了一种独特的节奏——不是"每回合都要做最有价值的事"，而是"有些牌值得等"。

### 2.4 真言/神圣（Mantra/Divinity）群

| 卡牌 | 真言数量 | 费用 |
|------|---------|------|
| Prostrate | 2(升级3) | 0 |
| Damaru (遗物) | 1/回合 | — |
| Pray | 1(升级2) | 1(保留→生成Insight) |
| Worship | 5 | 2(保留) |
| Devotion | 每回合+2(升级+3) | 2(能力) |
| Collect | 保留N回合→N张Miracle | 1(保留) |

**聚类结论**：真言群较小（5张+1遗物），且达成神圣需要10真言——这意味着需要多次循环牌组。策划有意识地让神圣难以达成但回报极高（×3伤害+3能量），使其成为"偶尔触发的终极爆发"而非常规手段。

## 第三部分：资源流追踪

### 3.1 观者的完整资源流图

```
            ┌──────────────────────────┐
            │       姿态切换            │ ← 核心行为
            └─────────┬────────────────┘
                      ↓
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
   ┌─────────┐  ┌──────────┐  ┌──────────┐
   │ 能量    │  │ 伤害倍率  │  │ 触发效果  │ ← 切换产出
   │(退平静) │  │(进暴怒)  │  │(Rushdown)│
   └────┬────┘  └────┬─────┘  └────┬─────┘
        ↓            ↓              ↓
   ┌─────────┐  ┌──────────┐  ┌──────────┐
   │高费牌   │  │ 爆发伤害  │  │ 抽牌     │ ← 产出消耗
   │Deva Form│  │ 一回合击杀│  │ 更多切换牌│
   │Ragnarok │  │          │  │ 继续循环 │

   独立资源流：
   ┌──────────┐       ┌──────────┐
   │  保留    │ ────→ │ 等待=减费│
   │Sands of  │       │ 或增伤   │
   │Time      │       └──────────┘
   └──────────┘
```

### 3.2 关键转化链

**链路1：姿态切换循环（核心引擎）**
```
平静 → 退出获得2能量
  → Eruption(1费)进入暴怒 → 攻击伤害×2
  → Inner Peace(1费)进入平静 → 抽3牌
  → 退出获得2能量（净赚1能量）
  → Rushdown抽2牌 → 循环
```

**链路2：无限循环（终极引擎）**
```
小牌组(≤10张) + Rushdown(能力)
  → 进入平静 + 退出 → 抽2牌
  → 进入暴怒 + 退出 → 抽2牌
  → 净费用0 + 抽4牌 → 手牌永远满
  → 每次暴怒下攻击伤害×2 → 无限输出
```

**链路3：真言 → 神圣（终极爆发）**
```
Prostrate/Worship/Devotion → 累积真言
  → 达到10 → 进入神圣
  → 伤害×3 + 获得3能量
  → 一回合倾泻所有高伤害牌
  → Wreath of Flame + Ragnarok = 极高伤害
```

## 第四部分：策划设计意图还原

### 4.1 核心设计决策："姿态切换是可循环的能量引擎"

**证据**：
- 平静退出给2能量，进入暴怒最低1费——净赚1能量
- Rushdown让每次切换抽2牌
- Flurry of Blows让每次切换获得一张0费攻击
- Violet Lotus让退出平静额外+1能量

**还原的意图**：策划将"姿态切换"设计为一种**可重复、有净收益**的行为。这不是"切换一次然后保持"——策划鼓励你**频繁切换**。每次切换都产出能量、抽牌、Block，形成正反馈循环。

### 4.2 核心设计决策："暴怒是双刃剑"

**证据**：
- 暴怒让受到的伤害也×2
- Wiki明确警告"not every fight will present an immediate kill opportunity"
- Mental Fortress（切换时+3Block）是"在暴怒下生存"的关键卡

**还原的意图**：策划没有让暴怒成为"无脑开启"的增益。在暴怒下，敌人的一击可能直接致命。这迫使玩家学会**精确控制姿态切换的时机**——在安全的回合进入暴怒输出，在敌人攻击前切回平静或退出暴怒。这就是"姿态舞步"的"舞步"——**节奏感**。

### 4.3 核心设计决策："保留 = 等待是资源"

**证据**：
- Sands of Time保留后每回合费用-1
- Windmill Strike保留后每回合伤害+4
- Establishment让所有保留牌每回合费用-1
- 许多保留牌本身就是强力牌

**还原的意图**：传统卡牌游戏中，手牌里的牌是"待消耗"的资源。观者的保留机制反转了这一点——**手牌里的牌可以随着时间增值**。这创造了一种完全不同的决策框架：不是"我该打出这张牌吗？"而是"我该等多久再打出这张牌？"

### 4.4 核心设计决策："观者是最高爆发 + 最低HP"

**证据**：
- 观者HP 72（全角色最低）
- 暴怒×2伤害 + 神圣×3伤害 = 全角色最高爆发
- Blasphemy让伤害×3但回合结束死亡——极端的赌注设计
- 起始牌组Eruption + Vigilance已经教学了"爆发+防御"的节奏

**还原的意图**：策划用最低HP来平衡最高爆发——你不能犯错，但如果你不犯错，你可以比任何角色更快结束战斗。这是经典的"玻璃大炮"设计。

## 第五部分：策划设计方法论提炼

### 方法论1："行为循环"设计法

**操作步骤**：
1. 设计两种**互斥状态**（暴怒/平静），各有明确收益
2. 让切换本身**有净收益**（退平静给能量、进暴怒给伤害）
3. 围绕"切换行为"设计触发器（切换→抽牌/Block/伤害）
4. 确保切换成本足够低（1费或0费），使频繁切换成为可能

**为什么有效**：传统设计中，状态切换是"一次性选择"。观者的创新在于让切换本身成为**可循环的引擎行为**。每次切换都有收益，让玩家不断寻找切换的理由。

### 方法论2："双刃剑增益"设计

**操作步骤**：
1. 设计一种**同时对玩家和敌人都有效的增益**（暴怒：伤害×2包括受到的）
2. 确保增益在正确使用时极其强大（×2伤害是巨大的）
3. 确保增益在错误使用时极其危险（受到×2伤害可能致命）
4. 提供"在增益下生存"的专门工具（Mental Fortress、Halt）

**为什么有效**：纯正面增益（如铁甲战士的力量）只有"什么时候使用"的决策。双刃剑增益增加了"**是否值得冒险使用**"的决策——这让每个回合的决策空间翻倍。

### 方法论3："等待增值"设计

**操作步骤**：
1. 设计一类"保留在手牌中"的牌
2. 让保留时每回合获得增益（费用降低、伤害增加）
3. 确保保留不占用行动（不需要消耗能量来保留）
4. 保留的增益应有上限（费用最低到0）或与战斗时长相关

**为什么有效**：传统卡牌游戏中"手牌"是待消耗资源。保留机制让手牌变成**随时间增值的资产**。这创造了"现在用还是再等等"的持续张力。

### 方法论4："绝对赌注"设计

**操作步骤**：
1. 设计一种**最强增益**（Blasphemy：×3伤害）
2. 附加**最严厉代价**（回合结束死亡）
3. 代价不应是"可能发生"而是"必然发生"——除非你在代价触发前解决战斗
4. 确保没有100%安全的使用方式——总有风险

**为什么有效**：Blasphemy是杀戮尖塔中"赌注设计"的极端形式。不是"有代价的增益"（如Boss遗物），而是"赢了通吃、输了全输"的赌注。这创造了一种独特的情绪体验——**每次使用都是一次生死抉择**。

## 第六部分：可迁移设计工具

### 工具1：可循环状态设计检查

设计可切换的双状态系统时：
- [ ] 状态A和状态B是否各有明确收益？
- [ ] 切换本身是否有净收益（而非零和）？
- [ ] 是否有"切换时触发"的被动效果？
- [ ] 切换成本是否足够低以支持频繁切换？
- [ ] 是否存在"无限循环"的可能性？（如果有，是否可接受？）

### 工具2：双刃剑增益平衡检查

```
1. 增益效果：__________ × __________（倍率）
2. 对玩家的风险：__________ × __________（同样被放大）
3. 风险抵消工具：__________（是否存在专门的安全工具？）
4. 最优使用场景：__________（什么时候值得冒险？）
5. 最差使用场景：__________（什么时候绝对不该用？）
```

### 工具3：爆发型角色设计模板

```
1. 爆发能力：__________（×2? ×3?）
2. 生存能力：__________（低HP? 低防御?）
3. 爆发窗口：__________（需要几回合准备？）
4. 失败代价：__________（暴怒下被打? 赌注失败?）
5. 安全工具：__________（如何在高风险下生存？）
6. 起始教学：是否通过起始牌组教学爆发节奏？ □是 □否
```
