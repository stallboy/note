# 01 核心循环：三层嵌套的决策引擎

## 核心问题

杀戮尖塔的"一局游戏"由哪些循环嵌套构成？每一层循环为玩家提供了什么决策空间和情绪节奏？

---

## 一、三层循环架构

杀戮尖塔的核心循环并非单一循环，而是**三层嵌套结构**，每一层有自己的节奏、决策点和情感曲线：

```
宏观循环（一局 Run）    —— 攀塔：从第一幕到最终Boss
  └─ 中观循环（一幕 Act）  —— 探索：在地图上选择路径
       └─ 微观循环（一场战斗 Combat） —— 出牌：回合制卡牌博弈
```

这三层循环的精妙之处在于：**每层的决策都会影响其他层**。微观战斗中的损伤会延续到中观探索（HP是跨战斗持续的），中观的路径选择决定了微观会遇到什么敌人，宏观的构筑目标又反过来指导中观应该走哪些房间。

---

## 二、宏观循环：一局游戏的骨架

### 2.1 流程概览

```
Neow祝福 → 第一幕(17层) → 第二幕(17层) → 第三幕(17层) → [第四幕(隐藏Boss)]
```

每局开始时，玩家遇到 Neow（鲸鱼），获得一个起始加成。随后依次通过三个幕，每个幕有17层楼，最终在幕末挑战Boss。击杀Boss后**满血恢复**，进入下一幕。如果收集到三把钥匙，则可以进入隐藏的第四幕挑战最终Boss"腐烂心脏"。

### 2.2 关键设计决策

**Boss战后满血恢复**——这是一个看似简单但极其重要的设计。

它意味着玩家不需要"为未来保留血量"。面对Boss时，玩家可以完全投入，即使以1点HP获胜也是安全的。这消除了传统Roguelike中常见的"资源囤积焦虑"，让每场Boss战都成为一场可以全力以赴的对决。

> 数据来源：[Gameplay - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gameplay) — "Defeating a Boss will heal the player to full HP for the following Act. Bosses are NOT meant to be challenged while retaining your HP for future encounters."

**Neow的祝福**——每局开局的随机选项让每局游戏的起点就有差异。选项包括：

- 纯增益（普通遗物、金币、卡牌、药水、升级卡牌）
- Neow的哀歌（前3场战斗敌人只有1HP，对普通怪、精英、Boss均有效）
- 代价交换（牺牲金币/HP换取稀有遗物/稀有卡牌）
- 以起始遗物换取Boss遗物

这个设计让游戏的"第0分钟"就有策略决策，而非让玩家做重复的开局。

### 2.3 宏观循环中的资源与状态

| 资源 | 跨幕持续性 | 说明 |
|------|-----------|------|
| HP | 跨战斗持续，Boss战后恢复 | 核心生存资源 |
| 金币 | 全局持续 | 用于商店购买 |
| 牌组 | 全局持续，逐步膨胀 | 核心成长载体 |
| 遗物 | 全局持续 | 被动能力加成 |
| 药水 | 全局持续，携带上限3 | 一次性战略资源 |

注意"牌组"的特殊性：它既是资源也是负担。每一张添加的牌都稀释了抽到关键牌的概率。这是杀戮尖塔最核心的张力来源之一——**成长本身自带代价**。

## 三、中观循环：地图探索与路径决策

### 3.1 地图结构

每个幕的地图由17层组成，每层最多6个房间位置横向排列。玩家从底层选择一条路径向上攀爬。

> 数据来源：[Map Generation - Slay the Spire Wiki (wiki.gg)](https://slaythespire.wiki.gg/wiki/Map_Generation)

**固定楼层设计**（以第一幕为例）：

| 层数 | 固定内容 | 设计意图 |
|------|---------|---------|
| 第1层 | 普通战斗 | 立即进入战斗，无缓冲 |
| 第9层 | 宝箱房 | 中点奖励，获得一件遗物 |
| 第15层 | 火堆 | Boss前的休息/升级机会 |
| 第17层 | Boss | 幕末挑战 |

> 数据来源：[Act 1 - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Act_1)

### 3.2 七种房间类型

| 类型 | 图标 | 功能 | 风险/回报 |
|------|------|------|----------|
| 普通战斗 | 怪物图标 | 战斗后获得3选1卡牌 + 金币 + 可能获得药水 | 低风险，基础回报 |
| 精英战斗 | 精英图标 | 强敌，额外获得一件遗物 | 高风险，高回报 |
| 火堆 | 篝火图标 | 回复30%最大HP 或 升级一张卡牌 | 零风险，策略选择 |
| 宝箱房 | 宝箱图标 | 免费获得一件遗物 | 零风险，纯奖励 |
| 商店 | 商店图标 | 购买卡牌/遗物/药水，移除卡牌 | 消耗金币，高度可控 |
| 事件 | ？图标 | 随机事件，可能有益也可能有害 | 不确定性，高方差 |
| Boss | Boss图标 | 幕末强敌，奖励稀有卡和Boss遗物 | 最高风险，最高回报 |

> 数据来源：[Gameplay - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gameplay)

### 3.3 路径选择的策略性

地图上并非所有路径都可达——路径有分支和汇合。玩家在每个分叉处都面临一个权衡：

- **走精英路线**：高风险获得遗物，但可能损失大量HP甚至死亡
- **走火堆路线**：安全回复或升级，但错过遗物
- **走商店路线**：精确购买需要的卡牌/遗物，但消耗金币
- **走事件路线**：不确定性，可能获得强力奖励，也可能被诅咒

这种"风险-回报"的路径选择是中观循环的核心玩法。玩家的当前状态（HP、牌组强度、金币）会动态改变最优路径——同样的地图，不同的游戏进程会给出不同的最优解。

### 3.4 中观循环的节奏设计

每个幕的17层形成了一个自然的**三幕结构**：

```
第1-5层：起步期   —— 普通战斗为主，牌组初步成型
第6-12层：发展期  —— 开始遇到精英和事件，核心决策集中区
第13-15层：冲刺期 —— 火堆准备，最后的构筑机会
第16-17层：决战期 —— Boss战
```

固定楼层的设计确保了节奏的可预测性——玩家知道第9层一定有宝箱，第15层一定有火堆。这种**可预测的锚点**在随机性主导的游戏中提供了规划的基础。

## 四、微观循环：战斗回合

### 4.1 回合流程

```
玩家回合开始
  ├─ 抽5张牌
  ├─ 获得3点能量
  ├─ Block重置为0（除非有特殊效果）
  ├─ 玩家自由出牌（消耗能量）
  └─ 玩家结束回合
       ├─ 手牌弃入弃牌堆
       └─ 剩余能量清零
敌人回合
  ├─ 敌人按预设意图行动
  └─ 敌人展示下一回合意图
循环直到一方HP归零
```

> 数据来源：[Combat Mechanics - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Combat_Mechanics)

### 4.2 每回合的决策空间

一个典型的战斗回合中，玩家面临以下决策：

1. **读意图**：观察敌人下回合要做什么（攻击多少伤害？施加什么debuff？强化自己？）
2. **评估手牌**：当前抽到的5张牌 + 当前能量（3点），有哪些可行的出牌组合
3. **攻防权衡**：有限的能量和手牌，分配给进攻（打伤害）还是防守（堆格挡）
4. **资源管理**：是否使用药水？是否打出消耗型卡牌？

这个决策空间的精妙之处在于**信息不对称的优势**：玩家先行动，且可以看到敌人的下一步意图。这意味着玩家的每个决策都是在**已知信息**下做出的，而非盲猜。这是杀戮尖塔区别于许多卡牌游戏的关键设计——**降低了随机性带来的挫败感，提升了策略深度**。

### 4.3 战斗结果与奖励

战斗胜利后：

| 来源 | 奖励内容 |
|------|---------|
| 普通战斗 | 3选1卡牌 + 金币 + 可能获得药水 |
| 精英战斗 | 上述 + 额外1件遗物 |
| Boss战斗 | 金币(约90-110) + 药水 + 3选1稀有卡 + 3选1Boss遗物 |

> 数据来源：[Gameplay - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Gameplay)

**卡牌奖励的"可以跳过"设计**——每次奖励都可以选择不拿牌。这不是一个小细节，而是牌组构筑的基石：**不拿牌本身就是一个重要决策**。在大多数卡牌游戏中，拿牌是默认行为；在杀戮尖塔中，"不拿"往往是最优解。

## 五、三层循环的交叉影响

三层循环之所以能产生深度，是因为它们**不是独立的**，而是通过资源系统紧密耦合：

```
微观结果（战斗中损失HP）────→ 中观策略（需要走火堆而非精英路线）
中观决策（跳过商店不买牌）────→ 微观压力（牌组不够强，战斗更困难）
中观决策（打精英获得遗物）────→ 微观强度（遗物提供被动加成）
宏观目标（我想要什么流派）────→ 中观路径（需要走事件/商店找关键牌）
微观战斗（遇到特定敌人）─────→ 宏观策略（需要补充AOE/单体/防御）
```

这种交叉影响创造了一个**高度涌现**的系统：玩家的每个小决策都有可能改变后续大决策的最优解。这就是杀戮尖塔"每局都不一样"的根本原因——不是简单的随机性，而是**随机性通过决策网络的级联效应**。

## 六、反事实推演

### 如果移除"敌人意图显示"？

战斗变成盲猜——玩家不知道敌人下回合是攻击还是强化。这会：
- 大幅增加战斗的随机性和挫败感
- 防御（Block）的价值大幅下降，因为你不知道是否需要防
- 游戏从"策略规划"退化为"概率赌博"
- 精英战斗和Boss战变得极其令人沮丧

结论：**意图显示是杀戮尖塔最重要的设计之一**，它将战斗从"运气游戏"提升为"策略游戏"。

### 如果Boss战后不恢复满血？

- 玩家会在Boss战中极度保守，试图以最高HP通关
- Boss战的体验从"全力以赴的史诗对决"变成"如履薄冰的资源管理"
- 幕间的难度曲线设计将变得极其困难——设计者无法预测玩家进入新幕时的HP
- 整体情绪从"征服感"变为"焦虑感"

### 如果不能跳过卡牌奖励？

- 牌组不可避免地膨胀，抽到关键牌的概率持续下降
- "精简牌组"这一核心策略将不复存在
- 游戏的长期可玩性大幅下降——没有了"少即是多"的策略空间

## 七、可迁移经验

### 1. 嵌套循环设计法
将游戏拆解为宏观/中观/微观三层循环，确保每层都有独立的决策空间和情绪曲线。**层与层之间通过共享资源耦合**，使小决策产生大影响。

### 2. "可跳过奖励"原则
任何奖励都应该允许玩家拒绝。当"不拿"本身成为一个有意义的决策时，游戏的策略深度自然提升。这适用于卡牌、装备、技能树等各种成长系统。

### 3. 信息对称性设计
让玩家在做决策前获得足够的敌方信息（如意图显示），将"运气成分"转化为"风险管理"。玩家应该因为**判断失误**而失败，而非因为**信息不足**而失败。

### 4. 固定锚点 + 随机填充
在随机生成的地图/关卡中，设置固定的锚点（如"第9层一定是奖励"、"Boss前一定是休息点"）。这给了玩家规划的基础，同时保留了随机性带来的新鲜感。

### 5. 成长自带代价
让获取新资源的动作本身带有代价（如牌组膨胀降低抽牌概率），创造"要还是不要"的天然张力。这比简单的"越多越好"有更深的策略空间。
