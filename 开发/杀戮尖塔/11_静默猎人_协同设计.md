# 11 静默猎人：协同设计与策划方法论

## 第一部分：协同效应清单

### 1.1 乘法放大型

| 协同组合 | 乘法机制 | 强度 |
|---------|---------|------|
| 毒素 + Catalyst | 毒素层数翻倍(升级×3) | 极高 |
| 毒素 + Envenom | 每次攻击未格挡伤害附加1毒素 | 高 |
| 毒素 + Corpse Explosion | 敌人死亡时按最大HP对全体造成伤害 | 极高（对群体） |
| 毒素 + Noxious Fumes | 每回合自动+2毒素，与手动施毒叠加 | 高 |
| 毒素 + Snecko Skull (遗物) | 每次施毒额外+1毒素 | 高 |
| 暗器数 + Accuracy | 每个暗器+4伤害 | 高 |
| 暗器数 + A Thousand Cuts | 每出一张牌全体1伤害，暗器0费=大量触发 | 极高 |

**策划意图**：毒素是静默猎人的"指数增长"引擎。策划在系统中放置了Catalyst（翻倍）和Noxious Fumes（自动增长）两个乘法点，让毒素层数以远超线性速度增长。

### 1.2 引擎循环型

| 协同组合 | 循环机制 |
|---------|---------|
| Concentrate + 弃牌流 | 弃3牌→+2能量→更多牌可以打出 |
| Tactician + 弃牌 | 弃掉时获得1能量 |
| Reflex + 弃牌 | 弃掉时抽2牌 |
| Storm of Steel + 大手牌 | 弃掉全部手牌→每张生成1暗器→暗器0费可打 |
| Calculated Gamble + Reflex/Tactician | 弃全部手牌→触发Reflex/Tactician→重新抽牌 |
| Tools of the Trade + 弃牌 | 每回合抽1弃1→持续触发弃牌效果 |

**策划意图**：弃牌（Discard）被设计为静默猎人的可循环资源。Tactician（弃牌=能量）和Reflex（弃牌=抽牌）是引擎的"油和火花塞"，策划围绕弃牌构建了整套能量-抽牌循环。

### 1.3 条件解锁型

| 协同组合 | 条件机制 |
|---------|---------|
| Bane + 毒素 | 敌人有毒素时Bane伤害翻倍(7→14) |
| Heel Hook + 虚弱 | 敌人有虚弱时回费+抽牌 |
| Sneaky Strike + 弃牌 | 本回合弃过牌时获得2能量 |
| Eviscerate + 弃牌 | 每弃1牌费用-1，最高3次 |
| Grand Finale | 牌堆为空时才能打出，50全体伤害 |
| Finisher + 多攻击 | 本回合每打出1张攻击牌+6伤害 |

**策划意图**：条件解锁迫使玩家创造前提。毒素是Bane的前提、虚弱是Heel Hook的前提、弃牌是Sneaky Strike的前提。这让"先铺垫再爆发"成为静默猎人的核心节奏。

### 1.4 资源转化型

| 协同组合 | 转化路径 |
|---------|---------|
| Concentrate | 弃3牌 → +2能量 |
| Tactician | 弃牌 → +1能量（不可打出，只能弃触发） |
| Survivor | 弃1牌 → 8Block |
| Flying Knee | 攻击 → 下回合+1能量 |
| Outmaneuver | 1费 → 下回合+2能量 |
| Adrenaline | 0费 → +1能量 + 抽2牌 |
| Corpse Explosion | 6毒素+击杀 → 全体按最大HP伤害 |

**策划意图**：静默猎人的核心转化是**弃牌 → 能量/抽牌**。与铁甲战士的HP→能量不同，静默猎人的"货币"是手牌——你"花掉"手牌（弃牌）来获得能量和更多手牌。

### 1.5 缺陷互补型

| 协同组合 | 缺陷 → 互补 |
|---------|------------|
| Wraith Form (-1敏捷/回合) + After Image | 每出一张牌获得1Block，不依赖敏捷 |
| Wraith Form + Intangible | 减伤到1+无敌防御→基本不需要Block |
| Masterful Stab (被攻击后费+1) + 虚弱/Block | 减少受伤保持0费 |
| Grand Finale (牌堆需为空) + Setup/Well-Laid Plans | 将牌放回牌堆顶控制牌堆大小 |

### 1.6 被动触发型

| 遗物/能力 + 行为 | 触发效果 |
|-----------------|---------|
| Snecko Skull + 施毒 | 每次施毒额外+1毒素 |
| Paper Krane + 虚弱敌人 | 虚弱减伤从25%提升到40% |
| The Specimen + 敌人死亡 | 将毒素转移到其他敌人 |
| Tingsha + 弃牌 | 每弃1牌随机敌人3伤害 |
| Tough Bandages + 弃牌 | 每弃1牌获得3Block |
| Ninja Scroll + 开局 | 起手3张暗器 |
| After Image + 出牌 | 每出一张牌获得1Block |
| Envenom + 攻击 | 攻击未格挡→附加1毒素 |

## 第二部分：卡池关键词聚类

### 2.1 毒素（Poison）群

| 卡牌 | 类型 | 稀有度 | 与毒素的关系 |
|------|------|--------|-------------|
| Neutralize | 攻击 | 起始 | 1虚弱（毒素教学的起点） |
| Deadly Poison | 技能 | 普通 | +5毒素（直接施毒） |
| Poisoned Stab | 攻击 | 普通 | 6伤害+3毒素 |
| Bane | 攻击 | 普通 | 敌人有毒素时伤害翻倍 |
| Noxious Fumes | 能力 | 非凡 | 每回合+2毒素 |
| Bouncing Flask | 技能 | 非凡 | 3毒素随机3次 |
| Crippling Cloud | 技能 | 非凡 | 4毒素+2虚弱 |
| Catalyst | 技能 | 非凡 | 毒素翻倍/×3 |
| Envenom | 能力 | 稀有 | 攻击附加1毒素 |
| Corpse Explosion | 技能 | 稀有 | 6毒素+死亡时全体伤害 |

**聚类结论**：毒素群包含**10张卡牌**，是静默猎人最大的协同群。从Deadly Poison（普通，直接施毒）到Catalyst（非凡，翻倍）再到Corpse Explosion（稀有，群体连锁），形成了完整的"施毒→放大→收割"链路。

**稀有度分层**：
- 普通层：Deadly Poison、Poisoned Stab → 基础施毒手段
- 非凡层：Noxious Fumes（自动施毒）、Catalyst（毒素翻倍）→ 核心放大器
- 稀有层：Envenom（攻击施毒）、Corpse Explosion（毒素连锁）→ 终极形态

### 2.2 弃牌（Discard）群

| 卡牌 | 类型 | 弃牌角色 |
|------|------|---------|
| Survivor | 技能(起始) | 主动弃1牌 |
| Prepared | 技能 | 抽1弃1 |
| Acrobatics | 技能 | 抽3弃1 |
| Dagger Throw | 攻击 | 抽1弃1 |
| All-Out Attack | 攻击 | 随机弃1 |
| Concentrate | 技能 | 弃3→+2能量 |
| Calculated Gamble | 技能 | 弃全部→重抽 |
| Tools of the Trade | 能力 | 每回合抽1弃1 |
| Unload | 攻击 | 弃全部非攻击 |
| Storm of Steel | 技能 | 弃全部→生成暗器 |

**弃牌触发器**：

| 卡牌 | 弃牌时触发 |
|------|----------|
| Tactician | +1能量（不可打出） |
| Reflex | 抽2牌（不可打出） |
| Sneaky Strike | 本回合弃过牌→+2能量 |
| Eviscerate | 本回合弃过N牌→费用-N |

**聚类结论**：弃牌群包含**10张主动弃牌牌 + 4张触发器**，规模仅次于毒素群。Tactician和Reflex两张"不可打出"牌是弃牌引擎的核心——它们**只能通过弃牌触发**，这迫使玩家围绕弃牌机制构建策略。

### 2.3 暗器（Shiv）群

| 卡牌 | 类型 | 与暗器的关系 |
|------|------|-------------|
| Blade Dance | 技能 | 生成3暗器 |
| Cloak And Dagger | 技能 | 6Block + 1暗器 |
| Infinite Blades | 能力 | 每回合生成1暗器 |
| Accuracy | 能力 | 暗器+4伤害 |
| Storm of Steel | 技能 | 弃手牌→每张1暗器 |
| Ninja Scroll (遗物) | — | 起手3暗器 |

**聚类结论**：暗器群只有5张卡牌+1遗物，比毒素群和弃牌群小得多。但每张暗器0费且消耗，意味着它是一个**高频出牌**引擎。这自然地与以下系统协同：
- A Thousand Cuts（每出1牌全体1伤害）→ 暗器每张触发一次
- After Image（每出1牌+1Block）→ 暗器每张触发一次
- Kunai/Shuriken/Ornamental Fan（3次攻击触发）→ 暗器快速堆叠触发

### 2.4 Block/敏捷群

| 卡牌 | Block来源 | 特殊 |
|------|----------|------|
| Survivor | 8Block + 弃1牌 | 起始 |
| Backflip | 5Block + 抽2牌 | |
| Deflect | 4Block 0费 | |
| Dodge and Roll | 4Block + 下回合4Block | |
| Leg Sweep | 11Block + 2虚弱 | |
| Blur | 5Block + Block不清零(1回合) | |
| Footwork | +2敏捷(永久) | 能力 |
| After Image | 每出1牌+1Block | 稀有能力 |

**聚类结论**：Block群比铁甲战士少，且缺少"Block翻倍"和"Block转伤害"的极端手段。这说明策划**有意让静默猎人不擅长"无限防御"**——她的防御依赖高频出牌（After Image）和敏捷（Footwork），而非堆叠。

## 第三部分：资源流追踪

### 3.1 静默猎人的完整资源流图

```
                  ┌──────────┐
                  │  手牌    │ ← 核心可消耗资源
                  └────┬─────┘
                       ↓ (弃牌机制)
              ┌────────┼────────┐
              ↓        ↓        ↓
         ┌────────┐ ┌──────┐ ┌─────────┐
         │ 能量   │ │ 抽牌 │ │ 暗器    │ ← 弃牌产出
         │(Tactician)│(Reflex)│(Storm)  │
         └────┬───┘ └──┬───┘ └────┬────┘
              ↓        ↓          ↓
         ┌────────┐ ┌──────┐ ┌─────────┐
         │高费牌  │ │更多  │ │高频出牌  │ ← 产出消耗
         │Catalyst│ │手牌  │ │触发遗物  │
         └────────┘ └──────┘ └─────────┘

    独立资源流：
         ┌──────────┐
         │  毒素    │ ← 不依赖弃牌，独立增长
         └────┬─────┘
              ↓ (Noxious Fumes/Catalyst)
         ┌──────────┐
         │ 指数增长 │
         └──────────┘
```

### 3.2 关键转化链

**链路1：弃牌 → 能量 → 高费牌（弃牌引擎）**
```
Survivor/Prepared/Acrobatics → 弃牌
  → Tactician触发 → +1能量
  → 能量用于打Catalyst(毒素翻倍)或Burst(技能双倍)
  → Calculated Gamble重置手牌 → 再次触发
```

**链路2：毒素 → 放大 → 收割（毒素链）**
```
Deadly Poison/Noxious Fumes → 堆叠毒素
  → Catalyst → 毒素翻倍/×3
  → Corpse Explosion → 击杀一个敌人 → 全体按最大HP伤害
  → 或 Bane → 敌人有毒素时双倍伤害
```

**链路3：暗器 → 高频出牌 → 被动触发（暗器链）**
```
Blade Dance/Infinite Blades → 生成暗器
  → 暗器0费 → 一回合打出大量牌
  → A Thousand Cuts → 每张牌全体1伤害
  → After Image → 每张牌+1Block
  → Kunai/Shuriken → 每3次攻击触发
```

## 第四部分：策划设计意图还原

### 4.1 核心设计决策："毒素是被动伤害引擎"

**证据**：
- 毒素群10张卡牌，是最大的协同群
- 毒素不需要每回合打攻击牌——它自动造成伤害
- Noxious Fumes让毒素每回合自动+2，完全被动
- Envenom让攻击也附加毒素，将主动伤害转化为被动积累

**还原的意图**：铁甲战士需要每回合打攻击牌来输出伤害，静默猎人不需要。策划有意将静默猎人的核心输出设计为**被动性的**——你施毒一次，之后每回合自动受伤。这让静默猎人可以腾出回合去做防御、抽牌、布局，形成与铁甲战士截然不同的节奏。

### 4.2 核心设计决策："弃牌是隐藏的能量系统"

**证据**：
- Tactician和Reflex是**不可打出**的牌——只能通过弃牌触发
- 弃牌相关卡牌有14张（主动弃牌10张 + 触发器4张）
- Concentrate将弃牌直接转化为能量
- Storm of Steel将弃牌转化为暗器

**还原的意图**：策划不想让静默猎人像铁甲战士一样直接"花HP换能量"。取而代之的是一个更间接的系统：**弃掉手牌 = 获得能量/抽牌**。这个设计更微妙——你"花掉"的不是HP，而是**信息**（手牌是你能看到的，弃掉它们意味着放弃已知的选项换取未知的可能性）。

### 4.3 核心设计决策："暗器是高频触发器，不是主输出"

**证据**：
- 单个暗器只造成4伤害（升级6），非常弱
- 但Accuracy让每个暗器+4，使伤害变为8/10
- 暗器0费且消耗，意味着可以大量打出
- A Thousand Cuts和After Image按"出牌次数"而非"伤害值"触发

**还原的意图**：暗器的设计目的**不是直接伤害**，而是**高频出牌次数**。策划用0费+消耗的标签确保暗器是"用了就没了，但用得很快"。这使得暗器成为触发"每出1张牌"类效果的最佳载体。

### 4.4 核心设计决策："Wraith Form是终极赌注"

**证据**：
- Wraith Form给予2层Intangible（所有伤害减为1）但每回合-1敏捷
- 代价是持续的（每回合-1敏捷），不是一次性的
- 没有任何牌能恢复敏捷（除了少数通用牌）

**还原的意图**：策划设计了一个"倒计时型"终极能力——Wraith Form给你几近无敌的防御，但你的防御能力（敏捷）每回合都在下降。这创造了一种紧迫感：你必须在敏捷归零之前获胜。

## 第五部分：策划设计方法论提炼

### 方法论1："被动输出 + 主动防御"节奏分离

**操作步骤**：
1. 设计一种**不需要主动操作就能造成伤害**的机制（毒素）
2. 让玩家施放一次后，伤害自动持续
3. 腾出的回合用于**防御、抽牌、布局**
4. 确保被动输出需要时间积累——不能太快击杀（否则主动输出更优）

**与铁甲战士的对比**：铁甲战士是"主动输出 + 被动防御"（Metallicize每回合自动加Block，需要主动打攻击），静默猎人是"被动输出 + 主动防御"（毒素自动伤害，需要主动堆Block）。两者形成完美镜像。

### 方法论2："不可打出"牌设计法

**操作步骤**：
1. 设计一种牌，它**不能正常打出**（无费用、无效果）
2. 给它一个**被弃牌时触发**的效果（获得能量/抽牌）
3. 在卡池中放置大量**弃牌手段**
4. 玩家必须围绕弃牌机制构建策略才能利用这些牌

**为什么有效**：不可打出牌是一种"隐藏资源"——它们占据了牌组空间（负面），但通过特定机制触发时提供巨大收益（正面）。这创造了"有毒资产"的变体：牌组中的"废牌"在正确搭配下变成引擎。

### 方法论3："高频出牌"作为独立维度

**操作步骤**：
1. 设计一种0费、消耗的牌（暗器），单体效果弱
2. 设计"每出1张牌触发X"的能力牌（A Thousand Cuts、After Image）
3. 设计"打出N张攻击触发"的遗物（Kunai、Shuriken）
4. 弱牌 + 高频触发 = 强效果，但需要收集足够多的触发器

**为什么有效**：传统卡牌游戏的策略集中在"打出哪张牌"。静默猎人的暗器流增加了"打出多少张牌"这个维度，让牌的数量本身成为策略变量。

### 方法论4："指数增长"毒素模型

**操作步骤**：
1. 设计一个**线性增长**的属性（毒素每回合-1，但可以叠加）
2. 放置一个**翻倍点**（Catalyst：毒素×2/×3）
3. 放置一个**自动增长器**（Noxious Fumes：每回合+2）
4. 让增长和翻倍在不同牌上——需要构筑

**数学验证**：
- 回合1：施毒5层
- 回合2：Noxious Fumes +2 → 总7层，敌人受伤7→剩余6
- 回合3：Catalyst → 6×2=12层
- 回合4：敌人受伤12→剩余11
- 回合5：Catalyst → 10×2=20层

毒素在Catalyst介入后呈现指数增长，而Catalyst是非凡稀有度——不是每局都能获得，但获得时会让毒素流产生质变。

## 第六部分：可迁移设计工具

### 工具1：节奏分离检查

设计角色/职业时，检查：
- 这个角色的输出是主动的还是被动的？
- 这个角色的防御是主动的还是被动的？
- 输出和防御的节奏是否**不同**？（如果都是主动或都是被动，体验会单调）

### 工具2：不可打出牌检查

如果想在卡牌游戏中引入"弃牌引擎"：
- [ ] 是否有足够的弃牌手段让触发器可靠触发？
- [ ] 不可打出牌是否占据了牌组空间（有代价）？
- [ ] 触发效果是否足够强以补偿代价？
- [ ] 是否有"弃全部手牌并重抽"的安全阀？

### 工具3：高频触发设计模板

```
1. 设计0费消耗型弱牌：伤害___，生成___张
2. 设计"每出1牌触发"能力：触发效果___
3. 设计"打出N次攻击触发"遗物：触发效果___，阈值N=___
4. 设计弱牌强化能力：弱牌+___伤害/效果
5. 确保步骤2-4分布在不同稀有度
```
