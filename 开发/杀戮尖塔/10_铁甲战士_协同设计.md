# 10 铁甲战士：协同设计与策划方法论

## 第一部分：协同效应清单

### 1.1 乘法放大型

| 协同组合 | 乘法机制 | 强度 |
|---------|---------|------|
| 力量 + Heavy Blade | 力量对此卡×3(升级×5)倍效果 | 极高 |
| 力量 + Twin Strike / Sword Boomerang / Pummel | 每段攻击独立享受力量加成 | 高 |
| 力量 + Whirlwind (X费) | 能量越多段数越多，每段享受力量 | 高 |
| 力量 + Reaper | 伤害高→回血多，攻击即治疗 | 极高 |
| 易伤 + 任意高伤害攻击 | 受到伤害+50%，配合高费攻击收益最大 | 高 |
| Limit Break | 力量翻倍，与任何力量来源协同 | 极高（罕见） |

**策划意图**：力量不是简单的+1伤害——策划有意识地设计了多张"多段攻击"牌和"力量放大"牌，让力量的价值**非线性增长**。这是"乘法点"思维的典型体现。

### 1.2 引擎循环型

| 协同组合 | 循环机制 |
|---------|---------|
| Corruption + Dark Embrace | 技能免费→消耗→抽牌→更多手牌→继续消耗 |
| Corruption + Feel No Pain | 技能免费→消耗→获得Block→持续防御 |
| Corruption + Dead Branch (遗物) | 技能免费→消耗→随机获得新牌→可能是技能→继续免费打出 |
| Evolve + 状态牌生成牌 | 状态牌堵塞牌组→Evolve将堵塞转化为额外抽牌 |
| Fiend Fire + Dark Embrace | 消耗手牌→每张触发Dark Embrace抽牌 |

**策划意图**：消耗（Exhaust）被设计为铁甲战士的"可循环资源"。策划围绕"消耗"构建了一整套产出→触发→收益的引擎。

### 1.3 条件解锁型

| 协同组合 | 条件机制 |
|---------|---------|
| Bash/Thunderclap (易伤) + Dropkick | 敌人易伤时Dropkick回费+抽牌 |
| Spot Weakness + 敌人攻击意图 | 敌人意图攻击时才获得力量 |
| Perfected Strike + 多张含"Strike"卡牌 | 每张Strike牌+2(升级+3)额外伤害 |
| Body Slam + 高Block | 伤害等于当前Block值 |
| Entrench + 高Block | Block翻倍 |

**策划意图**：条件解锁让卡牌的"纸面效率"不可靠——必须创造条件才能发挥。这迫使玩家构建"条件创造器"（如Bash制造易伤、防御牌堆Block），而不是单纯堆数值。

### 1.4 资源转化型

| 协同组合 | 转化路径 |
|---------|---------|
| Bloodletting | -3HP → +2能量 |
| Offering | -6HP → +2能量 + 抽3牌 |
| Hemokinesis | -2HP → 15伤害 |
| Rupture + 自伤牌 | 自伤 → +1力量 |
| Combust | -1HP/回合 → 全体5伤害 |
| Sentinel + 消耗 | 1费防御牌 → 消耗时获得2能量 |
| Second Wind | 消耗手牌非攻击牌 → 每张+5Block |

**策划意图**：HP是铁甲战士的"第二货币"。策划有意识地设计了一条 **HP → 能量/力量/抽牌** 的转化链，使铁甲战士可以"用血换一切"。这是整个角色身份的设计根基。

### 1.5 缺陷互补型

| 协同组合 | 缺陷 → 互补 |
|---------|------------|
| Wild Strike (强但注入伤口) + Evolve | 伤口不再是负担而是额外抽牌的触发器 |
| Immolate (强AOE但注入灼伤) + Feel No Pain | 灼伤消耗时获得Block |
| Power Through (注入2伤口获得15Block) + Evolve + Fire Breathing | 伤口→抽牌 + 全体伤害 |
| Mark of Pain (Boss遗物，+1能量但每战注入2伤口) + Evolve | 伤口变成引擎燃料 |
| Bash (2费) + 任何高伤害牌 | Bash自身效率低但放大后续伤害 |

**策划意图**：策划设计了多张"强力但有副作用"的卡牌（伤口、灼伤、自伤），然后提供了多张将副作用转化为收益的牌。这是一种**"有毒资产"设计模式**——有代价的东西在被正确搭配后变成优势。

### 1.6 被动触发型

| 遗物 + 行为模式 | 触发条件 |
|----------------|---------|
| Kunai/Shuriken/Ornamental Fan + 多段攻击 | 每回合3次攻击触发 |
| Charon's Ashes + 消耗牌 | 每消耗一张牌对全体敌人3伤害 |
| Red Skull + 低HP | HP≤50%时+3力量（与自伤流协同） |
| Paper Phrog + 易伤 | 易伤敌人受伤+75%而非50% |
| Self-Forming Clay + 自伤 | 每次战斗中失去HP获得下回合3Block |
| Brimstone + 高力量 | 每回合+2力量但敌人+1力量（适合快速击杀流） |

## 第二部分：卡池关键词聚类

### 2.1 力量（Strength）群

| 卡牌 | 类型 | 稀有度 | 与力量的关系 |
|------|------|--------|-------------|
| Bash | 攻击 | 起始 | 2易伤→间接放大力量收益 |
| Flex | 技能 | 普通 | +2力量1回合 |
| Heavy Blade | 攻击 | 普通 | 力量×3倍效果 |
| Inflame | 能力 | 非凡 | +2力量永久 |
| Spot Weakness | 技能 | 非凡 | 条件+3力量 |
| Demon Form | 能力 | 稀有 | 每回合+2力量 |
| Limit Break | 技能 | 稀有 | 力量翻倍 |
| Rupture | 能力 | 非凡 | 自伤时+1力量 |

**聚类结论**：力量群包含**8张卡牌**，横跨普通到稀有全部稀有度。这说明策划将力量设计为铁甲战士的**第一核心主题**。从Flex（普通，临时力量）到Demon Form（稀有，永久递增力量）再到Limit Break（稀有，力量翻倍），形成了一条从入门到精通的渐进路径。

**稀有度分层**：
- 普通层：Flex、Heavy Blade → 教学力量概念
- 非凡层：Inflame、Spot Weakness、Rupture → 稳定力量来源
- 稀有层：Demon Form、Limit Break → 力量爆发/翻倍

策划确保了：即使一局不出稀有牌，仅靠普通+非凡也能构建力量流。

### 2.2 消耗（Exhaust）群

| 卡牌 | 类型 | 稀有度 | 与消耗的关系 |
|------|------|--------|-------------|
| True Grit | 技能 | 普通 | 获Block + 消耗随机手牌 |
| Warcry | 技能 | 普通 | 抽牌 + 消耗自身 |
| Havoc | 技能 | 普通 | 打出牌堆顶牌并消耗 |
| Burning Pact | 技能 | 非凡 | 消耗1牌 + 抽2牌 |
| Second Wind | 技能 | 非凡 | 消耗全部非攻击 + 每张+5Block |
| Sever Soul | 攻击 | 非凡 | 消耗全部非攻击 + 16伤害 |
| Fiend Fire | 攻击 | 稀有 | 消耗全部手牌 + 每张7伤害 |
| Offering | 技能 | 稀有 | -6HP + 获2能量 + 抽3牌 + 消耗自身 |

**消耗触发器**（受消耗时获得收益）：

| 卡牌/遗物 | 触发效果 |
|----------|---------|
| Dark Embrace | 消耗1牌 → 抽1牌 |
| Feel No Pain | 消耗1牌 → +3Block |
| Charon's Ashes (遗物) | 消耗1牌 → 全体3伤害 |
| Sentinel | 被消耗时 → 获得2能量 |

**聚类结论**：消耗群更庞大——**直接消耗牌8张 + 触发器4个**，是铁甲战士最大、最完整的协同群。策划的设计逻辑清晰：
1. 提供大量消耗手段（消耗什么）
2. 提供消耗触发器（消耗后得到什么）
3. Corruption将两者统合（所有技能免费 + 打出即消耗）

### 2.3 自伤/HP操控群

| 卡牌 | 代价 | 收益 |
|------|------|------|
| Bloodletting | -3HP | +2能量 |
| Offering | -6HP | +2能量 + 抽3牌 |
| Hemokinesis | -2HP | 15伤害 |
| Combust | -1HP/回合 | 全体5伤害/回合 |
| Brutality | -1HP/回合 | 抽1牌/回合 |
| Rupture | 触发器 | 自伤时+1力量 |
| Blood for Blood | 被动降低 | 4费→每损失HP-1费，18伤害 |
| Reaper | — | 造成伤害=回血（反向协同） |

**聚类结论**：HP操控群有8张卡。与力量群不同的是，这个群的核心卡（Rupture）是非凡稀有度——策划不期望新手一上来就玩自伤流，它是一个需要理解基础后才能掌握的**进阶主题**。

### 2.4 防御/Block群

| 卡牌 | Block来源 | 特殊机制 |
|------|----------|---------|
| Shrug it Off | 直接8Block | 抽1牌 |
| True Grit | 直接7Block | 消耗1牌 |
| Flame Barrier | 直接12Block | 被攻击时反伤 |
| Entrench | Block翻倍 | 与高Block协同 |
| Body Slam | 伤害=Block | 与高Block协同 |
| Barricade | Block不清零 | 与持续堆Block协同 |
| Impervious | 直接30Block | 消耗自身 |
| Metallicize | 每回合+3Block | 能力牌 |
| Power Through | 15Block + 2伤口 | 状态牌协同 |

**聚类结论**：防御群有9张卡，但更值得注意的是其中的**自我协同**——Entrench让Block翻倍、Body Slam将Block转化为伤害、Barricade让Block不清零。这三张牌单独使用效果有限，但组合后形成了"无限防御+伤害"的循环。

## 第三部分：资源流追踪

### 3.1 铁甲战士的完整资源流图

```
                    ┌──────────┐
                    │    HP    │ ← 核心可消耗资源
                    └────┬─────┘
                         ↓ (Bloodletting/Offering/Hemokinesis)
                    ┌──────────┐
                    │ 能量/抽牌 │ ← 中间资源
                    └────┬─────┘
                         ↓ (打出卡牌)
              ┌──────────┼──────────┐
              ↓          ↓          ↓
         ┌────────┐ ┌────────┐ ┌─────────┐
         │ 力量   │ │ Block  │ │ 消耗    │ ← 三条产出路径
         └───┬────┘ └───┬────┘ └────┬────┘
             ↓          ↓          ↓
    ┌────────────┐ ┌─────────┐ ┌────────────┐
    │ 多段攻击   │ │ Entrench│ │ 触发器     │ ← 放大器
    │ Heavy Blade│ │ Body    │ │ Dark Embrace│
    │ Limit Break│ │ Slam    │ │ Feel No Pain│
    └────────────┘ │Barricade│ └────────────┘
                   └─────────┘
```

### 3.2 关键转化链

**链路1：HP → 力量 → 伤害（受虐流）**
```
Rupture(能力) + Combust/Brutality/Offering
  = 自伤触发Rupture → 力量持续增长
  → 搭配Twin Strike/Sword Boomerang等高段数攻击
  → 力量×段数 = 爆发性伤害
```

**链路2：消耗 → 抽牌/Block/伤害（消耗引擎）**
```
Corruption(能力) + Dark Embrace/Feel No Pain
  = 技能免费打出 → 消耗 → 触发抽牌+Block
  → 手牌源源不断 → 继续消耗 → 循环
  → 搭配Fiend Fire可以一次性倾泻
```

**链路3：Block → 伤害 → 回血（防御循环）**
```
Shrug it Off等Block牌 → 堆高Block
  → Entrench翻倍 → Body Slam转化为伤害
  → 或搭配Reaper在高力量下回血
  → 搭配Barricade让Block不清零，下回合继续积累
```

**链路4：状态牌 → 额外资源（状态引擎）**
```
Wild Strike/Power Through/Immolate → 注入状态牌
  → Evolve让状态牌 = 额外抽牌
  → Fire Breathing让状态牌 = 全体伤害
  → Feel No Pain让状态牌消耗时 = Block
```

## 第四部分：策划设计意图还原

### 4.1 核心设计决策1："HP是可消耗货币"

**证据**：
- 铁甲战士起始HP 80（全角色最高）
- 起始遗物Burning Blood每战回6HP
- 卡池中有8张涉及HP消耗/操控的牌
- 血药水(Blood Potion)回复20%最大HP，是铁甲战士专属

**还原的意图**：策划在铁甲战士的设计初期就确定了一个核心决策——**这个角色的HP不是"要保护的东西"，而是"可以花的东西"**。最高HP + 回复遗物 + 自伤卡牌群，三者共同建立了这个身份。没有回复遗物的铁甲战士不会玩自伤流，因为代价太高。

### 4.2 核心设计决策2："消耗创造战略深度"

**证据**：
- 铁甲战士有全角色最多的消耗相关卡牌（12+张直接涉及消耗）
- Corruption是铁甲战士最具标志性的稀有能力
- 消耗触发器（Dark Embrace/Feel No Pain/Charon's Ashes）都是铁甲战士专属或高度相关

**还原的意图**：策划意识到，在卡牌游戏中"牌组膨胀"是不可避免的问题。消耗机制不仅解决了这个问题，还将其**转化为一种战略资源**——你不是"被迫精简牌组"，而是"主动消耗牌组来获得收益"。

### 4.3 核心设计决策3："力量是渐进式乘法"

**证据**：
- 力量是+1的加法，但Heavy Blade让力量×3，Limit Break让力量翻倍
- 多段攻击牌（Twin Strike、Sword Boomerang、Pummel）让每点力量多次生效
- Demon Form提供每回合+2力量的持续增长

**还原的意图**：策划不想让力量只是"攻击+1"的线性加成。通过在系统中放置多个**乘法点**（Heavy Blade的×3、Limit Break的×2、多段攻击的次数乘法），策划让力量的增长是非线性的——从+1变成+3、+6、+12...这种非线性增长让玩家在构建力量流时追求的不是单张强力卡牌，而是**乘法点的叠加**。

### 4.4 核心设计决策4："有毒资产"设计

**证据**：
- 多张强力卡牌带有状态牌注入（Wild Strike、Immolate、Power Through）
- 专门设计了一套"状态牌 = 资源"的转化链（Evolve、Fire Breathing、Feel No Pain）
- Boss遗物Mark of Pain以注入伤口为代价换取+1能量

**还原的意图**：策划设计了一种"有毒资产"模式——看似有害的东西（状态牌堵塞牌组）在正确搭配下变成优势。这创造了**双重策略空间**：
- 不搭配转化牌时，这些牌是"有代价的强牌"——你可以承受代价换取即战力
- 搭配转化牌后，这些牌变成"无代价的更强牌"——代价被转化成了收益

## 第五部分：策划设计方法论提炼

### 方法论1："核心资源 + 转化链"设计法

**操作步骤**：
1. 确定角色的**核心资源**（铁甲 = HP + 力量）
2. 设计**转化路径**（HP → 能量/力量/抽牌）
3. 为每条路径设计**入口卡**（消耗HP的牌）和**出口卡**（将转化结果放大的牌）
4. 确保入口卡在普通/非凡稀有度（易获取），出口卡在非凡/稀有（需要构筑）

**验证**：铁甲战士的每条协同链都遵循这个模式——入口（低稀有度）提供基础效果，出口（高稀有度）将效果放大。

### 方法论2："乘法点"放置法

**操作步骤**：
1. 确定一个**线性增长属性**（如力量 = +1/次）
2. 在系统中放置2-3个**乘法点**（如Heavy Blade的×3、Limit Break的×2、多段攻击的次数乘法）
3. 乘法点应为**非凡/稀有稀有度**——确保"发现乘法点"本身是一种构筑奖励
4. 确保属性增长和乘法点分布在**不同的卡牌上**——需要玩家主动收集和搭配

**验证**：如果力量和Heavy Blade的效果在同一张牌上（如"造成14伤害，力量对此卡×3，且获得+1力量"），协同就消失了，变成了一张强力单体牌。分离是协同的前提。

### 方法论3："有毒资产"设计模式

**操作步骤**：
1. 设计一组**带有明显代价的强力效果**（如高伤害但注入状态牌）
2. 设计一组**将代价转化为收益的转化牌**（如状态牌 → 抽牌/伤害/Block）
3. 转化牌应比代价牌**更稀少**——大多数时候玩家需要权衡代价
4. 当两者同时出现时，组合效果应**明显优于无代价版本**——奖励玩家的构筑努力

**验证**：Wild Strike（普通，12伤害+伤口）本身是"可接受的代价"。当搭配Evolve（非凡，状态牌=额外抽牌）时，伤口变成免费抽牌触发器，Wild Strike变成"12伤害+免费抽牌"——优于无代价版本。

### 方法论4：稀有度分层教学

**操作步骤**：
1. **普通稀有度**：放置教学用卡牌，让玩家理解基础概念（Flex教力量、True Grit教消耗）
2. **非凡稀有度**：放置稳定版的相同概念（Inflame=永久Flex、Dark Embrace=消耗=抽牌）
3. **稀有稀有度**：放置该概念的"完全体"或"爆发点"（Demon Form=终极力量、Corruption=终极消耗）
4. 确保只用普通+非凡卡牌就能构建可用的策略，稀有卡牌是"锦上添花"而非必需品

**验证**：铁甲战士的每个协同群（力量、消耗、防御）都可以只用普通+非凡牌构建。稀有牌提供的是"终极形态"而非基础功能。

## 第六部分：可迁移设计工具

### 工具1：协同设计检查清单

设计一组有协同的系统时，检查以下项：

- [ ] 协同的核心属性是否被至少2张牌/技能引用？（否则不是"主题"，只是孤立效果）
- [ ] 是否有至少1个"乘法点"让核心属性非线性增长？
- [ ] 入口机制（获得属性）和放大机制（利用属性）是否在不同物品上？
- [ ] 是否存在"有毒资产"——有代价的强力效果 + 转化代价的手段？
- [ ] 协同的各部分是否分布在不同稀有度，形成渐进发现路径？

### 工具2：资源流设计模板

```
1. 选择核心资源：__________
2. 设计产出路径：__________ → 核心资源
3. 设计消耗路径：核心资源 → __________
4. 设计转化路径：核心资源A → __________ → 核心资源B
5. 放置乘法点：在__________处让核心资源效果×N
6. 设计有毒资产：__________有代价但强力 + __________转化代价
```

### 工具3："分离=协同"原则

如果想让两个效果产生协同，**不要把它们放在同一个物品上**。放在同一物品上只是一张强力牌，分开放在两个物品上才需要玩家去收集和搭配——这就是构筑的乐趣来源。
