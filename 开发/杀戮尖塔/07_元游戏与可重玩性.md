# 07 元游戏与可重玩性：为什么百小时后仍有新发现

## 核心问题

杀戮尖塔如何在保持随机性的同时确保玩家的成长感？解锁、攀升和随机性如何共同服务于可重玩性？

---

## 一、解锁系统：渐进式信息呈现

### 1.1 逐步解锁的卡牌池

每个角色有5个解锁等级。每级解锁3张新卡牌/遗物，逐步扩充可获取的牌池。

以铁甲战士为例：

| 解锁等级 | 解锁内容 |
|---------|---------|
| 第1级 | Heavy Blade、Spot Weakness、Limit Break |
| 第2级 | Omamori、Prayer Wheel、Shovel |
| 第3级 | Wild Strike、Evolve、Immolate |
| 第4级 | Havoc、Sentinel、Exhume |
| 第5级 | Blue Candle、Dead Branch、Singing Bowl |

> 数据来源：[Ironclad - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Ironclad) — Unlocks section

**设计意图**：新手不需要面对全部卡牌池做决策。初始池较小，降低了信息过载；随着玩家经验增长，新卡牌逐步引入，每次解锁都带来新的策略可能性。

### 1.2 为什么"限制可用内容"反而更好？

- **降低认知负担**：新手只需理解约30张卡牌的交互，而非100+张
- **创造里程碑感**：每次解锁都是"我的工具箱又扩大了"
- **自然教学**：初始池包含基础概念（攻击/防御/力量），后续解锁引入更复杂的概念（消耗/状态/无限）
- **逐步增加深度**：当玩家掌握了基础策略后，新解锁的卡牌打开新的构筑方向

### 1.3 角色解锁顺序

故障机器人需要用静默猎人通关一次才能解锁；观者需要用任意基础角色通关且故障机器人已解锁。这确保了玩家按**从简单到复杂**的顺序接触角色。

## 二、攀升系统：20层渐进挑战

### 2.1 攀升机制

攀升（Ascension）是一个累积性的难度系统，共20级。每次通关解锁下一级，失败不会倒退。每级添加一个新的负面修正，所有修正**叠加**生效。

| 等级 | 修正内容 | 影响维度 |
|------|---------|---------|
| 1 | 精英出现频率+60% | 地图压力 |
| 2 | 普通敌人伤害增加 | 战斗压力 |
| 3 | 精英伤害增加 | 战斗压力 |
| 4 | Boss伤害增加 | Boss压力 |
| 5 | Boss战后回复降至75%缺失HP | 资源恢复 |
| 6 | 开局损失10%HP | 初始状态 |
| 7 | 普通敌人HP增加 | 战斗时长 |
| 8 | 精英HP增加 | 战斗时长 |
| 9 | Boss HP增加 | Boss时长 |
| 10 | 开局获得1张诅咒 | 牌组污染 |
| 11 | 药水槽-1 | 资源限制 |
| 12 | 升级卡牌出现概率减半 | 成长质量 |
| 13 | Boss金币奖励-25% | 经济压力 |
| 14 | 最大HP-5（铁甲）/ -4（其他） | 生存空间 |
| 15 | 不利事件概率增加 | 随机性惩罚 |
| 16 | 商店价格+10% | 经济压力 |
| 17 | 普通敌人获得强化技能 | 敌人复杂度 |
| 18 | 精英获得强化技能 | 敌人复杂度 |
| 19 | Boss获得强化技能 | Boss复杂度 |
| 20 | 第三幕末连续打两个Boss | 终极挑战 |

> 数据来源：[Ascension - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Ascension)

### 2.2 攀升设计的精妙之处

**维度递增而非数值膨胀**：攀升不是简单地把敌人HP和伤害翻倍。它从多个维度逐步增加压力：

```
A1-4：   伤害压力（打你更痛）
A5-9：   生存压力（回复更少、初始更弱、敌人更耐打）
A10-14： 资源压力（诅咒、少药水、少升级、少金币、少HP）
A15-19： 系统压力（不利事件、更贵商店、敌人更强机制）
A20：    终极检验（双Boss）
```

**"不会倒退"的容错设计**：攀升等级只升不降。即使玩家在某个等级卡了很久，也不会因为失败而回到更低的等级。这消除了"退步"的挫败感——你的进度永远是向前的。

**可以回退游玩**：玩家可以选择任何已解锁的攀升等级游玩。这意味着如果你想练习A15的策略但不想面对A20的压力，你可以回到A15。这给了玩家**自主控制难度**的权力。

## 三、随机性与策略性的共生

### 3.1 杀戮尖塔中的随机性来源

| 来源 | 随机内容 | 策略应对 |
|------|---------|---------|
| 地图生成 | 房间排列和路径 | 根据当前状态选路径 |
| 卡牌奖励 | 3选1的随机卡牌 | "不拿"也是一种策略 |
| 敌人行为 | 概率性行动模式 | 基于意图做风险管理 |
| 事件结果 | 随机事件和选项 | 基于当前资源评估风险 |
| 遗物获取 | 随机遗物 | 适应获得的遗物调整策略 |
| 药水获取 | 随机药水 | 65%普通/25%非凡/10%稀有 |

> 数据来源：[Potions - Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Potions) — "When a potion is offered to you, the rarity chances are: 65% Common, 25% Uncommon, 10% Rare."

### 3.2 "随机性服务于可重玩性"

杀戮尖塔的随机性不是为了"惩罚玩家"，而是为了**确保每局都不同**。核心设计原则是：

**随机性影响"获得什么"，策略决定"怎么用"**。

- 你不能选择获得什么卡牌，但可以选择拿不拿
- 你不能选择遇到什么敌人，但可以选择打不打（路径规划）
- 你不能选择敌人下一步做什么，但可以看到意图并应对
- 你不能选择获得什么遗物，但可以围绕遗物调整构筑

这种"随机提供素材，策略决定组合"的模式是杀戮尖塔可重玩性的根基。

### 3.3 隐藏的补偿机制

游戏中有一些不太明显的补偿机制来帮助运气不佳的玩家：

- **稀有卡牌概率递增**：每出一张普通牌，稀有概率+1%（见03_卡牌系统）
- **同种敌人不连续3次出现**：防止连续遇到最难缠的敌人
- **Neow的哀歌**：前3场战斗敌人只有1HP，给最倒霉的开局一个保底

这些机制在玩家不知情的情况下悄悄运作，确保了**运气不会完全决定胜负**。

## 四、玩家技能成长曲线

### 4.1 认知跃迁模型

基于社区经验和Wiki上的策略讨论，玩家的成长大致经历以下阶段：

**阶段一：生存本能（0-5局）**
- 目标：活着就是胜利
- 行为模式：拿所有攻击牌，堆伤害
- 核心误区："牌越多越强"

**阶段二：攻防平衡（5-20局）**
- 目标：学会防御的重要性
- 行为模式：开始拿防御牌，理解Block的价值
- 核心跃迁："防御比攻击更重要"

**阶段三：牌组精简（20-50局）**
- 目标：学会"不拿牌"
- 行为模式：积极删牌，保持小牌组
- 核心跃迁："少即是多"

**阶段四：协同效应（50-100局）**
- 目标：追求卡牌/遗物之间的协同
- 行为模式：围绕核心引擎构筑，不再"拿最好的牌"而是"拿最适合的牌"
- 核心跃迁："单个强力卡 < 系统性协同"

**阶段五：适应性构筑（100+局）**
- 目标：根据每局的随机性灵活调整策略
- 行为模式：不再预设流派，而是根据获得的资源决定方向
- 核心跃迁："没有万能的最优解"

### 4.2 设计如何引导认知跃迁

| 认知跃迁 | 游戏机制引导 |
|---------|-------------|
| "防御很重要" | 第一幕Boss伤害高，纯攻击无法存活 |
| "少即是多" | 牌组膨胀导致抽不到关键牌 |
| "卡牌间有协同" | 力量×多段攻击的明显效果差异 |
| "需要适应随机性" | 每局获得不同的卡牌/遗物，同一流派不总是可行 |

## 五、药水系统：应急与策略的平衡

### 5.1 药水的基本属性

- 一次性使用，不消耗能量，不算打出卡牌
- 携带上限3个（攀升11后降至2个，药水腰带可+2）
- 使用时机完全由玩家决定

药水是杀戮尖塔中最**玩家可控**的随机资源——你获得什么药水是随机的，但什么时候用、用在哪里完全由你决定。

### 5.2 药水的战略价值

| 类型 | 代表 | 战略用途 |
|------|------|---------|
| 即时伤害 | Fire Potion（20伤害） | 补足伤害缺口，击杀关键目标 |
| 即时防御 | Block Potion（12 Block） | 应急防御 |
| 即时资源 | Energy Potion（+2能量） | 关键回合额外输出 |
| 状态增强 | Strength Potion（+2力量） | 持久战增益 |
| 逃生 | Smoke Bomb（逃离战斗） | 放弃不利战斗（无奖励） |
| 保命 | Fairy in a Bottle（死亡时回复30%HP） | 安全网 |

角色专属药水进一步加强了角色身份：
- 铁甲战士：Blood Potion（回复20%最大HP）、Elixir（消耗手牌）
- 静默猎人：Poison Potion（施加毒素）、Cunning Potion（生成暗器）
- 故障机器人：Focus Potion（+2专注）、Potion of Capacity（+2充能球槽）
- 观者：Bottled Miracle（获得奇迹）、Stance Potion（进入姿态）

## 六、反事实推演

### 如果没有攀升系统？

- 通关一次后，后续每局难度相同
- 高手在基础难度下的通关率接近100%，游戏失去挑战性
- 没有渐进式的难度目标，长线动力下降
- 百小时后的玩家没有新的挑战可以追求

### 如果所有卡牌从一开始就全部解锁？

- 新手面对100+张卡牌的决策空间，信息过载
- 早期游戏的策略深度过高，学习曲线过于陡峭
- 没有了"解锁新卡牌"的里程碑感
- 可能导致新手更快流失

### 如果没有随机性，所有奖励固定？

- 每局游戏的最优路径会被迅速发现
- 游戏变成一个固定解谜，可重玩性趋近于零
- "适应随机性"这个核心技能失去了意义
- 社区讨论会从"这局你怎么构筑的"变成"你还没发现最优解吗"

## 七、可迁移经验

### 1. 渐进式内容解锁
不要一开始就把所有内容暴露给玩家。通过解锁系统逐步引入新元素，既控制了信息量，又创造了里程碑感。

### 2. 多维度难度递增
难度提升不应只是数值膨胀。从伤害、资源、经济、敌人复杂度等多个维度逐步施压，让每一级难度都有质的不同。

### 3. "只升不降"的进度保护
当难度解锁后不允许倒退。失败不会惩罚进度，只靠胜利来推进。这消除了"越玩越差"的挫败感。

### 4. 随机性提供素材，策略决定组合
不要让随机性决定胜负，而让它决定"这一局是什么样的"。玩家的决策空间应该始终大于随机性的影响。

### 5. 隐藏的补偿机制
在玩家看不到的地方（如稀有概率递增、敌人不连续重复），悄悄帮助运气不佳的玩家。这提升了体验的稳定性而不破坏"公平"感。
